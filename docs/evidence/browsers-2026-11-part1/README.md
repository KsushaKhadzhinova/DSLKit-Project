## Дефекты и причины

1. Главная проблема прогонов: `Page.goto` по таймауту 8 с. Одиночный замер Firefox показал загрузку за 4,7 с, поэтому основная причина — загрузка машины (параллельные процессы), а не сайт. Скрипты не менялись. Нужен повтор на свободной машине или более длинный таймаут.
2. `probe.py`: после окончания работы Firefox `browser.close` не возвращается. Прогон скрипта в Firefox может зависать на выходе.
3. `testing-course/full/e2e_env.py`: добавлена ветка `E2E_BROWSER=firefox` (`p.firefox.launch()`). Это единственное изменение кода в этой работе.
