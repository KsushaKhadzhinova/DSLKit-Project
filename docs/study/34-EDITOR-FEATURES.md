# Функции редактора: разбор для защиты

Что добавлено в редактор Части 1 в октябре 2026, как это устроено и как показать. Английская версия: [`34-EDITOR-FEATURES.en.md`](34-EDITOR-FEATURES.en.md). Код лежит в `site/js/`, тесты в `labs/05-javascript-interactivity` и `labs/06-async-api-storage`.

## 1 Автосохранение

- **Что делает.** Через секунду после последнего изменения код записывается в `localStorage` (ключ `dslkit.editor-source`), в строке состояния появляется «Сохранено 22:30», метки несохранённого файла исчезают. При открытии страницы код возвращается.
- **Как устроено.** `components/source-autosave.js`: `MutationObserver` следит за списком строк кода, таймер (`setTimeout`, можно подменить в тестах) откладывается при каждой правке. Переключатель «Автосохранение» в меню включает и выключает запись. Испорченное или пустое сохранённое значение игнорируется.
- **Показать.** Меню «⋯» → шаблон другой нотации → подождать секунду → перезагрузить страницу.
- **Вопрос преподавателя:** «Зачем MutationObserver?» Код выводится списком элементов, а не полем ввода, поэтому событие `input` недоступно.

## 2 Экспорт

- **Форматы.** SVG, PNG, JPEG, `.drawio`, самодостаточный `.html` (рисунок и код, без сети и скриптов) и текст кода: PlantUML (`.puml`) и Mermaid (`.mmd`).
- **Как устроено.** `components/export-menu.js` берёт SVG с холста, `utils/exporters.js` собирает файл. PNG и JPEG рисуются через `Image` и `canvas` с белым фоном в двойном масштабе. Файл `.drawio` содержит рисунок одной картинкой на странице (не набором фигур). Имя файла строится из названия диаграммы (`fileName`). Скачивание: ссылка на временный адрес `URL.createObjectURL`.
- **Показать.** Меню «⋯» → «Экспорт PNG».
- **Код как файл.** `.puml` и `.mmd` делаются из кода, а не из рисунка, поэтому работают и без запуска. Они доступны там, где есть обратный разбор в импорте: блок-схема (Graph) даёт Mermaid, диаграммы последовательности и состояний дают оба языка. Для остальных нотаций редактор пишет, что обратного соответствия нет, и ничего не скачивает (`sourceExport` в `notations/index.js`). Выгруженный файл можно вернуть через «Импорт из файла».
- **Ограничение (честно):** `.drawio` нельзя редактировать по фигурам.

## 3 Импорт Mermaid и PlantUML

- **Что понимает.** Блок-схемы Mermaid (`graph`/`flowchart`), диаграммы последовательности и состояний (Mermaid и PlantUML). Результат: код DSLKit, который редактор принимает без ошибок. Остальные виды (классы, ER, Гант) называются неподдерживаемыми, пропущенные конструкции перечисляются.
- **Как устроено.** `utils/import-diagram.js` (чистые функции, три разбора), `components/import-menu.js` (файл и буфер обмена). Идентификаторы очищаются, кавычки и обратные слэши в подписях нейтрализуются.
- **Показать.** Меню «⋯» → «Импорт из буфера» с текстом `flowchart TD\nA[Старт] --> B{Ок?}`.

## 4 Перетаскивание блоков

- **Что делает.** Блок двигается мышью, пальцем или стрелками (Shift: шаг 50). Положение пишется в код как `pos=600x214.4` на строке блока, диаграмма перерисовывается.
- **Как устроено.** Отрисовка (`notations/svg.js`) читает `pos`, ставит центр блока и расширяет страницу; на каждом блоке есть `data-cx`, `data-cy`. `components/canvas-drag.js` ловит `pointerdown/move/up` на холсте, переводит экранные точки в единицы рисунка (`pointInDrawing`), `utils/node-position.js` меняет строку кода, не трогая текст в кавычках. Клавиатура: у блоков `tabindex`, после перерисовки фокус возвращается.
- **Условие.** Работает с «Собственным движком» и нотациями с общей раскладкой.
- **Показать.** Настройки → движок «Собственный» → шаблон BPMN → потянуть блок «Ship goods».

## 5 Панель свойств блока

- **Что делает.** Щелчок (или Enter) по блоку открывает панель под рисунком: подпись, цвет, вид блока (ключевое слово нотации, например `task` или `end`) и положение X, Y. Каждое изменение пишется в строку блока: `task t "Do it" duration=2 color=#ffcc00 pos=400x300`, диаграмма перерисовывается. Escape или «Закрыть» убирают панель.
- **Как устроено.** `utils/node-edit.js` режет строку объявления на ключевое слово, имя, подпись и признаки и собирает заново, текст в кавычках не трогает; цвет принимается только как `#rgb` или `#rrggbb`, поэтому в атрибут SVG ничего лишнего не попадёт. `components/node-panel.js` слушает щелчки на холсте, после каждой перерисовки (`MutationObserver`) заново читает значения из кода. Положение переиспользует `setNodePosition` из перетаскивания. Цвет закрашивает блок в `notations/svg.js` (`tint`).
- **Условие.** Работает с «Собственным движком» и нотациями, у которых строки вида `ключевое_слово имя "подпись"` (все, что описаны таблицей видов, их 25 из 34). Класс, ER, IDEF0, последовательность и Graph панель не открывают. Положение показывается только у блоков с общей раскладкой (у задачи диаграммы Ганта места нет, его задаёт время).
- **Показать.** Настройки → движок «Собственный» → шаблон BPMN → щёлкнуть по блоку → сменить цвет.

## 6 Диаграмма Ганта

- **Запись.** `task id "Подпись" start=4 days=7 done=40 color=#2563eb`, `milestone id "Подпись"`, `depends a -> b`. Время в днях. Начало задачи берётся из конца самой поздней из задач, от которых она зависит; `start=` задаёт его явно.
- **Рисунок.** Полосы на оси времени с шагом сетки 1, 2, 5, 10 ... дней, готовая часть закрашена темнее, веха ромбом, зависимости ломаными со стрелками, критический путь (задачи без запаса) жёлтым. Описан в `notations/specs-gantt.js` и не использует общую раскладку, поэтому блоки не перетаскиваются.
- **Проверки.** Неверное число (`gantt-number`), кольцо зависимостей (`gantt-cycle`), задача начинается раньше окончания предшественника (`gantt-early`).
- **Экспорт.** PlantUML (`@startgantt`) и Mermaid (`gantt`) с датами от условного 1 января 2026.
- **Показать.** Список нотаций → «Диаграмма Ганта».

## 10 Вероятные вопросы

- Почему код в списке элементов, а не в `<textarea>`? Строки подсвечиваются по ключевым словам.
- Чем `pos=` лучше хранения координат отдельно? Один источник правды: код. Перезапуск даёт ту же картинку.
- Почему service worker не кэширует Kroki? Это чужой сервис, его ответы нельзя считать нашим файлом.
- Почему панель не меняет рисунок напрямую? Один источник правды: код. Панель правит строку, рисунок строится заново.
- Что будет при повреждённом `localStorage`? Чтение защищено `try/catch`, повреждённое значение игнорируется.
