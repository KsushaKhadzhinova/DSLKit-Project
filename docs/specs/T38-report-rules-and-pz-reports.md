# T38: правила оформления отчётов и отчёты ПЗ1, ПЗ2

Короткая спецификация. Подробные таблицы правил: `docs/notes/20-report-rules-stp-2024.md`, требования преподавателя: `docs/notes/06-teacher-requirements.md`, что остаётся владельцу: `docs/notes/22-t38-owner-only.md`.

## Инструменты

- `tools/build.js`, `tools/build-report.js`: сборка `report.md` из шаблона.
- `tools/docx.js`, `tools/docx-cli.js`: DOCX только на русском; номера страниц содержания считает Word.
- `tools/part2/lint-report.js`: проверка текста отчёта, вызывается из `report.test.mjs` каждой работы.

## Правила, добавленные 2026-11-28

- Без прописных в заголовках, содержании и приложениях.
- Титульный лист по образцу (подписи слева, группа и фамилия в правой колонке).
- Язык: минимум латиницы, без «я, мы, вы», безличный стиль краткими страдательными причастиями, слова «был, была, было, были» и «также» запрещены (как и «was», «were», «also» в английской версии), прошедшее время, без повелительного наклонения.
- Линтер для языковых правил: `person`, `verb1`, `imperative`, `latin` (допустимые латинские термины в `LATIN_OK`).
