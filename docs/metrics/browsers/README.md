# Проверка в Firefox и Edge (14.10.2026)

Реальные браузеры, управление через puppeteer-core (скрипт во временной папке, в репозиторий не входит). Сервер сайта: `npm start`, `http://localhost:5173`.

| Браузер | Версия | Результат |
| ------- | ------ | --------- |
| Firefox | 157.0.1 | 20 из 20 |
| Microsoft Edge | 155.0.4283.45 | 20 из 20 |

Проверено в каждом браузере: загрузка лендинга и один `h1`; кнопка «Создать диаграмму»; переключатель темы и сохранение после перезагрузки; фильтр нотаций (3 и 6 карточек); аккордеон (открыт один ответ); форма (4 ошибки при пустой отправке, верная отправка сохраняет заявку и открывает страницу благодарности); отсутствие горизонтальной прокрутки на 375 px; бургер-меню и Escape; фильтр и поиск дашборда; выбор темы в настройках; вкладки редактора; собственный движок диаграмм; диалог закрытия файла; отсутствие ошибок в консоли.

Найден и исправлен дефект: на 375 px страница прокручивалась вбок (`html { overflow-x: clip }` в `site/css/base.css`).
