## 1. Цель

Выполнить на теме DSLKit все работы курса ИТиВП:

- Часть 1: лабораторные 1–8 (сеть, окружение, семантический HTML, адаптивный CSS, JavaScript и DOM, API и хранилища, React-компоненты, тестирование).
- Часть 2: лабораторные 1–8 (Node.js, Sequelize, аутентификация, состояние React, React и сервер, MongoDB, WebSocket, Docker), практические 1–4 (middleware и шаблонизаторы, REST API, маршрутизация React, состояние), курсовой проект.

- Отчёты Markdown на русском и английском без титульного листа для Части 1; код только в приложениях; сборка из шаблонов.

- Токен тёмной темы `muted` поднят до `#8a8fa8` (прежний `#7f849c` давал контраст 4,44 вместо 4,5).
- Лендинг честно говорит, что сервис в разработке: кнопка «Записаться в бету», в микроразметке только Offer с ценой 0 и `PreOrder`, нет выдуманных отзывов и цен.
