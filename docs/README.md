# Документы проекта

- [`CONTEXT.md`](CONTEXT.md) контекст для продолжения работы: пользователь, правила, договорённости, ловушки среды, промпт для нового чата.
- [`HANDOVER-LABS.md`](HANDOVER-LABS.md) статус всех лабораторных и практических, список того, что осталось, следующий шаг.
- [`project/`](project/) архив проекта DSLKit: обзор, дизайн-токены, исследование интерфейса, итоги 100 A/B тестов, HTML-макеты и SVG.
- [`../materials/`](../materials/README.md) условия работ и методические материалы с извлечённым текстом.
- В каждой работе есть свой `README.md`: `labs/01-network`, `labs/02-environment`.
