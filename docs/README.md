# Документы проекта

- [`INSTRUCTIONS.md`](INSTRUCTIONS.md) рабочие правила проекта, [`CONTEXT.md`](CONTEXT.md) контекст и договорённости, [`HANDOVER-LABS.md`](HANDOVER-LABS.md) статус лабораторных, [`SESSION-LOG.md`](SESSION-LOG.md) журнал работы, [`PROGRESS-AND-HANDOVER.md`](PROGRESS-AND-HANDOVER.md) прогресс и передача, [`DIALOGUE-CONTEXT.md`](DIALOGUE-CONTEXT.md) хронология решений
- [`HANDOVER.md`](HANDOVER.md) ([EN](HANDOVER.en.md)) с чего начать: передача проекта одним документом
- [`PROJECT-STATE.md`](PROJECT-STATE.md) состояние проекта: цель, правила, карта веток, статус каждой работы, команды, ловушки среды, план (английская версия [`PROJECT-STATE.en.md`](PROJECT-STATE.en.md))
- [`study/`](study/README.md) разборы работ для защиты: ЛР1–ЛР8, ПЗ1–ПЗ4, обзоры Частей 1 и 2, курсовой проект, запуск, данные от владельца, аудит безопасности
- [`notes/`](notes/) требования преподавателя, прогноз допов, бриф негативных тестов, снимки, план работ
- [`agent-reports/`](agent-reports/) результаты проверок: консилиум по допам, аудиты, метрики дизайна
- [`project/`](project/) архив проекта DSLKit: обзор, дизайн-токены, исследование интерфейса, итоги A/B тестов, HTML-макеты
- [`design-contest/`](design-contest/) макеты редактора (все нотации и движки), экраны Части 2, скрипты съёмки
- [`../materials/`](../materials/README.md) условия работ и методические материалы с извлечённым текстом
- В каждой работе есть свой `README.md`: `labs/01-network` … `labs/08-frontend-testing` и `part-2/<работа>`
