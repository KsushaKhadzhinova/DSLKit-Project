Пишите код — получайте диаграмму

Веб-редактор диаграмм как кода. Опишите схему на DSL, DSLKit проверит её по правилам нотации и нарисует.

Создать диаграммуЗаписаться в бету

Бесплатно в бете: до 5 диаграмм в день. Карта не нужна.

idef0 "Order" {
  A0 "Process order" {
    input   Order
    control Rules
    output  Invoice
  }
}
dfd "Shop" {
  entity  Customer
  process Checkout
  store   Orders
  Customer -> Checkout
  Checkout -> Orders
}
erd "Shop" {
  entity User { id, email }
  entity Order { id, total }
  User 1..* Order
}

Вопросы и ответы

Что такое DSLKit?

Веб-редактор диаграмм как кода: схема описывается текстом, а редактор проверяет её и рисует.

Нужно ли уметь программировать?

Нет. Синтаксис короткий, шаблоны и подсказки помогают написать первую диаграмму.

Какие нотации поддерживаются?

UML, BPMN, ERD, DFD, IDEF0 и сети Петри. Первыми в бете — IDEF0, DFD и ERD.

Сколько это стоит?

В бете бесплатно, до пяти диаграмм в день. Pro появится позже.
