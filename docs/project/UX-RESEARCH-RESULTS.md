# DSLKit UX Research Results

## Expert evaluations (12 оценщиков)

### Методология
Каждый оценщик получал макет DSLKit IDE v2 (улучшенный) и оценивал:
- Первое впечатление (30 сек)
- Усвояемость (без инструкций)
- Эффективность (задачи в домене)
- Удовлетворённость
- Вероятность рекомендации

## Ключевые инсайты

### Общий SUS до исправлений: ~63/100 (ACCEPTABLE, но не GOOD)
### Прогноз после accessibility + P1/P2 фиксов: **82+** (EXCELLENT)

### Топ-5 приоритетов
1. **Accessibility** (aria-labels, focus rings, roles) — WCAG Level A
2. **Onboarding** — объяснение нотаций, templates, "Start Here"
3. **P1 bug** — диалог при закрытии несохранённого таба
4. **P2 bug** — disable Run при ошибках
5. **DSL Autocomplete** — подсказки синтаксиса прямо в editor

### Целевая аудитория (по результатам)
| Аудитория | Принятие | Действие |
|-----------|----------|---------|
| Technical (DS, DevOps, Architect) | 🟢 Высокое | Фокус на возможностях |
| Mid-level (Dev, QA, Student) | 🟡 Среднее | Нужен onboarding |
| Non-technical (BA, HR, PM) | 🔴 Низкое | Нужен visual mode или не целевая |

## A/B Test Summary (5 батчей, ~49 вопросов)

### Принятые решения
| Элемент | Выбрано | Обоснование |
|---------|---------|-------------|
| Autosave | Toggle switch ON/OFF | Консистентно с theme toggle |
| Unsaved indicator | ● точка на табе | Минималистично, не мешает |
| Run button | Зелёная заливка | Чёткий visual affordance |
| Validate | Ghost button | Отличается от Run |
| Undo/Redo | Всегда видимы | Discoverability |
| Icons | 1.25px/17px | Middle ground |
| Tab close ×  | 20px кнопка | Достаточная tap target |
| Empty state | Chooser с нотациями | Onboarding + utility |
| Error panel | Снизу, закрываемый | Стандартный паттерн IDE |
| Notation label | "Diagram: IDEF0" | Context awareness |

### Открытые вопросы (не решены)
- Connection style (curved vs straight) — нет явного лидера
- Mobile layout — не тестировалось
- Scrollbar style — system vs custom
