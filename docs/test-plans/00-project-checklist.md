## 7. Правила, действующие для всей работы

- Коммиты только от имени владелицы, на английском, без подписей инструментов.
- Ничего не вливать в `main` и не пушить без её слова. Силой пушить и переписывать историю нельзя.
- Секреты только в `.env`, не в чате и не в репозитории.
- Отчёты и README на русском и английском одновременно.
- Не коммитить `.claude/admin-test-account.txt`, `.claude/worktrees/`, `.playwright-mcp/`, `.accelerator/profile.user.json`.
- На 70% недельного лимита аккаунта останавливать тяжёлую работу.
