## Что просила владелец

1. Изучить репозиторий, задать вопросы и продолжить незаконченное: сначала ЛР2 и ЛР3 по вёрстке (HTML), затем стили.
2. Метрики дизайна и UX, прогон независимых агентов и их оценки.
3. Макеты с разметкой и метрики по ним (макеты уже есть в репозитории).
4. Стартовая страница не должна быть голой и сухой; показывать возможности, а не сравнивать с конкурентами; порядок нотаций по популярности.
5. Собрать Figma-файл с макетами, мокапами, вайрфреймами, мудбордом, шрифтами, цветами, логотипами, компонентами и страницами по устройствам.
6. Коммиты и push регулярно, без авторства и меток ИИ.

Метрики в [`ux/mockups-metrics.md`](ux/mockups-metrics.md).

## Принятые решения

- Домен `dslkit.io`; порядок нотаций UML, BPMN, ERD, DFD, IDEF0, сети Петри; без сравнений с конкурентами; интерфейс сначала на русском; стили после HTML.
- Валидатор html-validate: приняты только стилистические замечания `doctype-style` и `void-style`.
