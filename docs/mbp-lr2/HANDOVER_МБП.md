## 5 Как пересобрать

Диаграммы: `python generate_dslkit.py` в `E:\ИИТ\МБП_ЛР1` (запускать из этой папки, нужен `generate.py`), `python generate_lr2.py` в `E:\ИИТ\МБП_ЛР2`. Генерация может занять больше двух минут (matplotlib), запускать в фоне.

Отчёт: правки в `E:\report-gen\projects\mbp-lrN\content\*.md`, затем `report-gen build projects/mbp-lrN` и `report-gen lint projects/mbp-lrN` (цель: 0 ошибок и 0 предупреждений). Результат скопировать в папку лабораторной. Заголовки разделов в `04_progress.md` без `{-}`, чтобы рисунки и таблицы нумеровались как 1.1, 1.2. В тексте ссылаться по номерам («на рисунке 1.2», «в таблице 1.1»), метки `{fig:...}` и `{tab:...}` для таблиц не работают, длинное тире «—» заменять на «–», слова «также» и «были» не использовать. Подпись таблицы: строка `Таблица: Название` перед таблицей, рисунок: `![подпись](diagrams/файл.png)`.

Открыть в draw.io (браузер владелицы, расширение Claude in Chrome): открыть `https://app.diagrams.net/?splash=0&lang=ru`, выполнить в странице `Draw.loadPlugin(ui => window.__ui = ui)`, добавить скрытый `<input type=file>`, загрузить файл `file_upload` (файл должен лежать в рабочей папке сессии, например в scratchpad), прочитать его через `FileReader` и вызвать `ui.fileLoaded(new LocalFile(ui, text, name))`. Прямые ссылки (`#U`, `#R`) и fetch с localhost не работают из-за CSP draw.io.
