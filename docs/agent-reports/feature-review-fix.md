# Функция «Проверить и исправить»

Пользователь отправляет свою диаграмму (код из редактора, в том числе распознанный по картинке или файлу). Система говорит, что в ней не так, и предлагает исправленные варианты.

## Что сделано

- `site/js/utils/diagram-review.js`: чистые функции `reviewCode(code, { lang })`, `applyEdits`, `diffLines`, `checkCode`, `nearest`. Результат: `{ notation, issues: [{ severity, line, rule, message: { ru, en }, fix }], variants: [{ id, title, code, changes, errors, warnings }] }`.
  - Замечания берутся из собственного парсера и валидатора каждой нотации (те же, что в панели проблем) плюс правила проверки: нет названия, пустая диаграмма, нечитаемое имя, слишком длинная подпись, диаграмма распалась на части, у блока IDEF0 нет входа.
  - Исправление есть у замечаний: заголовок (нет, опечатка, лишнее слово), повтор идентификатора, неизвестный элемент (замена на ближайший, объявление или удаление строки), несвязанный элемент, незакрытый блок, опечатка в ключевом слове, повторная связь и связь на себя, DFD (поток без процесса, поток без подписи), BPMN и другие потоки (начало, конец, тупик, подписи ветвей шлюза), ERD (нет ключа, повтор атрибута), IDEF0 (нет output и control, неверный порт стрелки).
  - Варианты строятся детерминированно: «минимальный» (только ошибки) и «полная чистка» (ошибки, предупреждения, советы и форматирование). Исправления применяются проходами (до четырёх), каждый вариант заново разбирается валидатором и предлагается, только если проблем стало меньше.
- `tools/ai-review.js`: необязательный слой ИИ. Строит запрос, разбирает JSON-ответ, проверяет каждый вариант тем же валидатором, оставляет не более двух. Без ключа, при сбое сервиса или при непригодном ответе возвращается детерминированный результат.
- `tools/ai-api.js`: режим `review` в `/api/ai/generate` (пять строк).
- `site/js/components/review-panel.js` и `site/css/review.css`: панель «Проверить и исправить»: замечания, варианты рядом как разница (до и после; на телефоне колонки одна под другой), кнопка «Применить этот вариант». Применение пишет код в редактор как обычное изменение, поэтому «Отменить» возвращает прежний код. Строки разницы помечены знаками и скрытым текстом, не только цветом. Тексты на русском и английском.

## Ограничения

- Без ключа ИИ сервер отвечает 503, как и на другие режимы; панель в этом случае использует только локальную проверку.
- Не всё можно починить автоматически (например, недостижимый узел со связями): такое замечание помечено «исправить вручную».
- Исправление по правилам не знает смысла диаграммы: подписи вида «данные», «Обработка», «вариант N» нужно заменить своими.
- Размер и вид панели на реальном телефоне в браузере не проверялись, только разметка и тесты.
