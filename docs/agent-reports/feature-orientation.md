# Поворот экрана и соотношение сторон

English version: [`feature-orientation.en.md`](feature-orientation.en.md). Файлы: `site/css/orientation.css`, `site/js/components/orientation.js`, тесты `labs/05-javascript-interactivity/orientation.test.js`, e2e `testing-course/full/orientation-e2e.py`, макеты `docs/design-contest/orientation/`.

## Правила раскладки

| Условие                                                      | Раскладка                                                                                            |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| Меньше 576 px, портрет                                       | Одна колонка, нижняя навигация, код и холст по очереди, панели поверх                                |
| Альбом и высота до 500 px (телефон на боку)                  | Боковая рейка вместо нижней панели, код и холст рядом, разделитель, шапка ниже, панели оверлеем      |
| От 576 px, портрет (планшет, развёрнутый складной)           | Код над холстом, разделитель тянется по вертикали                                                    |
| От 576 px, альбом                                            | Код и холст рядом, разделитель по горизонтали, минимум панели 192 px                                 |
| От 576 px, соотношение сторон 9:10 до 11:10 (квадрат)        | Компактная шапка, панели 50/50                                                                       |
| От 1024 px, соотношение сторон от 2:1 (2560x1080, 3440x1440) | Длина строки ограничена, содержимое по центру                                                        |
| Отступы выреза                                               | `env(safe-area-inset-left/right)` на страницах кроме редактора, в редакторе у рейки                  |
| Клавиатура на экране                                         | `visualViewport` задаёт высоту, нижние панели скрыты, строка с курсором остаётся видимой             |
| Поворот или изменение окна                                   | Курсор, выделение и прокрутка кода сохраняются, меню закрываются, холст подгоняется без ручного зума |
| `forced-colors`, `print`                                     | Разделитель и рейка остаются видимыми, при печати не показываются                                    |

Ничего нового не сохраняется, настройка автоматическая. Проверено: jsdom (matchMedia, resize, visualViewport, 100% покрытия), правила CSS, e2e в Edge и Firefox. Не проверено на настоящих телефонах, планшетах и складных устройствах.
