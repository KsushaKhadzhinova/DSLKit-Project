# Интерактивное уточнение и дополнение диаграммы

Если диаграмма неполная или неоднозначная, система задаёт уточняющие вопросы и достраивает диаграмму по ответам.

## Что сделано

- `site/js/utils/diagram-questions.js`: чистые функции без побочных эффектов.
  - `buildQuestions(code, notation)` читает код через `parseDiagram` и возвращает список вопросов по важности (ошибки, замечания, детали). Вопрос: `{ id, kind: 'choice' | 'text' | 'yesno', text: { ru, en }, options, target: { line, id }, priority, apply(answer, code) }`.
  - Правила: нет заголовка или нотация неизвестна, нет начала или конца (BPMN, ГОСТ, UML activity и state), элемент без названия, связь без подписи (DFD, ветки шлюзов, решения ГОСТ), изолированный, недостижимый и тупиковый элемент, процесс DFD без входа или выхода, неизвестное слово в строке («что это за тип»), необъявленный элемент, неверная кратность и связь без названия (ERD, IDEF1), сущность без ключа, у блока IDEF0 нет входа, выхода, управления или механизма, в диаграмме последовательности нет действующего лица и сообщение без текста, в диаграмме вариантов использования нет актёра.
  - `completeFromAnswers(code, answers)` применяет ответы (объект `{ id: ответ }` или список `{ id, answer }`) и проверяет результат тем же парсером. Результат: `{ ok, valid, reason, code, applied, problems, errorsBefore, errorsAfter }`. Если ответы ухудшили диаграмму (стало больше ошибок) или ничего не изменили, `ok: false`, а `code` равен исходному: некорректный результат молча не возвращается.
  - Строки находятся по содержимому, а не по номеру, поэтому ответы можно применять в любом порядке.
- `tools/ai-questions.js`: режим `clarify` сервера ИИ, маршрут `POST /api/ai/clarify` (`step: 'questions' | 'complete'`). Модель добавляет до трёх вопросов, которых нет в правилах, и дорабатывает код по ответам на них. Код модели проходит `parseDiagram` и отбрасывается, если он хуже исходного (одна повторная попытка). Без ключа, при сбое модели и при ответах только на правила работает детерминированный запасной вариант. Лимиты запросов и суточный лимит общие с остальным ИИ и касаются только вызовов модели.
- `site/js/components/clarify-panel.js`: диалог «Уточнить и дополнить» (кнопка в меню «Автоматизация»). Один вопрос за раз, индикатор «Вопрос N из M» и полоса прогресса, кнопки «Назад», «Пропустить», «Далее» и «Применить ответы», Enter в текстовом поле ведёт дальше, Escape закрывает. Ответы записываются в код одним шагом, поэтому одно нажатие «Отменить» возвращает прежний код. Тексты на русском и английском, `role="dialog"`, фокус переходит на поле ответа, области `aria-live`, кнопки не ниже 44 px, панель занимает всю ширину на 375 px.
- `site/css/clarify.css`: небольшие стили (оболочка берётся у панели `.auto`).

## Ограничения

- Правила знают самые частые пробелы; для диаграмм классов, таймингов и части UML-видов вопросов пока нет.
- Если ответ на вопрос о связи приводит к большему числу ошибок, диалог сообщает об этом и оставляет код как есть.
