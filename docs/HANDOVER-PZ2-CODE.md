## Сделано

- Журнал запросов в таблице БД (`request_log`, SQLite): запись до выполнения запроса; при сбое записи ответ 500 `journal_unavailable`, действие не выполняется (проверено для POST, PUT, PATCH, DELETE и при параллельной нагрузке).
- Request ID: каждый ответ несёт заголовок `X-Request-Id` (значение всегда создаётся сервером), то же значение в теле ошибки, в таблице журнала (`request_id`) и в строке серверного лога. Старый файл журнала без этого столбца дополняется сам.
- Ошибки с подробным описанием: JSON `{ error: { code, message, title, description, requestId, details? } }`; для браузера (заголовок `Accept` предпочитает HTML) оформленная страница с блоками «What happened», «Likely cause», «What to do» и Request ID. Каталог текстов: `src/error-catalog.js`, страница: `src/error-page.js`. Статусы 400, 403, 404, 405, 406, 409, 412, 413, 415, 429, 500. Маршрута, который отдаёт 403, нет (в API нет авторизации), страница 403 описана и проверена тестом.
- PATCH и DELETE: условные запросы `If-Match` (412), 404 для уже удалённой записи, 409 для записи с зависимостями; разбор в `docs/study/36-PZ2-PATCH-DELETE.md`.
- Гонки: «создать дочернюю запись, пока администратор удаляет родителя» даёт 201/409/404 и никогда 5xx или сироту (`test/consistency.test.js`, `test/break.test.js`).
- Проверка ввода и пределы в `limits.json`; тесты на огромные значения, пробелы, невидимые символы, SQL- и HTML-инъекции, лишние ключи, числа вне диапазона.
- OpenAPI и `API.generated.*.md` приведены в соответствие с кодом (409 для отсутствующего родителя, 412).

## Как запустить

```powershell
cd part-2/pz-02-rest-api
npm ci
npm test
$env:PORT = 4210; node src/server.js
```

`npm test` включает порог 100 % строк, ветвей и функций и проверку отчёта; `npm run lint` без замечаний.

## Как воспроизвести сбой журнала (для скриншота страницы 500)

1. `$env:JOURNAL_FILE = "demo.sqlite"; $env:PORT = 4210; node src/server.js`
2. В другом окне: `node tools/break-journal.mjs demo.sqlite` (удаляет таблицу журнала под работающим сервером).
3. Откройте `http://localhost:4210/api/users` в браузере: страница 500 «Request journal unavailable» с Request ID; запись в таблице не создана, действие не выполнено.
4. Вернуть: `node tools/break-journal.mjs demo.sqlite --restore`.
