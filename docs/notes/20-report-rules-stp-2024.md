# Правила оформления отчётов (СТП 01–2024): три уровня

Контекст: преподаватель строго проверяет отчёты по СТП 01–2024 и по своим замечаниям. Правила разделены, потому что структура отчёта по ПЗ и ЛР отличается от структуры курсовой.

- **А. Общие.** Действуют для любого отчёта (ПЗ, ЛР, курсовая). Источники: СТП 01–2024 разд. 2, приложения Л, М, Н, П; ГОСТ.
- **Б. Для ПЗ и ЛР.** Требования преподавателя и условий работ (`docs/notes/06-teacher-requirements.md`). При конфликте с чеклистом курсовой действует Б.
- **В. Только для курсовой.** Структура и объём записки, шифр, список источников и т. п. Полный текст: `docs/notes/21-course-report-checklist.md`. В проверку ПЗ и ЛР не входит.

Проверка: `tools/part2/lint-report.js` (строгий режим `strict: true`, им пользуются отчёты части 2) вызывает `tools/report-rules.js`, где лежат новые механические правила А и Б. Базовый `tools/lint-report.js` (отчёты Части 1) не менялся. Правила В линтер не проверяет и профиля `course` не имеет: курсовая будет собираться отдельно.

## Конфликты

- Чеклист курсовой требует «(см. рисунок 2.1)» и нумерации по разделам, преподаватель по ПЗ – без «см. рис.» и сквозной. Для ПЗ и ЛР действует преподаватель (Б3, Б8). Для курсовой действует чеклист (В4). Решение по курсовой остаётся за владельцем.
