# Что остаётся владельцу для отчётов ПЗ1 и ПЗ2 (T38)

## Как собрать и открыть отчёт

- Markdown из шаблонов: `node tools/build.js part-2/pz-01-middleware-ejs` (то же для `pz-02-rest-api`).
- DOCX рядом с `report.md` и `report.en.md`: `node tools/docx-cli.js part-2/pz-01-middleware-ejs`. Конвертер `tools/docx.js` написан без внешних библиотек, линтер DOCX (`lintDocx`) проверяет курсив, табуляции, пробелы вместо отступов, поля 20/15/20/30 мм, титул без номера, поле содержания, шрифты.
- В Word после открытия согласитесь на обновление полей или нажмите Ctrl+A, затем F9: заполнятся номера страниц содержания.
- Тесты папки проверяют, что `report.docx` и `report.en.docx` соответствуют текущему `report.md`: после замены любого рисунка пересоберите DOCX командой выше.

## Титульный лист

Подставьте в DOCX свои данные вместо подчёркиваний: «Выполнил(а)» и «Проверил». Факультет и кафедра взяты из образца `пз1.docx`.

## ПЗ1 (`part-2/pz-01-middleware-ejs/figures/`): снимки, которые снимает владелец

Файлы-заглушки уже лежат под этими именами, замените их своими PNG с тем же именем (заглушки создаёт `shots/placeholders.mjs`, существующий файл он не трогает).

| Файл | Что снять |
|---|---|
| `owner-403.png` | Браузер, `http://localhost:3000/add?auth=1`: отправить форму без скрытого поля токена (удалить поле в DevTools и нажать кнопку), страница 403 целиком с адресной строкой |
| `owner-429.png` | Браузер, `http://localhost:3000/`: обновить страницу много раз подряд до страницы 429 |
| `owner-db-tables.png` | Любой просмотрщик SQLite: таблицы `diagrams` и `request_log` из файла базы, видны строки |

Существующие рисунки (главная, детальная, формы, журнал, 404, 500, консоль, тесты) сняты по прежней сборке; если страницы после доработки T37 изменились, снимите их заново под теми же именами.

## ПЗ2 (`part-2/pz-02-rest-api/figures/`): снимки Postman

Коллекция `postman_collection.json`, сервер `npm start` на порту 3000. Окно Postman целиком: запрос, код ответа, тело ответа.

| Файл | Операция |
|---|---|
| `postman-01-get-users.png` | `GET /api/users`, 200 |
| `postman-02-post-diagram.png` | `POST /api/diagrams`, тело `{"title":"Billing schema","notation":"ERD","code":"invoice -> payment","projectId":1}`, 201 |
| `postman-03-patch-user.png` | `PATCH /api/users/1`, тело `{"role":"editor"}`, 200 |
| `postman-04-post-invalid.png` | `POST /api/users`, тело `{"name":"","email":"x"}`, 400 |
| `postman-05-delete-conflict.png` | `DELETE /api/users/1`, 409 |

Для ПЗ2 нужны ещё отдельные снимки для `PUT` и `DELETE` с кодом 204 (по одному на тип запроса), отчёт ПЗ2 по этому пункту будет пересобран отдельным шагом.
