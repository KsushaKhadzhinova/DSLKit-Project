# Что остаётся владельцу для отчётов ПЗ1 и ПЗ2 (T38)

## Как собрать и открыть отчёт

- Markdown из шаблонов: `node tools/build.js part-2/pz-01-middleware-ejs` (то же для `pz-02-rest-api`). Шаблон может брать `{{meta:repository}}` и `{{meta:branch}}` из `report.meta.json` и фрагмент файла `{{code:путь#от-до}}`.
- DOCX только русский (решение владельца): `node tools/docx-cli.js part-2/pz-01-middleware-ejs`. Английские DOCX не собираются, `report.en.md` обновляется только для согласованности.
- Номера страниц содержания считает Word (`tools/docx-pages.ps1`, нужен установленный Word) и записывает в `report.toc.json` вместе с хэшем документа, для которого они посчитаны. Если текст, шаблон или размеры рисунков изменились, тест просит запустить `docx-cli.js` снова. Замена рисунка на другой того же размера номера не меняет. В DOCX нет `updateFields`, Word не спрашивает об обновлении полей.
- Заголовки 14 пт полужирные (решение по СТП 2.1.1 и правилу Р3 из `20-report-rules-stp-2024.md`), заголовки ненумерованных частей и приложений по центру. Листинги Courier New 10 пт с висячим отступом для длинных строк, встроенный код в тексте набран Times New Roman 14 пт.

## Титульный лист

Откройте `part-2/pz-01-middleware-ejs/report.meta.json` и впишите `student` (ФИО) и `group` (номер группы), затем выполните `node tools/docx-cli.js part-2/pz-01-middleware-ejs`. Пока поля пустые, на титульном стоят подчёркивания. Ссылка на репозиторий и ветка `pz21` берутся из того же файла. Ветку `pz21` создаёте вы, в ходе T38 она не создавалась и не публиковалась.

## Итоговая сдача: режим final

Когда все снимки настоящие, добавьте в `report.meta.json` строку `"final": true`. Тогда тест отчёта работает в режиме `strict: 'final'` и падает, если в `figures/` остались заглушки (файлы `owner-*.png`, `placeholder-*.png` или PNG с меткой `dslkit-placeholder`, её ставит `markPlaceholder` из `tools/part2/figure-files.js`). Для ПЗ1 заглушек сейчас нет.

## ПЗ1: снимки

Все 15 рисунков ПЗ1 сняты скриптом с настоящего приложения (`node shots/shots.mjs`, затем `node shots/shots.mjs --tests`), интерфейс на русском. Скрипт не может показать адресную строку браузера: если преподаватель потребует видимый URL, снимите заново вручную под теми же именами. Подробный список файлов, адресов и действий: `part-2/pz-01-middleware-ejs/SCREENSHOTS-TODO.md`. Тест `figures` сравнивает хэш `src/`, `views/`, `public/`, `test/`, `limits.json` с записанным в `figures/manifest.json` и падает, если код изменился после съёмки.

## ПЗ2 (`part-2/pz-02-rest-api/figures/`): снимки Postman

Коллекция `postman_collection.json`, сервер `npm start` на порту 3000. Окно Postman целиком: запрос, код ответа, тело ответа.

| Файл                             | Операция                                                                                                                |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `postman-01-get-users.png`       | `GET /api/users`, 200                                                                                                   |
| `postman-02-post-diagram.png`    | `POST /api/diagrams`, тело `{"title":"Billing schema","notation":"ERD","code":"invoice -> payment","projectId":1}`, 201 |
| `postman-03-patch-user.png`      | `PATCH /api/users/1`, тело `{"role":"editor"}`, 200                                                                     |
| `postman-04-post-invalid.png`    | `POST /api/users`, тело `{"name":"","email":"x"}`, 400                                                                  |
| `postman-05-delete-conflict.png` | `DELETE /api/users/1`, 409                                                                                              |

Для ПЗ2 нужны ещё отдельные снимки для `PUT` и `DELETE` с кодом 204 (по одному на тип запроса), отчёт ПЗ2 по этому пункту будет пересобран отдельным шагом. Рисунки 08, 09, 11, 14, 15 и 16 ПЗ2 выше 60 % страницы, проверка высоты рисунка для ПЗ2 временно выключена строкой `"figureHeight": false` в её `report.meta.json`: исполнитель ПЗ2 обрезает снимки по содержимому и удаляет эту строку. Файлы `postman-*.png` пока заглушки без метки: пометьте их через `markPlaceholder` или переименуйте в `owner-*.png`, чтобы режим `final` их ловил.
