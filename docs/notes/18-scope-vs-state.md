# Границы проекта и что из них сделано (на 23 октября 2026)

Источник границ: сводный документ [`../project/PROJECT-OVERVIEW.md`](../project/PROJECT-OVERVIEW.md) (требования, правила владельца, список «Что осталось сделать») и [`../project/TODO.md`](../project/TODO.md). Английская версия: [`18-scope-vs-state.en.md`](18-scope-vs-state.en.md).

Важная граница между двумя целями:
- **Учебная цель (сделано)**: 16 лабораторных, 4 практических и курсовой по ИТиВП, все на теме DSLKit. Сайт в `site/` это HTML, CSS и JavaScript без сборки, в нём живёт редактор.
- **Дипломная цель (не начата как код)**: в документе границ стоят React 19, TypeScript, Vite, Monaco, ядро на C++ в WASM, бэкенд, вход через Google, GitHub и другие, тарифы, совместная работа, Git, интеграции. Защита диплома запланирована на июнь 2027. Этот код пока не писался: макеты и требования готовы, реализация в виде монорепозитория ещё впереди.

Отметки: готово, частично, не начато, решение владельца.

## 1 Продукт

| Требование из границ | Состояние |
| --- | --- |
| Веб-редактор диаграмм «как код», справа сразу диаграмма | готово как прототип: текст DSL, 27 нотаций, четыре движка отрисовки |
| Нотации IDEF0, ERD, BPMN, сети Петри, UML, DFD | готово: все названные плюс IDEF1, IDEF1X, IDEF3, IDEF4, IDEF5, граф, DAG и другие, всего 27 |
| Единый синтаксис DSL (одна грамматика вместо трёх прежних) | частично: единый разбор в `site/js/notations/`, общий заголовок и проверка, грамматика не оформлена как документ |
| Стек React 19, TypeScript, Vite, Monaco, elkjs, C++ в WASM | не начато (на сайте HTML и JS, собственная раскладка вместо elkjs, разбор на JS) |
| Дашборд «Мои проекты», приветственный экран, настройки | готово как экраны прототипа (`site/app/*.html`) |
| Редактор: вкладки, шаблоны, проблемы, строка состояния, хлебные крошки | готово как прототип |
| Холст: Zoom, Fit, перетаскивание с записью `pos` в код, инспектор свойств | частично: масштаб и подгонка есть, перетаскивание блоков (мышь, палец, стрелки) записывает `pos=XxY` в код и работает со «Собственным движком» для нотаций с общей раскладкой, инспектор свойств не сделан |
| Run, автосохранение, отмена и возврат | готово: Run, Undo и Redo, автосохранение кода через 1 секунду с отметкой «Сохранено» и восстановлением при открытии |

| AI-панель, «Fix with AI» | не начато (в макетах есть кнопка) |
| Вход (Email, гость, внешние поставщики), лимиты и тарифы | частично: в интерфейсе показан дневной лимит беты, настоящего входа в прототипе нет (вход реализован в учебных работах Части 2) |
| Совместная работа, Git, версии | не начато |
| PWA и офлайн | готово в коде и проверено тестами: манифест, значки, service worker; в браузере панели приложения регистрация недоступна, проверка в настоящем Chrome остаётся задачей владельца |
| Адаптив и мобильная версия | готово как вёрстка (три ширины, нижняя навигация) |
| Онбординг-тур из 5 шагов | готово: открывается один раз, повторно из меню «Показать тур» |
| Загрузка кода или репозитория и автоматическая диаграмма, Image → DSL | не начато |
