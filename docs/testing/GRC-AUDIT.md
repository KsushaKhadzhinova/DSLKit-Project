Что есть: минимизация (токены и пароли не пишутся в журнал), обезличивание тестовых данных, удаление пользователя администратором, политика конфиденциальности на сайте, защита при хранении (хеш), контроль доступа (статья 32).

Для учебных работ с вымышленными пользователями это допустимо, для дипломного проекта нужно закрыть: срок хранения журнала (рекомендация 30 дней, удаление по расписанию), усечение IP, самостоятельное удаление учётной записи.
