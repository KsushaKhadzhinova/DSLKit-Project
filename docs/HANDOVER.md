# Передача проекта: с чего начать

Документ для того, кто продолжает работу над DSLKit: для самой владелицы через время или для другого человека. Всё главное собрано здесь, подробности лежат по ссылкам. Обновлено 23 октября 2026.

## 1 Что это за проект

DSLKit — веб-редактор диаграмм «как код»: слева текст, справа диаграмма. Проект ведётся на двух уровнях.

- **Учебный.** Сайт Части 1 (HTML, CSS, JavaScript без сборки, лабораторные 1–8), Часть 2 (лабораторные 1–8, практические 1–4, курсовой проект) по дисциплине «Интернет-технологии и веб-программирование», вариант 26 (чётный).
- **Дипломный.** Защита в июне 2027. Как код пока не начат, есть только границы проекта и макеты ([`notes/18-scope-vs-state.md`](notes/18-scope-vs-state.md)).

Подробное состояние по каждой работе: [`PROJECT-STATE.md`](PROJECT-STATE.md) (есть английская версия `.en.md`).

## 2 Правила владелицы (обязательны)

1. В коммитах, документах и коде не должно быть меток ИИ и строк `Co-Authored-By`. Коммиты только от имени владелицы.
2. Документация пишется как для человека и от человека, коротко и по делу.
3. Каждая работа лежит в своей ветке и пушится отдельно. Слияние в `main` только после проверки владелицей и её явного «да».
4. Тесты Части 1 идут с порогом покрытия 100% (строки, ветки, функции). Отчёты на русском и английском собираются из шаблонов командой `node tools/build.js <папка>` и после правки кода пересобираются обязательно.
5. Перед любым необратимым действием (перезапись истории на сервере, удаление веток, отправка в Figma чужих данных) спросить.

## 3 Быстрый старт за пять минут

```bash
git clone https://github.com/KsushaKhadzhinova/DSLKit-Project
cd DSLKit-Project
git checkout work/part1-finish        # Часть 1: сайт и лабораторные 1–8
npm install
npm test                              # 608 тестов, покрытие 100%
npm start                             # сайт на http://localhost:5173
```

Работы Части 2 лежат в своих ветках (`lab21`, `lab12`, `23`, `24`, `25`, `26`, `27`, `28`, `pz21`, `pz22`, `pz23`, `pz24`, `course-project`), таблица в [`PROJECT-STATE.md`](PROJECT-STATE.md). Удобно держать их в отдельных рабочих папках: `git worktree add ../dslkit-lab25 25`.

## 5 Что осталось

### Только владелица

- Скриншоты Postman (ЛР1–ЛР3, ПЗ2) и структуры БД из PostgreSQL; Atlas для ЛР6; образы в Docker Hub для ЛР8.
- Проверка интерфейса в Firefox и Edge; установка PWA в настоящем Chrome (в панели приложения служба не регистрируется).
- React Router 7 в ПЗ3 владелица одобрила (решено, в репозитории остаётся v7). Вопросы преподавателю: экран администратора, остальное в [`study/33-QUESTIONS.md`](study/33-QUESTIONS.md).
- Курсовой в Word: титульный лист, задание, оглавление, 1–2 книги и статьи в списке источников, итоговые скриншоты экранов.
- Решения по курсовому: четвёртая сущность «Комментарий» (условие просит 4–6, сейчас три), React Router в клиенте, экран администратора, облачный деплой.
- Слияние веток в `main` и очистка истории от следов ИИ принудительной отправкой. Без её «да» не делать.

### Можно продолжить без неё

- Пересобрать отчёты ЛР3 в ветках 25 и 28 (там написано «SQLite по умолчанию»).
- Панель свойств блока; экспорт кода PlantUML и Mermaid файлом; диаграмма Ганта и другие виды со своим рисунком.
- Загрузка новых нотаций и кадров функций в Figma (способ описан в разделе 7).
- Собственные шрифты: ждут решения владелицы.
- После её согласия: четвёртая сущность и маршруты в курсовом.

### Диплом

Сначала утвердить тему и объём с научным руководителем. Потом: новый стек (React 19, TypeScript, Vite, Monaco, ядро на C++ в WASM), настоящий бэкенд со входом и тарифами, совместная работа, Git, интеграции, документы (SRS, ADR, лицензия, проверка названия, юзабилити-тест, CI).

## 7 Ловушки и приёмы

- **Обратные слэши.** В командах оболочки и в одном из редакторов `\u…`, `\d`, `\b` теряются или превращаются в символы. Файлы с регулярными выражениями создавать инструментом записи файла, а не командой.
- **Два прогона тестов сразу мешают друг другу** (общие порты и временные базы). Запускать по одному.
- **Тур редактора** открывается при чистом хранилище. Скрипты съёмки должны сначала записать ключ `dslkit.tour-done`.
- **Перетаскивание** работает только с движком «Собственный (в браузере)» и для нотаций с общей раскладкой (BPMN, DAG и подобные).
- **Галереи логотипов** держать вне `site/`: проверки страниц сайта считают каждую HTML-страницу в этой папке.
- **Figma.** Загрузка кадров: открыть файл, нажать Ctrl+Shift+K (появляется поле выбора файлов), передать до 10 МБ файлов за раз, нажать «Place all», выделенное обернуть в автолейаут (Shift+A), режим «Grid» на 4 столбца, зазоры по 40. Нужны установленное расширение Claude in Chrome и вход владелицы в Figma.
- **Сервис Kroki** иногда отвечает ошибками. Макеты Mermaid переснимаются командой из `PROJECT-STATE.md`, раздел 7.
- **Docker Desktop** долго запускается. Порт 5432 на этом компьютере занят PostgreSQL из WSL, поэтому в Compose порт базы берётся из `POSTGRES_PORT` (проверка шла на 55432).
