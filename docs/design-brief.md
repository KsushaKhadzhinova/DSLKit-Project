# Дизайн-бриф DSLKit

Дата: 2026-10-13. Решения владельца проекта, на которые опираются макеты и вёрстка.

## Ориентиры стиля

Берём принципы, а не бренды: логотипы, шрифты, фотографии и тексты чужих сайтов не копируем.

| Ориентир           | Что берём                                                                                                                                                                                                                                                |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Продуктовый сайт с тёплой светлой базой | Тёплая светлая база, крупные спокойные заголовки, много воздуха, сдержанный акцент, мягкие карточки                                                                                                                                                      |
| Innowise           | Чёткая последовательность секций: hero с одним главным действием, плитки направлений, блоки возможностей с короткими ссылками, счётчики и цифры, полоса призыва к действию, короткие действенные подписи кнопок («Записаться в бету», «Смотреть пример») |

| mermaid.js.org | Герой с кнопкой «Попробовать редактор» (живой редактор как главное действие), демо-диаграмма в светлой и тёмной версии, три короткие карточки преимуществ, минимум секций |
| drawio.com | Основная и вторичная кнопки, строка под ними («бесплатно, без регистрации»), ряд цифр-доказательств, сетка из шести карточек «польза в заголовке», блок «работает там, где вы работаете» (VS Code, GitHub), блок для разработчиков с примером кода, финальный призыв, подвал |
| Сайт с декларативными заголовками | Спокойные декларативные заголовки, единообразные текстовые карточки, ненавязчивые текстовые ссылки вместо кричащих кнопок |
| Страница загрузки продукта | Короткие действенные подписи («Скачать», «Установить»), карточки по платформам, FAQ в конце |
| app.diagrams.net и приложения с полем ввода по центру | Интерфейс приложения (панель фигур, холст, панель свойств; чистое поле ввода по центру). Страницы динамические и за логином, текстом не прочитаны: смотреть в браузере при проектировании экрана редактора |

Правила применения:

- Из draw.io берём структуру и карточки возможностей, но не подачу «против конкурентов» (решение владельца: без сравнений).
- Цифры только честные: шесть нотаций, три в бете, форматы экспорта. Выдуманных пользователей, отзывов и цен нет.
- Цвета и шрифты Innowise ещё не сняты: из текста страницы они не видны. Если понадобятся, смотреть страницу в браузере.

## Решения по главной странице

- Показывать возможности и сильные стороны продукта, без сравнения с конкурентами.
- Нужны визуальные примеры нотаций и живой пример продукта (код DSL и диаграмма рядом).
- Порядок нотаций: UML, BPMN, ERD, DFD, IDEF0, сети Петри. Доступные в бете (ERD, DFD, IDEF0) помечаются значком «в бете».
- Интерфейс делаем сначала на русском, английская версия после.
- Первая тема светлая, тёмная вторая. Мобильная и десктопная версии обязательны, шапка закреплена.
- Домен сайта: `dslkit.io` (пока не куплен).
