## Как проверено

Каждая диаграмма строится из одной модели и проверяется программой (`src`):

- IDEF0: один блок в A-0, от 3 до 6 блоков в A0, управление и выход у каждого блока, ступенька блоков, стороны подхода стрелок, совпадение 14 граничных стрелок A0 с A-0 по кодам ICOM;
- BPMN: правила методички для диаграмм «для людей» (типы задач, шлюзы XOR и AND, подписи выходов, потоки сообщений не у шлюзов, старт без входа, конец без выхода);
- EPC: 11 правил методички (чередование, операторы, число функций, связи);
- ССП: не более 25 целей, 1–3 показателя на цель, около 80 % нефинансовых, направление причинно-следственных связей;
- вёрстка: наложение подписей, выход текста за фигуру, пересечение подписи со стрелкой, наклонные отрезки.

Файлы `.drawio` открыты в просмотрщике draw.io для проверки отображения нативных фигур BPMN и EPC. Линтер report-gen: 0 ошибок и 0 предупреждений для всех четырёх отчётов.

## Допущения и открытые вопросы

1. Целевые значения ССП (кроме SUS 82+ и покрытия тестов) – учебные допущения; базовые значения взяты из документов проекта, где они есть, остальное «не измерено».
2. Цена Pro в документах проекта расходится (40 и 48 USD), поэтому в отчёте цена не указана.
3. Задачи, которые выполняет система, в BPMN показаны без маркера типа: методичка допускает для людей только пользовательские и ручные задачи.
4. Состав подразделений (оргструктура) придуман для лабораторной и не подтверждён владельцем; команда проекта – один человек.
5. Рисунки к заданиям 1 и 2 ЛР4 (цели и карта из методички) не просмотрены: PDF с рисунками не скачан без разрешения владельца.
6. Размер шрифта на широких диаграммах в печатном PDF мелкий; в электронном виде масштабируется.
7. Номер группы на титуле не указан (в шаблоне нет поля).

## Как пересобрать

```bash
cd src
python lab1.py && python lab2.py && python lab3.py && python lab4.py
python make_reports.py
python merge_project.py
```

Отчёты собираются инструментом report-gen (проекты `E:\report-gen\projects\mbp-lr1` … `mbp-lr4`). Без Docker: `cd E:\report-gen`, `set PYTHONPATH=E:\report-gen\src`, `python -m reportgen build projects/mbp-lr1`, затем `lint`. Тексты ЛР1 и ЛР2 правятся прямо в `content`, тексты ЛР3 и ЛР4 порождает `src/make_reports.py` (таблицы ЛР4 берутся из `src/bsc_data.py`).
