## How it was checked

Every diagram is built from one model and checked by a program (`src`):

- IDEF0: one block in A-0, 3 to 6 blocks in A0, control and output on every block, stair-step layout, arrow sides, the 14 boundary arrows of A0 match A-0 by ICOM codes;
- BPMN: the handbook rules for diagrams "for people" (task types, XOR and AND gateways only, labelled outgoing flows, message flows not at gateways, start without incoming flow, end without outgoing flow);
- EPC: the 11 handbook rules (alternation, operators, number of functions, links);
- scorecard: at most 25 goals, 1–3 indicators per goal, about 80 % non-financial, direction of cause-and-effect links;
- layout: overlapping labels, text outside a shape, label crossing an arrow, slanted arrow segments.

The `.drawio` files were opened in the draw.io viewer to confirm that the native BPMN and EPC shapes render. The report-gen linter reports 0 errors and 0 warnings for all four reports.

## Assumptions and open questions

1. Scorecard targets (except SUS 82+ and test coverage) are study assumptions; baselines come from the project documents where they exist, otherwise "not measured".
2. The Pro price differs between project documents (40 and 48 USD), so the report does not state a price.
3. Tasks performed by the system are shown without a type marker in BPMN: the handbook allows only user and manual tasks for diagrams read by people.
4. The org structure is invented for the lab and not confirmed by the owner; the project team is one person.
5. The figures for tasks 1 and 2 of lab 4 (goals and map from the handbook) were not viewed: the PDF with figures was not downloaded without the owner's permission.
6. Font size on wide diagrams is small in the printed PDF; it scales in the electronic version.
7. The group number is not on the title page (the template has no such field).

## How to rebuild

```bash
cd src
python lab1.py && python lab2.py && python lab3.py && python lab4.py
python make_reports.py
python merge_project.py
```

Reports are built with report-gen (projects `E:\report-gen\projects\mbp-lr1` … `mbp-lr4`). Without Docker: `cd E:\report-gen`, `set PYTHONPATH=E:\report-gen\src`, `python -m reportgen build projects/mbp-lr1`, then `lint`. Texts of labs 1 and 2 are edited directly in `content`; texts of labs 3 and 4 are generated by `src/make_reports.py` (lab 4 tables come from `src/bsc_data.py`).
