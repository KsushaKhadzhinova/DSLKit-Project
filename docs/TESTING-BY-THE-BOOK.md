## 3 Чек-лист по свойствам из книги (раздел 2.4)

Порядок идей: простое позитивное, затем негативное, затем сложное. Ожидаемые результаты в чек-листе необязательны.

Форма записи в бету:

1. Верные данные сохраняют заявку и открывают страницу благодарности: пройдено.
2. Пустая отправка показывает 4 ошибки и ставит фокус на первое поле: пройдено.
3. Ошибка появляется при уходе с поля, исчезает при исправлении: пройдено.
4. Повторная отправка не создаёт вторую заявку: пройдено.
5. Данные не попадают в адресную строку: пройдено.
6. Ошибки озвучиваются программой чтения: исправлено (`role="alert"`).

Редактор и движки: запуск для каждого движка, повтор из кэша, обновление без кэша, офлайн, таймаут, отмена старого запроса, очистка SVG от скриптов, ссылок и чужих пространств имён: пройдено, кроме Mermaid через публичный Kroki (см. BUG-10).

Совместимость: Chrome проверен, Firefox и Edge не проверены. Локализация: русский и английский лендинг проверены, экраны приложения только русские.

Пример полного отчёта (BUG-02). Шаги: открыть редактор, переключить автосохранение, открыть настройки, изменить любую настройку. Ожидаемо: автосохранение осталось включённым. Фактически: значение `autosave` исчезало из хранилища, потому что настройки записывали устаревший снимок. Воспроизводимость: всегда. Обход: нет. Первопричина: два компонента владеют одним ключом и один читает значение один раз при запуске. Предотвращение: чтение перед каждой записью и тест на чужую запись между двумя изменениями.

## 5 Виды тестирования

- Дымовое: после каждой правки `npm test` и открытие лендинга и редактора.
- Регрессионное: 394 теста корня и 54 теста React запускаются перед каждым коммитом.
- Удобство: прокликивание, проверка на 320, 375, 768 и 1280 px, Lighthouse по доступности.
- Совместимость: только Chrome, остальное в списке открытых задач.
- Производительность: Lighthouse и трассировка (LCP 165 мс, CLS 0).
