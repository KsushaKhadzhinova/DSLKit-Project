## Находки
a-calm
- Серьёзное: на 375 px редактор имеет горизонтальный overflow (metrics: horizontalOverflow=true), кнопка «Исправить» обрезана справа (скриншот editor-mobile.png; editor.html:105, style.css .code__note).
- Серьёзное: нет prefers-reduced-motion вообще, при этом transform-анимации карточек и шеврона (style.css:187, 314, 394, 414).
- Серьёзное: кольцо фокуса в блоке кода 2,71 в светлой теме (style.css:167).
- Малое: nav с radio вместо tablist (editor.html:166-169); пункт темы без состояния (editor.html:89); заглушки href="#" (editor.html:51-55).
- Плюс: details-меню с Esc и возвратом фокуса, role=switch, aria-current, подпись ошибок текстом «Ошибка:» плюс иконка плюс волнистая линия.

b-command
- Серьёзное: role=tablist/tab с tabindex=-1 у rules.dsl и invoice.dsl, без стрелочной навигации в JS: вкладки недостижимы с клавиатуры (editor.html:82-85).
- Малое: tabpanel без aria-labelledby (editor.html:88); однобуквенные хоткеи D/S на карточке (dashboard.html:74-75, 322; 2.1.4 частично закрыто областью карточки); квота показана дважды на дашборде (dashboard.html:37, 43).
- Плюс: единственная работа с prefers-reduced-motion (style.css:344), нативный dialog для палитры (фокус-ловушка, Esc), aria-pressed в сегментах, aria-keyshortcuts, role=status, quick-кнопки видны при focus-within.

c-canvas
- Серьёзное: на мобильном закрытая панель кода сдвинута transform, но остаётся в порядке Tab (style.css:239, editor.html:51): фокус уходит на невидимое.
- Серьёзное: ошибки в коде показаны только цветом, фоном и волнистой линией, текст ошибки есть лишь в свёрнутом списке (editor.html:55, 58, 147-171), 3.3.1 выполнено слабо.
- Серьёзное: кольцо фокуса в коде 2,71 в светлой теме (style.css:246).
- Малое: панель кода в DOM раньше header (editor.html:40 против 65); подсказки data-tip на CSS без закрытия по Esc (style.css:166); reduced-motion только для панели (style.css:353).
- Плюс: aria-expanded/aria-controls на меню и панели, aria-disabled с причиной на «Запустить».

d-guided
- Серьёзное: role=tablist с tabindex=-1 и без JS, rules.dsl недостижим (editor.html:98-100).
- Серьёзное: кольцо фокуса в коде 2,71 в светлой теме (style.css:151).
- Серьёзное: нет prefers-reduced-motion (style.css:350 transition шеврона).
- Малое: h1 внутри nav (editor.html:18); четыре radio opacity:0 стоят в Tab до header (editor.html:12-15, style.css:180); ссылки навигации дашборда ведут на одни и те же страницы (dashboard.html:28-30); details-меню без закрытия по Esc и клику вне (скриптов нет).
- Плюс: aria-current=step, aria-disabled с описанием, заголовки h1-h2-h3 по порядку, пошаговый цикл с текстом, ошибки текстом плюс иконка.

Общее для всех: lang="ru", landmarks (header, nav, main, footer), skip-link, aria-label у всех иконок-кнопок (unnamedControls=0), цели не меньше 44 px (targetsBelow44=0), текст не меньше 14 px, rem-размеры, role=img с title/desc у диаграммы, progress с подписью. Масштаб 200% и горизонтальная прокрутка на 375 px проверены только скриптом, кроме a-calm editor (там overflow).
