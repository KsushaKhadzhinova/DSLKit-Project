# b-command: «Команды вперёд»
**Идея.** Стиль и компоненты Части 1 (токены, логотип, тёмный блок кода, чипы, карточки с сеткой превью, поле поиска) без изменений. Вторичное убрано за Ctrl+K: поиск и палитра команд в шапке (`<dialog>`, фильтрация), меню «⋯», строка состояния. Режимы «Код / Разделить / Холст» — один переключатель (на телефоне нижняя навигация Код / Холст / Команды).
**Убрано и куда переехало (редактор).** Панель действий, сайдбар «Проводник/Шаблоны», вкладки Проблемы/AI/Вывод/Версии, тулбар холста, переключатель автосохранения, аватар. Undo/redo, форматирование, поделиться, сохранить, автораскладка, обновить, движок Kroki/локально, история запусков, настройки, тема, шаблоны, файлы: палитра Ctrl+K; часть — в «⋯». Файлы: вкладки над кодом. Квота 3 из 5, статус сервиса, движок, автосохранение, позиция курсора: нижняя строка (текст, не кнопки).
**Ошибки.** Строка в коде подсвечена (полоса, волнистая линия, красный фон), под ней встроенная подсказка с кнопкой «Исправить». Сводка «2 ошибки · 1 предупреждение» одна, под кодом. Слово «ошибка» ещё только в подписях подсказок (тип, не счёт).
**Дашборд.** Поле-палитра (Ctrl+K ищет диаграммы и команды), чипы-фильтры, сортировка, карточки; при наведении/фокусе (на касаниях всегда) «Дублировать» и «Поделиться», «⋯» всегда; клавиши D, S, Enter на карточке.
**Метрики (metrics.mjs, десктоп/планшет/мобильный).** Видимых элементов 16/16/13 (было 42). В шапке редактора 7/7/4 (логотип, палитра, 3 режима, «Запустить», «⋯»). Стилей кнопок 4 (главная, вторая, тихая, активная). Главная кнопка 1. Целей < 44 px: 0. Текст < 14 px: 0 (минимум 15 px). Горизонтального скролла нет. Дашборд: 1 главная, целей < 44 px: 0.
**WCAG.** Цели ≥ 3rem, текст ≥ 1rem (токен step-0), контраст токенами Части 1 (AA), фокус-кольцо из base.css (на коде светлое), `lang="ru"`, один h1, скип-ссылка, aria-label у иконок, ошибки = иконка + слово + волна, не только цвет; фильтры aria-pressed.
**Золотое сечение.** Колонки код:диаграмма `--columns-golden` (1:1,618) от 768 px; шкала шрифтов и отступы из токенов; rem от плавного корня; только min-width 576/768/1024.
