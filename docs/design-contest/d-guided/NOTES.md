# d-guided: «Управляемый процесс»
**Идея.** Редактор ведёт по циклу «Написать, Проверить, Нарисовать, Сохранить»: одна строка из 4 шагов в шапке, текущий шаг выделен (рамка и заливка secondary), недоступные шаги пунктирные с aria-disabled и подсказкой почему. Единственная кнопка заливкой синим — «Исправить» в сводной плашке (в этом состоянии это следующее действие). Когда ошибок нет, заливку получает кнопка текущего шага («Нарисовать», затем «Сохранить»).
**Узнаваемость Части 1.** Те же токены (variables.css скопирован без изменений), логотип, тёмный блок кода с нумерацией, моноширинные вкладки файлов, карточки с сеткой превью, чипы-пилюли, бейдж «в бете», кнопка меню «⋯» на превью карточки, левая навигация с синей меткой.
**Что убрано и куда переехало.**
- Запуск/Проверить/Сохранить, 3 «главные» кнопки: стали шагами цикла.
- Undo/redo: в полосе вкладок файлов над кодом. Автораскладка, форматирование, движок Kroki/Локально, автосохранение, новый файл, палитра: меню «⋯».
- Activity bar, проводник, шаблоны, аватар, тема, ветка: убраны с экрана редактора (файлы: вкладки, шаблоны: дашборд).
- Список проблем, история запусков и диаграмма: вкладки правой панели «Диаграмма / Проблемы / История». Зум: три иконки на холсте.
- Квота беты 3 из 5, статус Kroki и автосохранение: нижняя строка состояния.
- Число ошибок: один раз в плашке («2 ошибки, 1 предупреждение»), в самом коде: подсветка строк и пометка с иконкой.
- Дашборд: приветствие + главное действие «Новая диаграмма», 3 недавних проекта; фильтры, сортировка и остальные карточки на втором уровне («Другие проекты», раскрывающийся блок). Меню карточки: Открыть, Переименовать, Дублировать, Поделиться, В корзину.
**Измерено (metrics.mjs, editor.html, десктоп/планшет/мобильный).** Видимых интерактивных элементов 16/16/13, в шапке 7, стилей кнопок 5 (основная, вторичная, иконка, шаг, текущий шаг), целей меньше 44 px 0, текст мельче 14 px 0 (минимум 15 px), основных кнопок 1, горизонтальной прокрутки нет.
**WCAG.** Цели не меньше 3rem, текст не меньше step-0 (15 px+), токены с проверенным контрастом, фокус-кольцо --focus-ring, lang="ru", h1 один, смысл ошибок не только цветом (иконка + слово «Ошибка»/«Предупреждение»), aria-label и title у иконок, skip-link, переключение вкладок без JS на radio.
**Золотое сечение.** Десктоп: код:диаграмма = var(--columns-golden) (1fr 1,618fr); планшет: те же пропорции по вертикали (1fr 1,618fr); шкала шрифтов и отступы только из токенов; mobile-first, запросы min-width 576/768/1024, один столбец на мобильном (вкладки Код/Диаграмма/Проблемы/История, шаги внизу).
