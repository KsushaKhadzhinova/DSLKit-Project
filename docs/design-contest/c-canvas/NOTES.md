# c-canvas: «Холст прежде всего»

**Идея.** Диаграмма занимает весь экран, инструменты плавают поверх неё компактными группами; код открывается боковой панелью 1:1,618 (кнопка «Код» / крестик) и на телефоне становится выдвижной нижней панелью. Стиль Части 1 сохранён: токены, логотип, белые кнопки с рамкой и радиусом 8, чипы-пилюли, тёмный блок кода, карточки с сеткой превью.
**Что убрано и куда переехало.** Проводник, шаблоны, вкладки проблем (AI, Вывод, Версии), баннер ошибок, три статуса ошибок, переключатель автосохранения, аватар: файлы в меню у имени файла, Поделиться, Сохранить, автосохранение, движок Kroki/локально, тема и настройки в «⋯»; undo/redo, автораскладка, форматирование, история запусков в левой вертикальной панели; зум справа снизу; квота 3 из 5, сервис и движок в нижней строке состояния. «Проверить» и «Нарисовать через Kroki» слились в одну главную «Запустить».
**Ошибки.** Один индикатор «2 ошибки, 1 предупр.» (раскрывается во всплывающую панель) и подсветка строк в коде.
**Дашборд.** Верхняя строка: логотип, поиск, «Новая диаграмма» (главная), профиль. Один ряд: чипы нотаций и сортировка. Крупные карточки с превью по нотации, меню «⋯». Боковая навигация на десктопе, нижняя на планшете и мобильном.
**Числа (metrics.mjs).** Редактор десктоп: видимых элементов 18, в шапке 5, стилей кнопок 4, целей <44 px 0, текст <14 px 0 (мин. 17 px), главная кнопка 1, горизонтального скролла нет на трёх размерах. Планшет и мобильный: 18 и 17 элементов, в шапке 5 и 4. Дашборд: 20, 22, 17 элементов, в шапке 4, стилей 4.
**WCAG.** Цели не меньше 3rem, текст не меньше 1rem, токены AA, фокус-кольцо 3 px, `lang="ru"`, один h1 и h2 по порядку, ошибки: иконка, слово и волнистое подчёркивание (не только цвет), `aria-label` и подсказки `data-tip` у иконок.
**Золотое сечение.** `--columns-golden` для код:диаграмма, шкала шрифтов и отступы из токенов, превью карточек `aspect-ratio: var(--phi)`. Размеры в rem, медиазапросы только min-width 576/768/1024, JS только для меню и переключения панели кода.
