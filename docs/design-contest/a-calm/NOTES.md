# Вариант A «Спокойный фокус»
Идея: экран Части 1 (логотип, токены, тёмный код, точечная бумага холста, пилюли-чипы, карточки с сеткой) без перегруза: одна главная кнопка, остальное по запросу.
Редактор: шапка = логотип, файл (меню файлов и шаблонов, рядом статус «Сохранено»), отменить, повторить, поделиться, «Запустить», «⋯». Всего 7.
Переехало в «⋯»: проверить, форматировать, автораскладка, движок Kroki/локально, история запусков, автосохранение, тема, настройки, команды. Убраны: панель активности, дерево файлов (теперь в меню файла), вкладки, 4 вкладки панели проблем, кнопки «Нарисовать»/«Обновить», баннер ошибок, дубль счётчика в статусе.
Ошибки: один раз в самом коде (красная строка, волнистое подчёркивание, пояснение под строкой, «Исправить») и один раз сводкой одной строкой «2 ошибки и 1 предупреждение», список раскрывается по клику.
Диаграмма: зум плавающей группой из 3 кнопок, подпись «последняя удачная отрисовка». Строка состояния: тип, позиция курсора, сервис Kroki, квота беты 3 из 5.
Дашборд: верхняя панель (поиск, «Новая диаграмма», профиль), боковая навигация и квота как в Части 1, чипы одной строкой, карточки с меню по «⋯» (Открыть, Переименовать, Дублировать, Поделиться, В корзину). Активный чип не залит синим: заливка только у «Новая диаграмма».
Измерено metrics.mjs (editor.html, десктоп / планшет / мобильный):
- видимых интерактивных элементов 13 / 13 / 7 (было 42); в шапке 7 / 7 / 4 (было 11);
- стилей кнопок 3 (было 16): главная, тихая, «Исправить»; главных кнопок 1;
- целей меньше 44 px: 0 / 0 / 0; текстов мельче 14 px: 0, минимум 15 px; горизонтальной прокрутки нет.
Золотое сечение: колонки код:диаграмма = 1fr 1.618fr (var(--columns-golden)); на планшете те же пропорции по вертикали; шрифты и отступы из токенов.
WCAG: цели 3rem, текст от 1rem, фокус-кольцо 3 px, цвета только токены (светлая и тёмная), смысл дублируется значком и текстом (ошибка = красный значок + подчёркивание + текст), lang=ru, h1, skip-link, подписи aria-label и title у иконок.
Мобильный: mobile-first, только min-width (576/768/1024), нижняя навигация «Код / Диаграмма» без JS (radio + :has), меню «⋯» содержит отмену, повтор, «Поделиться».
JS: только закрытие меню, переключатель темы, фильтр чипов. Примечание: shoot.mjs в корне конкурса не запускается (потерян обратный слэш в регулярке); скриншоты сняты его исправленной копией.
