| Знак                                                                      | Файл                                             | Где используется                                                           |

Цвета взяты из палитры сайта: синий `#2563eb`, зелёный `#16a34a`, янтарный `#d97706`, красный `#dc2626`, светло-синий `#e8efff`, текст `#1c1f2e`. Курсор белый с контуром цвета текста, поэтому читается на светлой и тёмной темах. Скриншоты в шапке и редакторе: [`final/header-light.png`](final/header-light.png), [`final/header-dark.png`](final/header-dark.png), [`final/editor.png`](final/editor.png).

## Все наборы вариантов

`set-1` … `set-10`: галереи (`index.html`) с версиями светлой, тёмной, одноцветной, размерами 16/32/48 и иконкой приложения. Скриншоты лежат рядом с папкой: `../logo-options*.png`. Галерея набора снимается командой `node docs/design-contest/shoot-logos.mjs <номер набора> <файл.png>`.

| Набор | Идея                                                     |
| ----- | -------------------------------------------------------- |
| 1–2   | первые варианты: скобки, узлы, чертёжный стиль           |
| 3     | крупные сплошные знаки                                   |
| 4–5   | по брифу владелицы: DSL, K, автоматизация                |
| 6–7   | личные знаки на K, блок и стрелка                        |
| 8     | развитие улыбки и блока со стрелкой                      |
| 9     | принципиально разные силуэты (муравей, колба, вертушка…) |
| 10    | цвета палитры сайта; отсюда выбраны два знака            |

Скрипты, которые рисуют наборы, лежат в [`generators/`](generators) (запускать node, пути вывода внутри скриптов жёстко заданы под `site/images` и `docs/design-contest/logos`, при необходимости поправить). Знаки легко перерисовать по SVG в `final/`. PNG-значки PWA пересобираются командой `node tools/make-icons.mjs` после смены `site/images/logo.svg`.

Запоминающиеся ответы владелицы для будущих правок: ей важны чистота, личное, лёгкая улыбка, блок и стрелка, правка в обе стороны (код и холст); не нравятся «ИИшные» искры и градиенты и перегруженные круглые эмблемы.
