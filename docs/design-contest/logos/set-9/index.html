Логотипы DSLKit, вариант 9: разные силуэты

Восемь знаков с принципиально разными силуэтами: муравей, колба, вертушка, лестница, круг, закладка, ячейка, ленты. Полоса вверху: те же знаки чёрным и размытыми, как издалека. Если силуэты различимы, значит, знак не спутать с соседями.

Силуэты издалека

Все знаки чёрным, размытие как с большого расстояния
