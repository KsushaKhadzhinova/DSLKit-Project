# Набор логотипа: четыре вертушки (палитра «чернила и коралл»)

Папки: `pinwheel`, `pinwheel-arrows`, `pinwheel-drag`, `pinwheel-tile`. В каждой:

| Файл | Назначение |
|---|---|
| `mark-light.svg`, `mark-dark.svg` | знак на светлом и тёмном фоне |
| `mark-mono-black.svg`, `mark-mono-white.svg` | одноцветные: печать, штамп, вышивка |
| `lockup-horizontal-{light,dark,mono-black,mono-white}.svg` | знак + DSLKit для шапки |
| `lockup-horizontal-{light,dark}@2x.png` | то же растром 544×128 |
| `favicon.svg`, `favicon-{16,32,48,180,512}.png`, `favicon.ico` | упрощённый знак (без пунктира и центральной точки) |
| `../contact-sheet.png` | все версии рядом, включая 16 px |

Пересборка: `LAB7_DIR=<папка с puppeteer-core> node make-final.mjs`.

## Цвета

| Роль | HEX | RGB |
|---|---|---|
| Чернила | #14161F | 20, 22, 31 |
| Коралл | #FF5A36 | 255, 90, 54 |
| Тёмный фон | #0F172A | 15, 23, 42 |
| Светлый знак на тёмном | #F3F4F8 | 243, 244, 248 |

CMYK и Pantone не заданы: подобрать при печати по пробному оттиску.

Контраст (WCAG): чернила на белом 18,0:1, коралл на белом 3,1:1 (достаточно для крупной графики, не для мелкого текста), коралл на чернилах и на тёмном фоне 5,8:1, светлый знак на тёмном 16,2:1.

## Правила

- Минимальный размер знака 16 px (используйте favicon-версию), lockup не меньше 100 px по ширине.
- Свободное поле вокруг знака: не меньше четверти его высоты.
- Нельзя растягивать, наклонять, добавлять тени и градиенты.
- Слово DSLKit в lockup набрано системным шрифтом (Inter, Segoe UI, Arial) и не переведено в кривые: для печати нужно превратить текст в контуры в векторном редакторе.

## Известные ограничения

- В одноцветных версиях акцентный блок сливается с основным цветом. Для «перетаскивания» помогает пунктирный след, у остальных различие только по форме.
- Пунктирный след в `pinwheel-drag` на 16 px пропадает, поэтому в favicon его нет.
- Товарные знаки и reverse image search не проверялись.
