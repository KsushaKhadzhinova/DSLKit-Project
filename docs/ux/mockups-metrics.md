# Метрики UX по макетам DSLKit

Дата: 2026-10-13. Объект: макеты из `docs/project/figma-svg/` (генератор `generate.py`). Разметка сайта (HTML) здесь не оценивается.

Метод: каждый SVG отрисован в Chrome, размеры и цвета сняты скриптом [`method/mockmetrics.mjs`](method/mockmetrics.mjs) (реальные размеры элементов, цвет фона под текстом, контраст по WCAG 2.2). Это расчёт по геометрии макета, а не тест с пользователями.

## Главные выводы по макетам

1. **Мелкий текст.** Кегль 9–11 px встречается в 35–59% текстовых элементов на десктопе и планшете. Минимум для читаемости 12 px, для мобильных 14 px.
2. **Цели касания.** Наименьшая сторона интерактивных элементов 18–20 px на десктопе и планшете; на планшете это ниже нормы касания (24 px по WCAG 2.2, рекомендуется 44 px).
3. **Контраст.** Три реальных пары ниже нормы (список выше); решается сменой цвета текста на `#1d4ed8` и заливки Run на `#15803d`.
4. **Сетка.** Заявленные 8 px и золотое сечение не выдержаны: 12–39% геометрии кратно 8 px. Холст IDE 754 px, код 466 px: отношение 1.62, это золотое сечение внутри рабочей области (достоинство макета).
5. **Покрытие.** Нет тёмной темы для планшета, настроек и welcome. Состояния ошибки, загрузки и пустого экрана на всех экранах не проверялись отдельно.

## Ограничения

- Скрипт не учитывает прозрачность (`opacity`, `fill-opacity`) и градиенты. Формальные цифры на полупрозрачных подложках не использовались.
- Размеры целей оценены по скруглённым прямоугольникам, содержащим текст или иконку; реальные области нажатия в будущей вёрстке могут быть больше.
- Оценки основаны на статических макетах. Реальное время задач и SUS даёт только тест с пользователями (5–8 человек).
