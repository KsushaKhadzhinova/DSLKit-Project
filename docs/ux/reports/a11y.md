## 2. Нарушения и риски (file:line, исправление)

### Критичные и высокие

**A1. Переключатели меню и темы: checkbox + label (index.html:24-28, 40-41; то же в en).**
Если CSS скроет чекбокс через `display:none` или `visibility:hidden`, он выпадет из Tab-порядка, и меню и тему нельзя открыть с клавиатуры (SC 2.1.1). Сам `label` фокус не получает.
- У бургера нет `aria-expanded` и `aria-controls`: скринридер говорит «флажок», не связывая его с навигацией (SC 4.1.2).
- Тема как чекбокс: нужны `role="switch"`, видимое состояние и фокус-кольцо на `label` через `input:focus-visible + label`.
- Исправление: скрывать input так, чтобы он оставался фокусируемым (`position:absolute; opacity:0; 24x24px`), а не `display:none`. Для бургера лучше `<button aria-expanded aria-controls="nav">` с мини-JS в js/script.js (сейчас 62 байта), CSS-чекбокс оставить как no-JS fallback. Тему хранить в `localStorage` с учётом `prefers-color-scheme`.

**A2. Ошибки формы не связаны с полями и не объявляются (index.html:257, 265, 283, 301, 312).**
Абзацы `form__error` с `hidden` не входят в `aria-describedby` (254, 263, 298 ссылаются только на подсказки). У `notation` и `consent` `aria-describedby` нет вовсе. При показе ошибки скринридер её не озвучит, `aria-invalid` не ставится (SC 3.3.1, 4.1.3, 1.3.1).
- Исправление: `aria-describedby="name-hint name-error"`, у блока ошибки `role="alert"`, JS переключает `hidden` и `aria-invalid="true"`. Добавить сводку ошибок со ссылками на поля и перенос фокуса на первое невалидное поле. Пока JS пуст, работает только нативная валидация браузера, собственные тексты не появятся.

**A3. Форма уходит GET-ом на `#waitlist` (index.html:239).**
Имя и почта попадут в URL и историю (приватность). Успешная отправка не объявляется. Исправление: `method="post"` с реальным action либо сообщение об успехе с `role="status"` (SC 4.1.3).

**A4. Фокус и размер целей зависят от ещё не написанного CSS (SC 2.4.7, 2.4.11, 2.4.13, 2.5.8).**
Дизайн должен гарантировать:
- `:focus-visible` с контуром не менее 2px и контрастом 3:1, без `outline:none`.
- Нативный чекбокс (310) и инлайн-ссылки футера (322-326) доводить до 24x24 CSS px (чекбокс лучше до 44px вместе с label).
- Если шапка будет `position:sticky`, нужен `scroll-padding-top` и проверка, что фокус не перекрыт (SC 2.4.11). Иначе якоря `#notations` и др. уезжают под шапку.
- Skip-link должен показываться при фокусе и не перекрываться шапкой.

### Средние

**A5. Битая ссылка (index.html:325).** `errors/500.html` ведёт в пустую папку `site/errors/`. Создать страницу или убрать ссылку до Lab 4.

**A6. Паттерн имени отвергает валидные имена (index.html:252, en аналогично).** `[A-Za-zА-Яа-яЁё' \-]` не пропустит «José», «Zoë», «Müller». Ложные ошибки вредят инклюзивности (SC 3.3.1). Исправление: `pattern="[\p{L}' \-]{2,60}"` (современные браузеры применяют флаг `v`) и обновить подсказку.

**A7. `select` с первым `option disabled selected` (index.html:275).** Допустимо, но часть скринридеров пропускает начальное значение. Лучше `value=""` без `disabled`, при `required`.

**A8. Поле `team` по умолчанию `0` (index.html:297).** 0 уже валидно, поле можно пропустить, не заметив. Допустимо по смыслу (0 = один), ошибку и подсказку нужно связать с полем (см. A2).

**A9. Контраст в палитре (palette.png).**
- Светлая тема: `--color-accent #16a34a` 3.1:1 к белому. Белый текст на зелёной кнопке не пройдёт 4.5:1 (SC 1.4.3). Взять `#15803d` (около 5:1).
- `--color-warning #d97706` 3.0:1: нельзя использовать как цвет текста.
- `--color-border #dde1e9` 1.2:1 и тёмный `#313244` 1.3:1: границы полей и чекбоксов не проходят SC 1.4.11 (нужно 3:1). Нужен отдельный токен границы контрола, например около `#767f94` (светлая) и `#6c7086` (тёмная).
- Тёмная тема: `--color-primary #2563eb` 3.2:1 к фону. Годится как заливка с белым текстом, но не как цвет текста. Ссылки там отдельным токеном (7.6:1), это хорошо.
- Остальные пары проходят (text 15.5, text-light 7.6, muted 4.6, link 6.4, error 4.6; тёмные 11.3, 7.4, 5.1, 7.6, 7.1).

### Низкие
- A10. Кнопка темы: текст «Тёмная тема» не отражает текущее состояние (нужен switch или смена подписи).
- A11. Микроданные в `p`/`section` (47-66, 203-233) и `itemprop` на `summary` (206) нарушений не создают, замечено только для сведения.
- A12. EN-страница: `title` и `description` переведены, `lang` стоит. Замечаний нет.

## 4. IDE-макет (docs/project/mockups/dslkit-mockup-v2.html)
Прототип, но он задаёт требования к реализации.

- M1. Кнопки-иконки без доступного имени, только `title` (583, 816, 881, 886, 891, 899, 902, 914, 969-976, 1105). `title` не работает на касание. Исправление: `aria-label` и `aria-hidden` у SVG (SC 4.1.2).
- M2. Поля без `label`, только placeholder (754, 758, 861, 1104). SC 1.3.1, 3.3.2.
- M3. `outline:none` на `input`/`select` (56) и `.ai-input` (428). Фокус виден лишь по смене цвета рамки 1px (57, 430). Исправление: `:focus-visible` с контуром 2px (SC 2.4.7, 2.4.13).
- M4. Контраст в тёмной теме: `--tx-3 #3b4261` на `#1a1b26` около 1.7:1 (время событий и подсказки почти не видны на скриншоте). `--tx-2 #7982a9` на `#1f2335` около 4.1:1, ниже 4.5:1 (SC 1.4.3). Поднять `--tx-3` и `--tx-2` до 4.5:1.
- M5. Текст 9-11px (280, 387, 436, 1045-1168). Строгого нарушения нет, читаемость плохая. Минимум 12px для вторичного, 14px для основного.
- M6. Модальное окно (1328-1336): нет `role="dialog"`, `aria-modal`, `aria-labelledby`, перехвата фокуса, закрытия по Esc, возврата фокуса (SC 2.1.2, 2.4.3, 4.1.2). Эмодзи скрыть от AT.
- M7. Вкладки (563-565, 881-891) сделаны кнопками без `tablist`, `role="tab"`, `aria-selected`.
- M8. `h1` «DSLKit» внутри `nav` (562), избыточный `role="navigation"` (561), `h3` без `h2` (702), одинаковый `title` на всех экранах (4).
- M9. Отключённая кнопка запуска (917) объясняет причину только в `title`; тост сохранения и блок ошибки E003 (1045-1047) без `role="status"`/`alert` (SC 4.1.3).
- M10. Холст диаграммы: нужны `role="img"` и `aria-label` либо текстовая альтернатива (сам DSL-код это и есть эквивалент, на него стоит ссылаться). Редактору кода нужен `aria-label` и выход из Tab-ловушки (SC 1.1.1, 2.1.2).
- M11. Цели меньше 24x24: `width:20px;height:20px` (816), `padding:2px 6px` (1047) (SC 2.5.8).
- M12. Карточка «Новый проект» на скриншоте серая и почти нечитаемая при том, что она активна. Поднять контраст.

## 6. Топ-5 исправлений
1. Чекбоксы меню и темы: не прятать через `display:none`, добавить `:focus-visible` на label, `aria-expanded`/`aria-controls` для бургера (мини-JS), `role="switch"` для темы (A1).
2. Ошибки формы: id ошибок в `aria-describedby`, `aria-invalid`, `role="alert"`, сводка и фокус на первом невалидном поле, `role="status"` для успеха, `method="post"` (A2, A3).
3. Цветовые токены: акцент `#15803d`, границы контролов 3:1, warning не для текста, `--tx-3` и `--tx-2` макета до 4.5:1 (A9, M4).
4. Фокус и цели: единый `:focus-visible` 2px, цели не менее 24x24 (чекбокс согласия, ссылки футера, иконки IDE 20px), `scroll-padding-top` под липкую шапку (A4, M3, M11).
5. IDE-макет: `aria-label` на кнопки-иконки, `label` на поля, `role="dialog"` с ловушкой фокуса, ARIA tabs, `role="status"` для тостов (M1, M2, M6, M7, M9).
