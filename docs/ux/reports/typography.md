# Типографика DSLKit: независимое ревью

Роль: строгий ревьюер, режим read-only. Файлы проекта не менялись.
Источники: design-tokens.txt, typography.png, home-desktop/tablet/mobile.png, ide-mockup-v2.png, dslkit-mockup-v2.html (CSS-переменные), Tipografika (1)/(2).pdf (одинаковые по содержанию, как данные).

## 0. Эталон из PDF (как чек-лист)

- Основной текст 12-18 px; ширина текстового блока не более 600 px.
- Интерлиньяж не менее 150% (примерно 1,5 высоты строчных букв).
- Не более трёх начертаний (заголовки bold, текст regular, кнопки italic).
- Выравнивание только по левому краю; абзацы с отступами между ними.
- Для кириллицы проверять на русском тексте, а не на Lorem ipsum.

## 3. Что в порядке

- Шкала отношений высоты строки соответствует правилу PDF (body 150%).
- Роли распределены понятно: заголовки Bold/SemiBold, текст Regular, код Mono (по PDF "три начертания" почти выдержано).
- Выравнивание строго по левому краю, лишних центровок нет.
- Measure основного блока около 62-65 знаков (укладывается в 600 px).
- Пара Inter + JetBrains Mono подходит для продукта "диаграммы как код" и хорошо читается на кириллице.

## 4. Топ-5 исправлений (по приоритету)

1. Подключить шрифты по-настоящему: self-hosted woff2 Inter (cyrillic + latin) и JetBrains Mono, `font-display: swap`, fallback через `size-adjust`. Сейчас в скриншотах сайта работают запасные шрифты, а style.css пуст (system-ui), поэтому вся оценка по паре шрифтов теоретическая.
2. Поднять код и мелкий текст: код редактора с 11 до 13 px (строка 20), основной UI-текст не ниже 12 px, label/uppercase 12 px; на mobile любой читаемый текст не ниже 14 px.
3. Исправить контраст текста: tx-3 (#3b4261, около 1.5:1) и tx-2 (#7982a9, около 3.9:1) на тёмной теме довести до 4.5:1 для текста и 3:1 для номеров строк/декора (например tx-2 около #9aa5ce, tx-3 около #6b749b).
4. Объединить шкалу: одна шкала для сайта и IDE, добавить в design-tokens lead 18/28, код 13-14/20, label 12/16; убрать 15 и избыточные 11/12; hero-код привести к токену 14/20 (сейчас 28 px строка, то есть 2.15).
5. Довести измерение и мелкую вёрстку: `max-width: 62ch`, `text-wrap: balance` на заголовках и `pretty` на lead (убрать вдову "Петри."), `letter-spacing: -0.02em` на H1/H2 Bold, `font-feature-settings: "zero"` для кода, mobile H1 через `clamp(2rem, 1.4rem + 2.6vw, 3rem)`.

## 5. Оговорки

- Размеры в скриншотах оценены по шагам строк и ширинам, а не из computed styles, погрешность около 1-2 px.
- Рендер сайта в скриншотах использует запасные шрифты (вывод по форме глифов и по отсутствию подключения в index.html/style.css); с настоящими Inter ширины строк будут отличаться примерно на 3-5%.
- Контрасты посчитаны по формуле WCAG для токенов из mockup v2 и design-tokens; в живом UI могут быть полупрозрачные наложения.
