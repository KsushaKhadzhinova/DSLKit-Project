## 2. Оценки

1. Контраст основного текста и ссылок: 8/10. Тело/заголовки 11–16:1, ссылки 6–8:1. Минус: muted и error в светлой темой на 4.56/4.59 — нулевой запас, любое осветление фона ломает.
2. Контраст вторичных и UI-элементов: 5/10. accent как текст 3.1, warning 3.0, белый на зелёной кнопке 3.3, границы 1.25–1.4, тёмный primary как текст 3.2, подписи mockup ~2.5.
3. Гармония палитры: 8/10. Синий primary + светло-синий secondary + зелёный accent — холодная, триадная-аналогичная схема, сдержанная (соответствует мудборду "минимализм", правило 60-30-10 соблюдено: нейтрали ~90%, синий ~8%, зелёный ~2%). Нейтрали сине-серые (#1c1f2e, #4a5068) согласованы с primary по тону. Тёмная — Catppuccin Mocha-подобная (#1e1e2e/#cdd6f4/#f38ba8/#fab387), внутренне цельная. Минус: зелёный #16a34a в светлой теме не работает как текст, а в тёмной даёт фиолет/розовый/оранжевый вне ядра палитры (в mockup ещё сиреневый, голубой) — акцентов больше, чем зафиксировано в токенах.
4. Семантические цвета: 6/10. Есть только error и warning; нет success (отдельного токена нет, accent играет роль success — смысловая путаница: брендовый CTA и "успех" один цвет), нет info. Error #dc2626 и warning #d97706 в светлой теме различимы по тону, но warning как текст проваливается (3.0). В тёмной теме error/warning пастельные (#f38ba8, #fab387) — хорошо читаются (7–9:1), но стиль тем разный по насыщенности (пастель vs насыщенные) — допустимо, однако red-vs-orange в тёмной оба тёплые светлые и близки по яркости.
5. Цветовая слепота: 6/10. Плюс: в ide-mockup статусы дублированы значком/текстом (▲, ○, ✓, подписи "Валидация пройдена", "Ошибка нотации", тип диаграммы текстом IDEF0/ERD). Минус: точки журнала активности различаются только цветом (красная/зелёная/оранжевая/сиреневая) — при протанопии красный и зелёный сливаются (accent #16a34a vs error #dc2626 почти равны по яркости: 3.3 vs 4.6, разница мала); в диаграммах ERD ключи/типы кодируются цветом заголовков. Нужны форма/иконка/подпись для каждого статуса.
6. Тёмная тема: 7/10. Не чисто-чёрная (#1e1e2e), поверхности 181825 темнее фона — "утопленные" карточки, ступень яркости нарушает типовую модель (surface светлее bg), но читается, акценты десатурированы, текст не чисто белый (#cdd6f4) — нет halation. Минус: primary #2563eb один и тот же в обеих темах — как текст/иконка 3.2:1, рамки узлов 2.5:1; границы 1.3:1 — карточки на скриншоте home-desktop-dark различимы лишь по едва заметной обводке, кнопка "Демо" почти сливается; secondary #27304d понижает muted/accent ниже AA; hero-diagram.svg жёстко светлый (fill #fff) — при подключении через img в тёмной теме даст белый блок (на скриншоте показан тёмный вариант, значит либо подмена файла, либо inline; проверить).
7. Выбор графических форматов: 8/10. Всё векторное SVG (logo 283 Б, favicon 283 Б, hero 1.1 КБ, иконки нотаций ~0.3 КБ, ширина/высота заданы — нет CLS), корректно для схем/иконок/логотипа (чёткость на любом dpi, ничтожный вес, ~2.5 КБ на всю графику). Растр не нужен. Минус: нет PNG/OG-изображения 1200x630 для соцсетей и apple-touch-icon 180 PNG (SVG-фавикон не везде), иконки жёстко окрашены #2563eb (stroke) — не адаптируются к темам; нет currentColor; шрифт в SVG hero (Inter/JetBrains) как текст — при отсутствии шрифта подставится Arial (лучше текст в контуры или webfont). Иконки 48x48 сохраняют стиль (stroke 2, округлые концы) — единый набор. Обратите внимание: иконки без alt (декор, корректно при подписи рядом).

## 4. Топ-фиксы (с проверенными числами)

1. Светлая тема: ввести accent-text #15803d (5.02 на белом, 4.76 на bg) для текста и белого на зелёной кнопке (5.02); #16a34a оставить только для заливок/иконок (>=3).
2. warning для текста в светлой теме #b45309 (4.77 на bg); error на secondary — #c81e1e (4.98); muted на secondary — #5f6679 (4.97).
3. Границы интерактивных элементов (кнопка "Демо", поля, переключатели): отдельный токен --border-strong: светлая #868ea3 (3.11 на bg; #8b93a7 даёт 3.07 на белом), тёмная #6c7086 (3.59 на surface, 3.36 на bg). #dde1e9/#313244 оставить только для декоративных разделителей.
4. Тёмная тема: ввести --primary-text/--primary-light #5b8def (5.08 на bg, 5.43 на surface) для ссылок/иконок/рамок узлов вместо #2563eb (3.17); кнопку с белым текстом оставить #2563eb (5.17). Подписи mockup поднять с ~#585b70 (2.46) до muted #8a8fa8 (5.14).
5. Добавить токен success (светлая #15803d, тёмная #a6e3a1-подобный пастельный) и info отдельно от accent; для всех статусов (журнал активности, ошибки) обязательные иконки/подписи помимо цвета (✓, ▲, ✕) — защита от дальтонизма. Сделать hero-diagram/иконки темо-адаптивными (inline SVG с currentColor или CSS-переменные, либо второй файл через <picture> с prefers-color-scheme) и добавить og-image PNG 1200x630 + apple-touch-icon 180 PNG.

Ограничения: контрасты приблизительные по скриншотам для mockup (цвета из токенов Catppuccin предположены, не считаны из CSS, т.к. site/css/style.css пока 60 байт); значения по токенам точные.
