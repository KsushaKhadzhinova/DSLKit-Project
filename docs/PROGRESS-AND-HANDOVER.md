## 6. Известные ловушки

- Встроенная панель Claude и расширение Chrome снимают только содержимое страницы, не панели DevTools. Настоящий интерфейс DevTools открывается как страница по `devtoolsFrontendUrl` при флагах `--remote-allow-origins=* --disable-features=LocalNetworkAccessChecks,LocalNetworkAccessChecksWebSockets,BlockInsecurePrivateNetworkRequests` (см. `tools/evidence/dtf.mjs`).
- Выпадающие списки DevTools выбираются клавиатурой (ArrowDown, Enter), мышью нет. Пресет Fast 3G в Chrome 155 называется **Slow 4G** (562,5 мс, 1,6 Мбит/с, 750 Кбит/с).
- Chrome 155 не загружает расширения флагом `--load-extension` (Edge 155 загружает). React DevTools подключён через `react-devtools-inline@6.1.5` и экспериментальный React.
- W3C CSS-валидатор падает на `color-mix()` внутри градиентов; цвета только через токены.
- Тесты читают сайт, поэтому лишние HTML-страницы в `site/` ломают проверки (галерея макетов исключена в `site.test.js` и `styles.test.js`).
- Подагенты ломают контекст: давайте им точное самодостаточное задание, git запрещайте, результат проверяйте сами. При достижении лимита сессии отчёты агентов могут не прийти.
- Работать с владельцем: короткие отчёты по сути, честно писать, что не получилось (Profiler, Chrome-расширения), не обещать то, чего не сделано.
