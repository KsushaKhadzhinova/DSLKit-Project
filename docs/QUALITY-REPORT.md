## 4 Прокликивание интерфейса (Chrome, встроенный браузер)

Проверено руками и скриптами, ошибок в консоли нет:

- Лендинг: переключатель темы, фильтр нотаций (6, 3, 3), аккордеон (открыт один), форма (4 ошибки при пустой отправке, фокус на первом поле, верная отправка сохраняет заявку и открывает `thanks.html`), крупная кнопка «Создать диаграмму».
- Английская версия: язык, кнопка, бургер-меню на 375 px (открытие, Escape, закрытие по ссылке), без горизонтальной прокрутки.
- Дашборд: фильтр по нотации, поиск, сортировка, счётчик проектов, состояние сохраняется.
- Настройки: переключатели и списки сохраняются, тема «светлая, тёмная, как в системе».
- Редактор: вкладки мышью и стрелками, диалог закрытия с названием файла, автосохранение, кнопка запуска заблокирована пока есть ошибки (по макету), переключатели вида, масштаб.
- Движки диаграммы: Graphviz (Kroki) работает, PlantUML (Kroki) работает, собственный движок рисует живой SVG без сети, повтор берёт копию из кэша, «Обновить с сервера» обходит кэш, офлайн показывает «Кэшированные данные».
- React-приложение: четыре заглушки пишут в консоль, карточки в ряду одной высоты, у всех элементов есть правила CSS.

Известные особенности:

- Mermaid через публичный Kroki 14.10.2026 не отвечал 40 секунд: движок показывает сообщение о таймауте. Это ограничение внешнего сервиса.
- В скрытой вкладке браузера событие `close` у диалога не приходит. Проверка диалога сделана тестами и в видимой вкладке.
