# Чек-листы DSLKit по экранам и по API

Правила построения чек-листа взяты из книги С. С. Куликова (раздел о чек-листах): пункт это идея проверки, а не пошаговая инструкция; пункты идут от простого к сложному, позитивные раньше негативных; ожидаемый результат пишется только там, где он неочевиден; пункты атомарны и допускают ответ «пройдено / не пройдено». Нумерация `CL-<экран>-<номер>`. Подробные шаги для части пунктов даны в документе 13; ссылка на кейс стоит в последнем столбце, если он есть.

Условные обозначения: Г = под гостем, П = под вошедшим пользователем. Окружение везде одно: `http://localhost:5190`, чистый профиль браузера, если не сказано иное.
