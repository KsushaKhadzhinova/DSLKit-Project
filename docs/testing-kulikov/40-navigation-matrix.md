# Матрица переходов: страница × элемент → результат

Источник: `scripts/nav-01-crawl.py` (Playwright). Каждый видимый элемент (ссылка, кнопка, поле, переключатель, вкладка) нажимался на свежезагруженной странице с восстановленным хранилищем. Результат: куда ушёл адрес, код ответа, изменился ли DOM или localStorage, диалоги confirm/prompt, ошибки консоли.

Элементов без видимого эффекта: 30; ссылок на 404/5xx: 0; ошибок выполнения проверки: 9; элементов с ошибкой консоли: 0.
Строк в матрице: **1921** в 25 сочетаниях «язык × гость/вошедший × страница»; из них нажато **1520**, остальные скрыты в данном состоянии (кнопка «Выйти» у гостя, пункты меню ⋯ и панелей редактора, которые проверены отдельно скриптом `nav-01b-editor-menus.py`, только для русской версии: 100 элементов) или относятся к полям файла (проверены в E23). Повторяющиеся карточки проектов на дашборде проверены на первых двух, остальные помечены «same as the previous cards».

## Адреса вручную (скрипт `nav-02-urls.py`, 160 страничных проверок и 51 HTTP-проверка)

- Параметры `?p=`, `?my=`, `?tpl=` с пустым, несуществующим, длинным, юникодным и мусорным значением: редактор открывает новую диаграмму и пишет «Проект не найден, открыта новая диаграмма.»; на остальных страницах параметры игнорируются. Исключение: `?template=__proto__`, `constructor`, `toString` (BUG-N04).
- `?q=` с HTML, битой кодировкой и лишними параметрами: разметка не внедряется (img=False), диалогов нет. Длинный `?q=` (3000 букв) даёт ответ 431 без страницы (BUG-N11).
- Несуществующие пути (`/nope`, `/app/nope.html`, `/en/app/nope.html`, `/app/`, `/index`, `/app/dashboard`) дают 404 со страницей ошибки (на русском для английских адресов, BUG-N09). Каталоги `/js/`, `/css/` — 404 (список файлов не показывается).
- Выход из корня: `/..%2f..%2ftools/server.js` и `/app/..%5c..%5cpackage.json` — 403; `/tools/server.js`, `/package.json`, `/.git/config` — 404.
- Методы POST, PUT, DELETE, OPTIONS, TRACE дают 405, HEAD — 200. `/api` — 404 в JSON, `/api/render` методом GET — 405 в JSON.
- Лишняя косая черта в конце (`/app/dashboard.html/`) отдаёт страницу без стилей и скриптов (BUG-N05); двойная косая в середине (`/app//login.html`) отдаёт страницу, в начале (`//app/login.html`) — 404.
- Кодировка пути: `/%` и `/%zz` — 400 со страницей ошибки; `/app/%00.html` — 404.

## Кнопки браузера и вкладки

- Назад после выхода на «Мои проекты»: проекты не показываются, ведёт на вход (A07). Вперёд, затем обновление: перенаправление на вход (A08).
- Выход в одной вкладке: меню второй вкладки обновляется по событию storage (A23), но защищённый список остаётся (A24, BUG-N01).
- Обновление страницы редактора: тема и проект сохраняются (E31, E41).
- Открытие в новой вкладке, правая кнопка, тройной щелчок и долгое нажатие: ссылки открываются как обычные; собственных обработчиков `contextmenu`, `auxclick`, `dblclick` (кроме переименования блока) в коде нет, дополнительных эффектов не обнаружено.
