# Ручной прогон кликами: протокол

Тестирование выполнено вручную: реальные нажатия кнопок мыши и клавиш (движения курсора, нажатие, отпускание, набор с клавиатуры) в браузере Chromium; координаты брались из положения элементов на странице, результат оценивался по скриншотам и состоянию страницы. Сайт: локальная копия исходников на порту 5191 (порт 5190 в начале прогона не отвечал); сборка dist проверена на порту 5198. Окна: 1366x800 (основное), 768x1024, 375x812.
