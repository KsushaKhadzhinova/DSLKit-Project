# Ручной прогон: отчёты о дефектах

Формат по Куликову (https://svyatoslav.biz/software_testing_book/): заголовок, окружение, шаги, фактический и ожидаемый результат, серьёзность и срочность. Общее окружение: Windows 11, Chromium 153, сайт http://localhost:5191 (копия site/), окно 1366x800, если не указано иное; пользователь manual1@example.com. Пруф: скриншоты в `screens-manual/` по идентификаторам проверок из 50-manual-click-run.md.

Сводка: 18 дефектов. Самые серьёзные: M-02, M-07, M-12, M-04, M-05, M-01, M-15.

## M-01. Кнопка «Пустой файл» открывает не пустой файл, а пример «Order process»

- Окружение: welcome.html, «Пустой файл»
- Шаги: 1. Войти. 2. Открыть /app/welcome.html. 3. Клик «Пустой файл».
- Фактический результат: В редакторе код IDEF0-примера из 20 строк, вкладка называется order.dsl, в проводнике «Новая диаграмма (не сохранена)».
- Ожидаемый результат: Пустой текст редактора и пустая доска.
- Серьёзность: Значительная
- Срочность: Средняя
- Пруф: D01, C02

## M-02. Проект или шаблон из списка открывается с кодом по умолчанию из editor.html, содержащим опечатку «contro»

- Окружение: dashboard, «Мои шаблоны» и «Мои проекты»
- Шаги: 1. «Общие», ⋯ у «Order process», «Добавить в Мои шаблоны». 2. «Мои шаблоны», ⋯, «Изменить шаблон». То же при клике по карточке «Order process» в «Мои проекты».
- Фактический результат: Редактор показывает код A0/A1 с ошибкой «Неизвестное свойство contro», «Запустить» заблокирована, у вкладки точка «не сохранено» без правок, доска пуста, список файлов пуст.
- Ожидаемый результат: Открывается сохранённое содержимое выбранного проекта или шаблона, без ошибок и без метки изменений.
- Серьёзность: Значительная
- Срочность: Высокая
- Пруф: J03, F00

## M-04. Перетаскивание элемента принимается только в пределах прямоугольника SVG схемы, а не всей доски

- Ожидаемый результат: Блок добавляется в точку отпускания в любой части видимой доски.
- Серьёзность: Значительная
- Срочность: Средняя
- Пруф: E01, E02

## M-07. Лимит «5 в день» не действует: счётчик 9 из 5, проекты продолжают создаваться

- Окружение: editor.html, dashboard
- Шаги: 1. Несколько раз открыть editor.html или шаблон и изменить диаграмму. 2. Сохранить копии из «Общие».
- Фактический результат: «Бета: сегодня создано 9, лимит 5 в день превышен», полоса заполнена, создание не блокируется; каждое открытие шаблона и правка даёт новый проект «Order handling» (дубликаты в проводнике).
- Ожидаемый результат: Либо блокировка с понятным сообщением, либо правка существующего проекта без новых.
- Серьёзность: Значительная
- Срочность: Средняя
- Пруф: K01, K03b, N-375x812-dashboard
