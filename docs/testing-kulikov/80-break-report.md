## Что проверено и устояло

- Вставка скриптов и HTML в метки диаграммы, названия и имена: не выполняется (санитайзер SVG, `textContent`).
- RU и EN страницы (`break-05-ru-en-diff.mjs`): совпадают id, `data-*`, число основных тегов, дублей id нет, мёртвых ссылок нет.
- Выход из сети (offline) при встроенном движке: рисунок строится локально, ошибки нет.
- 300 перерисовок подряд: память 9 МБ без роста, DOM около 950 узлов (утечки нет).
- Быстрые серии отмены/возврата: 60 правок и 200 нажатий за 16 с, ошибок нет.
- Смена размера окна во время ввода: без ошибок.

## Не проверено (честно)

- Service worker со старым кэшем после правок (проверяется только вручную: версия кэша `dslkit-v3` задана вручную в sw.js и не меняется при правках сайта, стратегия «файл из кэша сразу, свежий в фоне» отдаёт устаревший JS при первом заходе после обновления).
- Перетаскивание блоков на холсте и перезагрузка посреди сохранения: не доведены до воспроизводимых скриптов.
- Страницы Kroki-движков (внешняя сеть).
