# Сценарии тестовых данных (сиды), созданные вручную через интерфейс

Сайт: `http://localhost:5190`. Данные создавались реальными действиями в браузере (Playwright, отдельный контекст браузера на пользователя):
регистрация на `/app/register.html`, ввод DSL в поле редактора, `Ctrl+S`, кнопки верхней панели редактора (добавить элемент, соединить,
переименовать, удалить, перетаскивание блока), меню карточек на странице «Проекты». Подмена `localStorage` была только там, где это требует сценарий
(возраст записей в корзине, повреждённое поле). Аккаунты и проекты хранятся в `localStorage` браузера, поэтому сид = снимок `localStorage`.
Пароль всех учётных записей: `Passw0rd!x`.

## Как загрузить сид скриптом в консоли

1. Откройте любую страницу сайта (`http://localhost:5190/index.html`), чтобы был нужный origin. Если уже есть другой пользователь, он будет заменён: скрипт делает `localStorage.clear()`.
2. Откройте консоль (F12), вставьте содержимое `load-snapshot.js` и вместо `{}` в конце вставьте объект из нужного `scenario-N.json`
   (для `scenario-3.json` возьмите `.users[0]` или `.users[1]`, то есть `{...}.users[1]`).
3. Скрипт запишет ключи, сдвинет метки времени проектов на время, прошедшее после снятия снимка (последний аргумент `true`, нужен для корзины), и откроет `/app/dashboard.html` уже в сессии этого пользователя. Для английской версии замените путь на `/en/app/dashboard.html`.

Проверено: все файлы загружены этим скриптом в чистый контекст, в RU и EN число проектов, шаблонов и квота совпали со снимком. Скрипты создания лежат в `scripts/`
(`sclib.py` — помощники, `dsl.py` — тексты диаграмм, `scenario1.py` … `scenario5.py`, `scenario1b.py` … `scenario1d.py` — доработка BPMN кнопками, `verify_load.py` — проверка загрузки). Запуск: `python scenarioN.py` из папки `scripts`. Электронные адреса фиксированы, повторный запуск требует заменить адрес.

## Ключевые факты по результатам

- Квота считает проекты, созданные сегодня (кроме стартовых примеров): 14 в С1, 6 в С2, 7 в С3, 68 в С5. Блокировки на шестом нет, шкала остаётся на 5 из 5, подпись меняется на «лимит 5 в день превышен».
- Лайк примера сразу сохраняет копию в «Мои проекты»; повторный лайк снимает отметку, но копию не удаляет; следующий лайк создаёт вторую копию.
- В корзине подпись «будет стёрт через N дн.» для 1, 15, 29, 29,9 дня: 29, 15, 1, 1. Записи в 30 дней и старше стираются при открытии страницы (граница включительная).
