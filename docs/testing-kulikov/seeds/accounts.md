# Тестовые учётные записи сидов

Все пароли придуманы для тестов, к реальным сервисам отношения не имеют. Аккаунты живут только в localStorage браузера.

| Пользователь | Имя                | Почта                     | Пароль (тестовый) | Файл        |
| ------------ | ------------------ | ------------------------- | ----------------- | ----------- |
| А            | Анна Петрова       | anna.petrova@test.example | Тест-Пароль-2026A | user-a.json |
| Б            | Борис Иванов-Smith | boris.ivanov@test.example | Boris-Seed-2026!  | user-b.json |
| В            | Ци Лэй             | qi.lei@test.example       | Qi-Lei-Seed-2026  | user-c.json |

Пароль А содержит кириллицу: приложение принимает его и вход после выхода работает.
