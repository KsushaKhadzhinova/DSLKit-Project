# Сиды DSLKit: данные трёх пользователей

Данные созданы вручную через интерфейс сайта (реальные клики и ввод в браузере, Playwright), а не записью в localStorage. Снимок это полное содержимое `localStorage` пользователя, ключи вида `dslkit.*`. Аккаунты и сессия лежат в нём же: после загрузки можно войти тестовым паролем из `accounts.md`.

## Как загрузить сид

1. Запустить сайт (`http://localhost:5190`), открыть любую страницу приложения, например `/app/login.html`.
2. Открыть консоль (F12) и вставить, подставив содержимое нужного `user-*.json` вместо `PASTE_JSON_HERE`:

```js
const seed = PASTE_JSON_HERE; // объект {ключ: строка}
localStorage.clear(); // убрать данные другого пользователя
for (const [k, v] of Object.entries(seed)) localStorage.setItem(k, v);
location.href = '/app/dashboard.html'; // в снимке есть сессия, вход не нужен
```

Вариант без вставки текста: открыть страницу, в консоли выбрать файл и загрузить:

```js
const input = Object.assign(document.createElement('input'), { type: 'file', accept: '.json' });
input.onchange = async () => {
  const seed = JSON.parse(await input.files[0].text());
  localStorage.clear();
  for (const [k, v] of Object.entries(seed)) localStorage.setItem(k, v);
  location.href = '/app/dashboard.html';
};
input.click();
```

Несколько пользователей в одном браузере: загрузить файлы без `localStorage.clear()` и склеить ключ `dslkit.accounts` (массив) вручную, ключ `dslkit.session` не трогать. Такая склейка проверена: все три пользователя входят, чужие данные не видны.

Playwright: `page.evaluate` с тем же телом после `page.goto('/app/login.html')`.

## Что лежит в сидах

Общие ключи: `dslkit.accounts` (аккаунты, пароль только как хеш PBKDF2), `dslkit.session` (вошедший), `dslkit.dashboard` (фильтр, поиск, сортировка), `dslkit.editor-*` (состояние редактора). Ключи пользователя содержат его id: `dslkit.projects.<id>`, `dslkit.templates.<id>`, `dslkit.likes-<id>`, `dslkit.seeded.<id>`. Корзина это проекты с полем `trashedAt` в `projects`. Даты сидов реальные (28-30.10.2026): корзина стирает записи через 30 дней, счётчик квоты считает проекты за день создания.

Первое открытие списка кладёт в проекты 33 стартовых диаграммы (`seed: true`, по одной на нотацию). Они есть у каждого пользователя.

## Проверки, выполненные на сидах

Для каждого пользователя после каждого шага проверялись «Мои проекты», «Мои шаблоны», «Корзина», «Общие» (счётчик и названия карточек).

- После выхода и повторного входа А: все четыре раздела идентичны (названия и счётчики).
- Гость открывает `/app/dashboard.html`: перенаправление на вход.
- Три аккаунта в одном браузере: у каждого видны только свои проекты, шаблоны и корзина; чужие названия не встречаются; проект А по его id у В не открывается (открывается новая диаграмма).
- Поиск (регистр, кириллица, эмодзи, пробелы по краям, символы `% . * [ \`), фильтры по нотации (чипы и список), сортировка «новые/старые/по названию», фильтр вместе с поиском: работают на 86 проектах. Страниц нет, все карточки выводятся сразу (высота ~11350 px).
