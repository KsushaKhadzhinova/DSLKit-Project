# 92. Проверка глазами целевых пользователей: клавиатура и диктор, смартфон и планшет, англоязычный пользователь

Дата: 2026-10-30. Стенд: http://localhost:5190, Chromium 153 под управлением Playwright (Python), реальные события мыши, клавиатуры и касаний (`page.tap`, `is_mobile`, `has_touch`). Код сайта не менялся. Каждый сеанс начинался с чистого профиля и регистрации нового аккаунта. Скриншоты лежат в `docs/testing-kulikov/screens-persona/` (префиксы `kb-`, `m375-`, `en-`).

Ограничения честности: настоящий экранный диктор (NVDA, VoiceOver) не запускался. «Что услышит диктор» восстановлено по дереву доступности: роли, имена, `aria-live`, `aria-describedby`, `aria-invalid`. Экранная клавиатура смартфона не эмулировалась, вводился текст через клавиатуру браузера; про неё судим по атрибутам полей (`autocomplete`, `type`, размер шрифта). Прогон 360x640, планшета 768x1024 и альбомной ориентации 812x375 был запущен, но из-за перегрузки машины на момент сдачи не завершился. Для них приведены только выводы по CSS и по результату 375x812, это помечено ниже.
