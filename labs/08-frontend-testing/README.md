# Лабораторная работа №8. Тестирование фронтенд-приложения

Проект DSLKit (направление SaaS), ветка `feature/frontend-testing`. Условие: `materials/text/part-1/Модуль 08…/09. Лабораторная работа №8…`. Тестируется React-приложение из лабораторной работы 7 (папка [`react-app/`](../../react-app/README.md)). Отчёты: [`report.md`](report.md) на русском, [`report.en.md`](report.en.md) на английском.

## 1 Как запустить тесты и покрытие

```bash
cd react-app
npm install
npm test                 # Jest: все тесты
npm run test:coverage    # отчёт о покрытии, HTML: react-app/coverage/lcov-report/index.html
```

Из корня репозитория: `npm run react:test` запускает тесты приложения, `npm test` проверяет остальной код и этот пакет лабораторной работы.

## 2 Что сделано

| Требование условия                 | Реализация                                                                                                                                        |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Jest и React Testing Library       | `jest.config.js`, `babel.config.cjs`, `src/setupTests.js`, `__mocks__/fileMock.js`                                                                |
| Тесты чистых функций (минимум три) | `src/utils/helpers.test.js`: `formatPrice`, `formatDate`, `filterByNotation`, `truncateText`, `pluralizeFiles`                                    |
| Тесты компонентов (минимум три)    | UI: `Button`, `Card`, `Badge`; композитный: `NotationCard`, `ProjectList`; с обработчиком: `ProjectCard`, `PlanCard`, `Header`; интеграция: `App` |
| Покрытие не ниже 70 и 60 процентов | 100 процентов по строкам, ветвлениям и функциям (порог в `jest.config.js` 70/60/70/70)                                                            |
| Отладка в DevTools                 | В коде `console.log`, `console.group`, `console.table`; результаты описаны в отчёте                                                               |
| Lighthouse до и после улучшения    | Отчёты в `lighthouse-before/` и `lighthouse-after/`, сравнение в отчёте                                                                           |
