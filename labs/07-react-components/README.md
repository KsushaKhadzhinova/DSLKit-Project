# Лабораторная работа №7. Компонентный интерфейс на React

Проект DSLKit (направление SaaS), ветка `feature/react-components`. Условие: `materials/text/part-1/Модуль 07…/16. Лабораторная работа №7…`. Приложение лежит в папке [`react-app/`](../../react-app/README.md), там же инструкция запуска и список компонентов. Отчёты: [`report.md`](report.md) на русском, [`report.en.md`](report.en.md) на английском.

## 1 Цель и задание

Создать приложение на Vite и React, написать не менее пяти компонентов (базовые и предметные), передавать данные через `props`, использовать моковые данные (5–10 записей), обработчики-заглушки и стили. **Запрещено** использовать `useState` и `useEffect`.

## 2 Что сделано

| Требование условия                                         | Реализация                                                                                              |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Vite и React, React Router                                 | `react-app/package.json`, маршрутизатор установлен и не используется                                    |
| Структура `components/ui,layout,features`, `pages`, `data` | Все папки созданы                                                                                       |
| Минимум 5 компонентов                                      | 10: Button, Card, Badge, Header, Footer, NotationCard, NotationList, ProjectCard, ProjectList, PlanCard |
| Композиция                                                 | `NotationCard` собирается из `Card` и `Badge`, `ProjectCard` из `Card`, `Badge`, `Button`               |
| Моковые данные 5–10 записей                                | 6 нотаций, 8 проектов, 3 тарифа                                                                         |
| Обработчики-заглушки                                       | `console.log` в `App.jsx`                                                                               |
| Стилизация                                                 | CSS-модули и `index.css`                                                                                |
| Без `useState` и `useEffect`                               | Проверяет автоматический тест                                                                           |

## 3 Запуск и проверка

```bash
cd react-app && npm install && npm run dev   # http://localhost:5174
npm test                                     # проверка структуры и правил лабораторной (из корня репозитория)
npm run lab7:report                          # сборка отчётов
```

Тест `react-app.test.js` проверяет структуру папок, число компонентов, отсутствие `useState` и `useEffect`, размер моковых данных, `key` в списках, заглушки обработчиков и использование CSS-модулей. Работа приложения проверена в Chrome: консоль без ошибок, четыре заглушки пишут в консоль, вёрстка проверена на 375, 768 и 1280 пикселях.
