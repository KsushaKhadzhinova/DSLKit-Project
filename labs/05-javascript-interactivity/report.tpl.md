# Лабораторная работа №5. Разработка интерактивного интерфейса на JavaScript

## 1 Цель работы

Освоить основы JavaScript и работу с DOM, научиться обрабатывать события, проверять формы и сохранять состояние в LocalStorage на примере проекта DSLKit, веб-редактора диаграмм как кода, тематика которого соответствует направлению SaaS и будущему курсовому проекту.

## 2 Краткие теоретические сведения

**DOM.** Объектная модель документа представляет страницу в виде дерева узлов. Скрипт ищет узлы методами `getElementById`, `querySelector` и `querySelectorAll`, меняет текст через `textContent`, атрибуты через `setAttribute`, классы через `classList` и создаёт узлы методом `createElement`.

**События.** Обработчики подключаются методом `addEventListener`. Событие всплывает от целевого элемента к родителям, поэтому один обработчик на контейнере обслуживает много элементов: этот приём называется делегированием, а нужный элемент находит `event.target.closest`.

**Формы и валидация.** Событие `submit` отменяется методом `preventDefault`, значения проверяются кодом, а сообщения об ошибках показываются рядом с полями.

**LocalStorage.** Хранилище браузера записывает строки по ключам. Объекты сохраняются через `JSON.stringify` и читаются через `JSON.parse`, а ошибки доступа и разбора обрабатываются блоком `try/catch`.

**ES6+ и модули.** Код использует `const` и `let`, стрелочные функции, шаблонные строки, деструктуризацию и модули `import` и `export`.

### 3.2 Работа с DOM

Элементы ищутся по идентификаторам и селекторам, найденные узлы проверяются на `null`, а повторные выборки в цикле заменены ссылками в переменных. Фильтр нотаций создаёт кнопки и область состояния методом `createElement` и задаёт текст через `textContent`, поэтому в разметку не попадает пользовательский ввод. Видимость карточек меняется атрибутом `hidden`, состояние кнопок атрибутом `aria-pressed` и классом `filter__chip--active`.

### 3.3 События

Использованы пять типов событий: `click` (фильтры, вкладки, кнопки), `input` (поиск и проверка полей), `change` (сортировка, настройки, тема), `submit` (форма) и `keydown` (стрелки на вкладках, клавиша Escape, сочетание Ctrl и Enter). Дополнительно применено событие `toggle` для вопросов и событие `close` для диалога. Делегирование используется для кнопок фильтров, вкладок и настроек.

### 3.5 Сохранение состояния

Состояние хранится в LocalStorage под ключами с префиксом `dslkit.`: тема, фильтр нотаций, открытый вопрос, заявки, состояние дашборда, настройки, вкладка и вид редактора. Модуль `storage.js` оборачивает чтение и запись в `try/catch` и возвращает запасное значение при ошибке доступа или повреждённых данных. Если LocalStorage недоступен, используется хранилище в памяти.

### 3.6 Обработка ошибок и стандарт ES6+

Чтение и запись данных защищены блоками `try/catch`, а точка входа запускает каждый компонент отдельно: ошибка одного компонента попадает в консоль и не останавливает остальные. Код использует `const` и `let`, стрелочные функции, шаблонные строки, деструктуризацию и модули. Обработчики подключены через `addEventListener`, атрибуты `onclick` не применяются.

### 3.7 Тестирование

Для каждого модуля написаны автоматические тесты на jsdom, которые разбирают настоящие страницы сайта. Тесты проверяют фильтры, форму с верными и неверными данными, восстановление состояния после перезагрузки, ошибки хранилища и отсутствие нужной разметки. Покрытие всех файлов JavaScript равно 100 процентов по строкам, ветвлениям и функциям. Работа компонентов дополнительно проверена в браузере Chrome: консоль не содержит ошибок, заявка попадает в LocalStorage, тема сохраняется между страницами. Проверка в Firefox и Edge и снимок вкладки Event Listeners инструментов разработчика остаются задачей на этап приёмки.

## 4 Ответы на контрольные вопросы

{{answers}}
1. **Методы поиска элементов.** Метод `getElementById` быстро находит элемент с известным идентификатором, например `#project-list`. Метод `querySelector` принимает любой селектор и возвращает первый элемент, а `querySelectorAll` возвращает все совпадения, например кнопки фильтров `.filter__chip[data-filter]`.
2. **Делегирование событий.** Один обработчик на контейнере получает события от потомков, а нужный элемент определяется через `event.target.closest`. Так работают и добавленные позже элементы: кнопки фильтра нотаций создаются скриптом и обслуживаются одним обработчиком группы.
3. **Создание элементов.** Применены `createElement`, `append` и `before`. Метод `innerHTML` разбирает строку как разметку и открывает путь для внедрения кода, а `createElement` с `textContent` безопасен для пользовательских данных и возвращает ссылку на созданный узел.
4. **Структура кода.** Точка входа `script.js` запускает компоненты из папки `components`, общие вещи вынесены в `utils`: хранилище и проверка полей. Разделение позволило проверять каждый модуль отдельно.
5. **Всплытие и перехват.** Событие `toggle` не всплывает, поэтому аккордеон подписан на фазе перехвата на контейнере. Остальные события обрабатываются на фазе всплытия через делегирование.
6. **Что такое DOM.** Это дерево объектов, которое браузер строит из HTML. Скрипт читает и меняет его, и страница обновляется без перезагрузки.
7. **Выбор по идентификатору.** Выражение `document.getElementById('name')` возвращает элемент или `null`.
8. **Изменение текста.** Присваивание `element.textContent = 'Показано 3 из 6'` заменяет текст внутри элемента без разбора разметки.
9. **Обработчик события.** Это функция, которую браузер вызывает при событии. Подключается так: `button.addEventListener('click', (event) => { ... });`.
10. **Атрибуты элемента.** Чтение через `getAttribute('aria-label')`, запись через `setAttribute('aria-invalid', 'true')`, удаление через `removeAttribute`. Атрибуты `data-` доступны через `element.dataset`.
11. **Добавление элемента.** Создать элемент: `const chip = document.createElement('button');`, задать свойства и вставить: `group.append(chip);` либо `list.before(group)`.
12. **Удаление элемента.** Метод `element.remove()`, как в редакторе при сохранении файла удаляется отметка несохранённых изменений.
13. **LocalStorage.** Хранилище по ключам. Сохранение: `localStorage.setItem('theme', JSON.stringify('dark'));`, чтение: `JSON.parse(localStorage.getItem('theme'))`.
14. **LocalStorage в проекте.** Ключи `dslkit.notation-filter`, `dslkit.waitlist`, `dslkit.dashboard`, `dslkit.settings`, `dslkit.theme` хранят фильтр, заявки, состояние дашборда, настройки и тему. Заявки записываются массивом объектов.
15. **Обновление без перезагрузки.** Скрипт меняет DOM: фильтр скрывает карточки атрибутом `hidden`, а поиск пересортировывает и скрывает проекты, страница не перезагружается.
16. **Стили из JavaScript.** Предпочтительны классы через `classList.add`, `remove` и `toggle`. Точечные значения задаёт `element.style.width = '10px'`, вычисленные стили читает `getComputedStyle`.
17. **Различие getElementById и querySelector.** Первый работает только с идентификаторами и работает быстрее, второй принимает любой CSS-селектор и возвращает первый найденный элемент.
18. **Добавление в список.** Создать `li` через `createElement`, задать `textContent` и вызвать `list.append(li)`. Сохранённые заявки добавляются в массив методом `push`.
19. **Сортировка.** Массив элементов сортируется методом `sort` с компаратором, например `localeCompare` по названию, после чего элементы вставляются в список в новом порядке. Так работает сортировка проектов.
20. **Проверка почты.** Регулярное выражение `/^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/` проверяет наличие символа «@» и домена. Функция `isValidEmail` в `validation.js` использует его.
21. **Изменение класса.** Методы `classList.add('x')`, `remove('x')`, `toggle('x', true)` и `contains('x')`.
22. **Клик по кнопке.** `button.addEventListener('click', handler);` где обработчик выполняет нужное действие и при необходимости вызывает `event.preventDefault()`.
23. **Событие submit.** Возникает при отправке формы. Обработчик вызывает `event.preventDefault()`, проверяет поля и сам решает, что делать дальше. В проекте он сохраняет заявку и открывает страницу подтверждения.
24. **Значение поля.** Свойство `input.value`, для флажка `checkbox.checked`. Форма читает значения по идентификаторам полей.
25. **Фильтрация.** Для каждого элемента вычисляется условие и выставляется `item.hidden = !matches`. Фильтр нотаций сравнивает `item.dataset.status` с выбранным значением.
26. **Анимация.** Плавность задаёт CSS, а скрипт переключает класс или атрибут. В проекте анимации отключаются правилом `prefers-reduced-motion` для пользователей, которым они мешают.
27. **Слайдер.** Массив слайдов, индекс текущего и обработчики кнопок «назад» и «вперёд», которые меняют индекс и показывают нужный слайд. Индекс сохраняется в LocalStorage.
28. **Выпадающий список.** Элемент `select` с `option` создаётся разметкой или кодом, а изменение обрабатывается событием `change`. В проекте так сделана сортировка проектов.
29. **Таймер.** Функция `setInterval(() => {...}, 1000)` вызывает действие каждую секунду, остановить её можно через `clearInterval`. Одноразовая отсрочка делается через `setTimeout`.
30. **Перетаскивание.** У элемента ставится `draggable="true"`, обрабатываются события `dragstart`, `dragover` и `drop`, а данные передаются через `event.dataTransfer`.
