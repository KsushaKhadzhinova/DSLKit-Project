# Лабораторная работа №6. Работа с API браузера и асинхронными операциями

Проект DSLKit (направление SaaS), ветка `feature/async-api-storage`. Условие: `materials/text/part-1/Модуль 06…/06. Лабораторная работа 6…`. Отчёты: [`report.md`](report.md) на русском, [`report.en.md`](report.en.md) на английском.

## 1 Какое API используется

**Kroki** (`https://kroki.io`) рисует диаграммы по их текстовому описанию. Это та же задача, которую решает DSLKit, поэтому API можно использовать и в курсовом проекте. **Ключ не нужен**, регистрация не нужна, `.env` не требуется.

| Запрос                               | Назначение                                               |
| ------------------------------------ | -------------------------------------------------------- |
| `GET https://kroki.io/health`        | Проверка доступности сервиса, ответ JSON                 |
| `POST https://kroki.io/graphviz/svg` | Тело запроса: текст Graphviz DOT, ответ: изображение SVG |

Если позже понадобится API с ключом, ключ нужно хранить в файле `site/js/api/config.local.js` или `.env.local`: оба имени добавлены в `.gitignore` и не попадают в репозиторий.

## 2 Как это работает на сайте

Откройте `site/app/editor.html` (`npm start`, затем `http://localhost:5173/app/editor.html`) и нажмите **«Запустить»** (движок отрисовки выбирается в настройках и назван в строке состояния внизу).

1. Код диаграммы из редактора разбирается в модель (`utils/dataParser.js`) и превращается в DOT.
2. Запрос уходит в Kroki (`api/apiService.js`): таймаут 10 секунд, до 3 повторов с нарастающей паузой, отмена предыдущего запроса.
3. SVG очищается от скриптов и обработчиков и показывается на холсте.
4. Результат сохраняется в LocalStorage на 24 часа, последние запуски попадают в историю.
5. Без интернета или при ошибке сервера показывается сохранённая копия с пометкой «Кэшированные данные».
6. Кнопка **«Обновить с сервера»** игнорирует кэш.

## 3 Структура

| Путь                                   | Назначение                                                                 |
| -------------------------------------- | -------------------------------------------------------------------------- |
| `site/js/api/config.js`                | Адрес сервиса, формат ответа, таймаут, число повторов, срок жизни кэша     |
| `site/js/api/apiService.js`            | `fetchData`, `postData`, `checkHealth`, `renderDiagram`, ошибки `ApiError` |
| `site/js/storage/localStorage.js`      | Обёртки чтения и записи, кэш с сроком жизни, история запусков              |
| `site/js/utils/dataParser.js`          | DSL в модель, модель в DOT, ключ кэша, очистка SVG                         |
| `site/js/components/diagram-runner.js` | Кнопки, индикатор загрузки, сообщения об ошибках, офлайн-режим, история    |
| `labs/06-async-api-storage/*.test.js`  | Тесты с подменой `fetch`, покрытие 100 процентов                           |
| `labs/06-async-api-storage/figures/`   | Снимки экрана работы интеграции                                            |

## 4 Дополнительные требования (выполнено больше двух)

- Индикатор «обновление данных» и кнопка принудительного обновления без кэша.
- История запусков в LocalStorage (последние пять, без повторов).
- `AbortController`: новый запуск отменяет предыдущий запрос.
- Повтор запроса до 3 раз с экспоненциальной задержкой, учитывается заголовок `Retry-After` при коде 429.
- Защита от дублирования одинаковых параллельных запросов.

## 5 Запуск и проверка

```bash
npm start                 # сайт на http://localhost:5173
npm test                  # все тесты, порог покрытия 100 процентов
npm run lab6:report       # сборка отчётов
npm run format:check
```

Офлайн-режим в Chrome: DevTools, вкладка Network, переключатель Offline (или Throttling, Slow 3G).

## 6 Безопасность

- Ключа нет, в репозитории нет секретов.
- Ответ сервера считается недоверенным: из SVG удаляются `script`, `foreignObject`, атрибуты `on*` и ссылки `javascript:`.
- Все запросы обёрнуты в обработку ошибок, пользователь видит понятное сообщение, подробности идут в консоль.
- Пока форма записи и редактор работают без собственного сервера, в Kroki уходит только текст диаграммы.
