Код ошибки: 405

Ошибка 405: метод не поддерживается

Сервер получил запрос с HTTP-методом, который для этого адреса не разрешён. DSLKit поддерживает только методы GET и HEAD: страницы открываются обычной ссылкой или вводом адреса в строку браузера. Методы POST, PUT, PATCH и DELETE для статических страниц не выполняются.

На главную

Что можно сделать:

  • Откройте страницу обычной ссылкой или введите адрес в строку браузера, это запрос методом GET.
  • Если вы отправляли запрос через API-клиент или сторонний инструмент, выберите метод GET или HEAD.
  • Если страница открывается обычной ссылкой, но ошибка всё равно появляется, напишите на hello@dslkit.io с адресом страницы.

Error code: 405

Error 405: method not allowed

The server received a request with an HTTP method that is not allowed for this address. DSLKit supports only GET and HEAD: pages open through a normal link or by typing the address in the browser bar. POST, PUT, PATCH and DELETE requests are not processed for static pages.

Back to home

What you can do:

  • Open the page through a normal link or type the address in the browser bar, which sends a GET request.
  • If you sent the request with an API client or another tool, switch the method to GET or HEAD.
  • If the page opens through a normal link but the error still appears, email hello@dslkit.io with the page address.
