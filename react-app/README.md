# DSLKit: React-компоненты (лабораторная работа 7)

## Предметная область

**DSLKit** — SaaS-сервис диаграмм как кода: пользователь описывает диаграмму текстом, а сервис рисует её. Приложение показывает компонентный интерфейс для трёх экранов: каталог нотаций (UML, BPMN, ERD, DFD, IDEF0, сети Петри), список проектов и тарифы. Все данные статические, состояния нет: `useState` и `useEffect` не используются по условию лабораторной работы.

## Запуск

```bash
cd react-app
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Структура

```
src/
├── components/
│   ├── ui/        Button, Card, Badge
│   ├── layout/    Header, Footer
│   └── features/  NotationCard, NotationList, ProjectCard, ProjectList, PlanCard
├── pages/         заготовка для маршрутизации
├── data/          notations.js, projects.js, plans.js (моковые данные)
├── utils/         helpers.js (чистые функции форматирования и фильтрации)
├── App.jsx        корневой компонент
├── main.jsx       точка входа
└── index.css      глобальные стили и токены золотого сечения
```

## Компоненты и их назначение

| Компонент      | Группа   | Назначение                                                                |
| -------------- | -------- | ------------------------------------------------------------------------- |
| `Button`       | ui       | Универсальная кнопка, вариант `primary` или `quiet`                       |
| `Card`         | ui       | Контейнер с заголовком, содержимое приходит через `children`              |
| `Badge`        | ui       | Метка статуса, цвет задаётся пропсом `tone`                               |
| `Header`       | layout   | Название, ссылки на разделы и кнопка записи в бету                        |
| `Footer`       | layout   | Подвал с годом и владельцем из пропсов                                    |
| `NotationCard` | features | Карточка нотации: `Card`, `Badge` и пример кода                           |
| `NotationList` | features | Список карточек нотаций, сообщение о пустом списке                        |
| `ProjectCard`  | features | Карточка проекта с обработчиком «Открыть»                                 |
| `ProjectList`  | features | Список проектов с выбором нотации (обработчик-заглушка), пустое состояние |
| `PlanCard`     | features | Тариф: цена, возможности, кнопка «Выбрать»                                |

## Условия лабораторной работы

- Vite и React, React Router установлен для будущих работ и не используется.
- Больше пяти компонентов, композиция, `props`, `children`, списки с `key`, условный рендеринг.
- Моковые данные: 6 нотаций, 8 проектов, 3 тарифа.
- Обработчики — заглушки с `console.log`.
- Стили: CSS-модули для компонентов и общий `index.css`.
