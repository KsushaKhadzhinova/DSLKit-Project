# Макеты DSLKit для Figma

SVG-экраны трёх степеней детализации. Генератор: `python figma/generate.py`. Просмотр всех сразу: `figma/index.html`.

| Папка | Уровень | Что внутри |
|---|---|---|
| `wireframes/` | Вайрфрейм | Только структура: рамки, плейсхолдеры иконок, серые полосы вместо кода |
| `mockups/` | Мокап | Серая палитра, реальные тексты, иконки и состояния |
| `designs-light/` | Макет, светлая тема | Токены из `DESIGN-TOKENS.md` (светлая тема проектируется первой) |
| `designs-dark/` | Макет, тёмная тема | Те же экраны в `.t-dark` (IDE, дашборд, мобильная версия) |

Экраны: `ide-desktop` (1440×900), `ide-tablet` (1024×768), `ide-mobile` (390×844), `dashboard`, `welcome` (выбор шаблона нотации), `settings`.

## Как добавить в Figma

1. Откройте файл `bsuir-diploma` в режиме редактирования.
2. Создайте страницы `Wireframes`, `Mockups`, `Designs Light`, `Designs Dark`.
3. Выделите SVG-файлы нужной папки в проводнике и перетащите их на холст страницы (или `Ctrl+Shift+K`, затем выбор файлов).
4. Каждый SVG станет фреймом; текст остаётся текстовыми слоями, блоки (`Toolbar`, `Sidebar`, `Canvas`, `BottomPanel`, `StatusBar` и др.) — именованными группами.
5. Шрифты: Inter и JetBrains Mono (установите или подключите через Google Fonts; иначе Figma подставит замену). Собственный шрифт проекта ещё не создан.

Сетка точек на холсте нарисована отдельными кругами в группе `Grid`; в Figma её можно удалить и заменить Layout grid или стилем.

## Ограничения

- Это статичные экраны без компонентов, Auto Layout и переменных. Следующий шаг в Figma: собрать компоненты (кнопка, toggle, вкладка, строка ошибки) и подключить токены как Variables.
- Прямую запись в файл Figma автоматически сделать не удалось: нужен Personal Access Token или Figma MCP либо подключённое расширение Chrome.
