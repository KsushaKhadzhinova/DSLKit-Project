# Практическое занятие №3. Маршрутизация в React-приложениях

## 1 Цель работы

Освоить маршрутизацию в React-приложении: настроить маршруты, создать одностраничное приложение с несколькими страницами, использовать динамические маршруты и защищённые маршруты на примере проекта DSLKit, веб-редактора диаграмм как кода (направление SaaS).

## 2 Выбор версии React Router

Условие называет React Router v6 с пометкой «v6?». Использована библиотека `react-router-dom` версии 7.18.4. Весь API из условия (`BrowserRouter`, `Routes`, `Route`, `Link`, `NavLink`, `Outlet`, `Navigate`, `useParams`, `useNavigate`, `useLocation`) в версии 7 в режиме библиотеки работает так же, как в v6. Версия 7 поддерживается, совместима с React 19 и уже используется в приложении из первой части курса. При необходимости код переносится на v6 командой `npm i react-router-dom@6` без правок.

## 3 Ход работы

### 3.1 Карта маршрутов

Приложение состоит из страниц, показанных в таблице 1. Все страницы, кроме входа и выхода, находятся внутри общего маршрута-обёртки `Layout`, который рисует меню и через `Outlet` подставляет содержимое страницы.

Таблица 1 – Маршруты приложения

| Путь           | Страница               | Доступ                             |
| -------------- | ---------------------- | ---------------------------------- |
| `/`            | Главная                | открыт                             |
| `/catalog`     | Каталог шаблонов       | открыт                             |
| `/catalog/:id` | Карточка шаблона       | открыт, неверный `id` ведёт на 404 |
| `/about`       | О проекте              | открыт                             |
| `/login`       | Вход (имитация)        | открыт                             |
| `/logout`      | Выход, редирект на `/` | открыт                             |
| `/dashboard`   | Личный кабинет         | только после входа                 |
| `*`            | 404                    | открыт                             |

### 3.2 Меню и динамический маршрут

Меню построено на `NavLink`, функция в `className` получает флаг `isActive` и добавляет класс активного пункта. Для главной страницы указан `end`, чтобы пункт не оставался активным на всех путях. Страница `/catalog/:id` читает параметр через `useParams`, ищет шаблон в данных и при неудаче отправляет пользователя на страницу 404 компонентом `Navigate`. Кнопка «Назад» вызывает `navigate(-1)`. Код приведён в приложении А.

### 3.3 Защищённый маршрут и имитация входа

Компонент `PrivateRoute` работает как маршрут-обёртка: при установленном флаге `isAuth` он рисует `Outlet`, иначе перенаправляет на `/login` и передаёт в `state` запрошенный путь, не показывая его в адресе. Флаг хранится в состоянии провайдера `AuthProvider` и в `localStorage`. После нажатия «Войти» компонент `Login` вызывает `navigate` на запрошенную страницу или на `/dashboard`. Выход сделан отдельным маршрутом `/logout`: он очищает флаг и возвращает на главную декларативно. Первая версия с вызовом `navigate('/')` и `logout()` в одном обработчике не работала, потому что `PrivateRoute` успевал перенаправить на `/login`.

### 3.4 Тестирование

Тринадцать автоматических тестов на `MemoryRouter` проверяют все страницы, подсветку `NavLink`, переход по меню, динамический маршрут с неверным `id`, страницу 404, редирект гостя на `/login`, возврат после входа, выход и сохранение входа между загрузками. Ручная проверка описана в `README.md`.

## Заключение

Приложение на Vite содержит семь маршрутов, меню с подсветкой активного пункта, динамический маршрут с обработкой неизвестного параметра, страницу 404 и защищённый кабинет с имитацией входа и программной навигацией. Выбрана версия `react-router-dom` 7, API которой для задач работы совпадает с v6.

## Приложение А – Ключевые части кода

```jsx
// App.jsx: карта маршрутов, Layout даёт меню и Outlet
<Routes>
  <Route element={<Layout />}>
    <Route index element={<Home />} />
    <Route path="catalog/:id" element={<CatalogItem />} />
    <Route path="logout" element={<Logout />} />
    <Route element={<PrivateRoute />}>
      <Route path="dashboard" element={<Dashboard />} />
    </Route>
    <Route path="*" element={<NotFound />} />
  </Route>
</Routes>
```

```jsx
// CatalogItem: параметр из URL и редирект на 404
const { id } = useParams();
const template = findTemplate(id);
if (!template) return <Navigate to="/not-found" replace />;
```

```jsx
// PrivateRoute: защита и запоминание запрошенного пути
return isAuth ? <Outlet /> : <Navigate to="/login" replace state={{ from: location.pathname }} />;
```

```jsx
// Login: программная навигация после имитации входа
login();
navigate(location.state?.from ?? '/dashboard', { replace: true });
```
