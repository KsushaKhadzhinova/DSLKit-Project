# Практическое занятие №3. Маршрутизация в React-приложениях

Проект DSLKit (SaaS, редактор диаграмм как кода). Условие: `materials/text/part-2/Модуль 02…/24. Практическое занятие 3…`. Отчёты: [`report.tpl.md`](report.tpl.md) на русском, [`report.en.tpl.md`](report.en.tpl.md) на английском (без титульного листа и ответов на контрольные вопросы).

## Версия React Router

В условии указан React Router v6 с пометкой «v6?». Выбран **`react-router-dom` 7.18.4**. Причины: API из условия (`BrowserRouter`, `Routes`, `Route`, `Link`, `NavLink`, `Outlet`, `Navigate`, `useParams`, `useNavigate`, `useLocation`) в версии 7 работает без изменений (режим библиотеки), v7 является текущей линейкой с обновлениями, она совместима с React 19 и уже стоит в `react-app` из части 1. Версия 6.x подошла бы так же (код не меняется), версия 8 требует Node 22.22 и выходит за рамки условия. Если преподаватель требует строго v6, достаточно `npm i react-router-dom@6`.

## Что сделано

| Требование условия                  | Реализация                                                                                    |
| ----------------------------------- | --------------------------------------------------------------------------------------------- |
| Минимум 4 страницы                  | `/`, `/catalog`, `/catalog/:id`, `/about`, `/login`, `/dashboard`, `*` (`pages/pages.jsx`)    |
| Динамический маршрут и `useParams`  | `CatalogItem`, неизвестный `id` показывает 404 на месте                                       |
| Меню с подсветкой (`NavLink`)       | `components/Layout.jsx`, активный пункт получает класс `nav__link--active`                    |
| Страница 404                        | маршрут `*`, компонент `NotFound`                                                             |
| Защищённый маршрут, имитация логина | `components/PrivateRoute.jsx` (layout-маршрут с `Outlet`), `auth.jsx` с флагом в localStorage |
| Программная навигация после входа   | `Login`: `navigate(from ?? '/dashboard')`; выход через маршрут `/logout`                      |

## Запуск

```bash
cd part-2/pz-03-routing
npm install
npm run dev      # http://localhost:5176
npm test         # Vitest, React Testing Library и MemoryRouter, 15 тестов
npm run build
```

## Что проверить

1. Пункт меню текущей страницы подсвечен, на `/catalog/2` подсвечен «Каталог».
2. Открыть `/catalog/999` и `/xyz`: показывается 404.
3. Открыть `/dashboard` без входа: переход на `/login` с подсказкой, после «Войти» возвращение в кабинет.
4. «Выйти» очищает флаг `dslkit.isAuth` в localStorage и ведёт на главную.
