# Запуск ЛР3 на PostgreSQL

Снимки сделаны 28 октября 2026 на PostgreSQL 16 в Docker (`docker compose up -d db`, порт 5433): `npm run db:migrate`, `npm run db:seed` (администратор из переменных окружения), `node server.js`, затем запросы из `requests.http`.
Окно Postman не использовалось: ответы получены скриптом и нарисованы как панель ответа. Токены на снимках сокращены. Структура таблицы и строки Users сняты командами psql внутри контейнера.
Показаны: регистрация 201, повтор 409, слабый пароль 400, вход 200 и 401, профиль с токеном 200 и без токена 401, создание диаграммы 201, список пользователей 403 для роли user и 200 для роли admin.
