# Практическое занятие №4. Управление состоянием приложения

Проект DSLKit (SaaS, редактор диаграмм как кода). Условие: `materials/text/part-2/Модуль 02…/25. Практическое занятие 4…`. Отчёты: [`report.tpl.md`](report.tpl.md) на русском, [`report.en.tpl.md`](report.en.tpl.md) на английском (без титульного листа и ответов на контрольные вопросы).

**Ветка.** По условию работа сдаётся в ветке `pz24`. Эти файлы закоммичены в ветке `claude/part2-react-labs-251a24` одним коммитом, перенести их в `pz24` можно командой `git cherry-pick <хэш коммита>` (создание ветки `pz24` из `work/part1-finish` не удалось выполнить из этой сессии, подробности в отчёте сессии).

## Что сделано

| Требование условия                        | Реализация                                                                                                     |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Показать prop drilling                    | `components/PropDrilling.jsx`: `userName` идёт через `DrillingHeader`, `Navigation`, `UserMenu` в `UserAvatar` |
| Контекст темы                             | `context/ThemeContext.jsx`, тема пишется в `data-theme` корня, цвета переключают CSS-переменные                |
| Контекст языка                            | `context/LanguageContext.jsx`: словарь RU и EN, функция `t(key)`, атрибут `lang` корня                         |
| Бизнес-логика на `useReducer` и Context   | `context/FavoritesContext.jsx`: редьюсер `ADD`, `REMOVE`, `TOGGLE`, `CLEAR`, избранные шаблоны диаграмм        |
| Доступ к состоянию и `dispatch` везде     | хуки `useTheme`, `useLanguage`, `useFavorites`, компоненты не получают их через props                          |
| Сохранение в localStorage (рекомендовано) | `FavoritesProvider` пишет список эффектом, читает ленивым инициализатором, проверяет формат                    |

## Запуск

```bash
cd part-2/pz-04-context-reducer
npm install
npm run dev      # http://localhost:5177
npm test         # Vitest и React Testing Library, 19 тестов
npm run build
```

## Что проверить

1. Переключатель с луной и солнцем в шапке меняет светлую и тёмную темы всей страницы, выбор запоминается.
2. Кнопка языка (RU или EN) в шапке меняет язык заголовков, названий шаблонов и подписей кнопок.
3. «В избранное» добавляет шаблон в панель «Избранное», «Убрать» и «Очистить» удаляют, счётчик обновляется.
4. После перезагрузки избранное сохранено (ключ `dslkit.favorites` в localStorage).

## Внешний вид и скриншоты

Стили скопированы из сайта первой части командой `node docs/design-contest/bundle-css.mjs src/dslkit.css` (файл `src/dslkit.css`), недостающие правила шапки, карточки ошибки и подсказок лежат в `src/shell.css`, общая оболочка (шапка, подвал, переключатель темы, страницы 404 и 500) в `src/shell/`. Скриншоты для отчёта: `node shots/shots.mjs` (нужны Chrome и пакет `puppeteer-core`, он не входит в зависимости), результат в `figures/`.
