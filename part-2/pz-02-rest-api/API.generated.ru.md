# DSLKit REST API: справочник, собранный из документа OpenAPI

Файл собран скриптом `tools/gen-api-md.mjs` из ответа `GET /api/openapi.json` (OpenAPI 3.0.3, версия 1.0.0). Вручную не правится: запустите `node tools/gen-api-md.mjs`. Правила, которые документ выразить не может (заголовки, лимиты, замечания по безопасности), описаны в `API.md`.

## Операции

### GET `/api/users`

Список пользователей

**Параметры**

| Имя | Где | Тип и правила | Описание |
| --- | --- | --- | --- |
| `page` | строка запроса | integer, от 1, до 999999999999999, по умолчанию `1` |  |
| `limit` | строка запроса | integer, от 1, до 100, по умолчанию `20` |  |
| `sort` | строка запроса | string | Имя поля; минус в начале означает сортировку по убыванию. |
| `q` | строка запроса | string | Часть любого текстового поля, регистр не учитывается. |
| `name` | строка запроса | string, до 60 символов |  |
| `role` | строка запроса | string, одно из: `owner`, `editor`, `viewer`, по умолчанию `viewer` |  |

**Ответы**

| Статус | Значение | Тело |
| --- | --- | --- |
| 200 | Страница записей | { data: массив UserListItem, meta } |
| 400 | Неверные данные | Error |
| 406 | Клиент не принимает application/json | Error |
| 429 | Слишком много запросов | Error |
| остальные статусы | Непредвиденная ошибка | Error |
