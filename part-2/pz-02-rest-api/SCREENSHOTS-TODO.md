## Как сняты

`node shots/real-shots.mjs` (порты 4230–4236, экран разблокирован, окно снимает `shots/window-shot.ps1`). Консоль и таблица журнала сняты из папки `E:\DSLKit\part-2\pz-02-rest-api` (копия без пути служебного worktree). Снимки Postman получены управлением окном Postman: запрос вставлялся в строку адреса как команда cURL, затем нажималась кнопка Send. Верх окна Postman (заголовок с именем рабочей области, баннер, вкладки) обрезан, вкладки владелицы не затрагивались. Снимок Chrome сделан в гостевом профиле.

Снимок `tests.png` сделан после исправления теста запуска сервера (`src/start.js`): прежняя версия в окне консоли показывала `server.js` 84,62 процента.
