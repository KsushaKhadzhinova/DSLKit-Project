# Повторный запуск ЛР8 на этой машине (28 октября 2026)

Команда: `docker compose -p dslkit-rerun up -d` (свежий проект и свежий том). Результат: `db`, `backend` и `frontend` поднялись, `healthy`, страница входа на http://localhost:8080 отвечает 200, `/api/health` через прокси отвечает `{"status":"ok"}`.

Находка: запуск без `-p` в проекте `dslkit` упал: контейнер `backend` в цикле перезапуска с ошибкой `password authentication failed for user "dslkit"`. Причина: том `dslkit_pgdata` остался от прежнего запуска, а PostgreSQL берёт пароль только при первой инициализации тома, поэтому новый `POSTGRES_PASSWORD` из `.env` к старому тому не подходит. Лечение: удалить том (`docker compose down -v`, это сотрёт данные базы) или вернуть прежний пароль. Это стоит одной строкой добавить в README и в отчёт.

Образ в Docker Hub не публиковался: для этого нужен вход в аккаунт, его делает владелица.
