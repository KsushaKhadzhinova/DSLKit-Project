# Скриншоты лабораторной работы 6

Файлы создаёт `node shots/shots.mjs`: скрипт поднимает временную MongoDB и сервер, выполняет настоящие запросы и рисует запрос с ответом в headless Chrome. Скриншоты кластера Atlas и MongoDB Compass здесь не заменены.

- `01-get-list.png`: ответ `GET /diagrams` со списком из трёх диаграмм, у каждой видны теги, вложенные комментарии и время создания.
- `02-get-one.png`: ответ `GET /diagrams/:id` с одной диаграммой по идентификатору ObjectId.
- `03-post-create.png`: запрос `POST /diagrams` с телом новой диаграммы и ответ 201 с заголовком Location.
- `04-put-replace.png`: запрос `PUT /diagrams/:id`, который заменяет поля диаграммы, при этом её комментарий в ответе сохранён.
- `05-delete.png`: первое `DELETE /diagrams/:id` с ответом 204 и повторное удаление того же документа с ответом 404.
- `06-comment-add.png`: `POST /diagrams/:id/comments` добавляет комментарий в вложенный массив оператором `$push`, ответ 201.
- `07-comment-edit.png`: `PUT /diagrams/:id/comments/:commentId` меняет текст одного элемента массива позиционным оператором `$`.
- `08-comment-delete.png`: `DELETE /diagrams/:id/comments/:commentId` убирает элемент оператором `$pull`, массив комментариев в ответе пуст.
- `09-filter-by-tag.png`: `GET /diagrams?tag=shop&owner=anna` возвращает диаграммы, у которых массив тегов содержит `shop` и владелец `anna`.
- `10-mongo-document.png`: сырой документ коллекции `diagrams` из MongoDB с полями `_id`, вложенным массивом `tags` и вложенными комментариями.
- `11-validation-error.png`: ответ 400 с перечнем полей, не прошедших проверку (пустые и пробельные строки, неизвестная нотация, приоритет вне диапазона, пустой тег).
- `12-limits.png`: ответ 400 на название длиннее 80 символов и 21 тег, то есть превышение пределов из `limits.json`.
- `13-injection-body.png`: тело запроса с операторами `{"$ne": null}` и `{"$gt": ""}` вместо строк отклонено ответом 400.
- `14-injection-query.png`: параметр `owner[$ne]=nobody` и повторяющийся параметр `tag` отклонены ответом 400.
- `15-not-found-and-bad-id.png`: ответ 404 для корректного, но неизвестного ObjectId и ответ 400 для строки `abc`.
