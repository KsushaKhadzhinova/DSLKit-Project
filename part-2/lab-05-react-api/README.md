## 3 Безопасность: решения

- Данные записей и тексты ошибок сервера выводит React как обычный текст, `dangerouslySetInnerHTML` и `innerHTML` не используются (есть тест с разметкой в ответе сервера).
- Токен JWT хранится в `localStorage`, как требует условие. Риск: скрипт, внедрённый на страницу, прочитает токен. Поэтому разметка не вставляется, срок токена один час, а код 401 сразу удаляет токен. Разбора JSON из `localStorage` нет, там лежит только строка токена.
- Повторная отправка: пока запрос по записи не завершён, второе удаление или правка этой же записи игнорируется, запись с временным идентификатором нельзя удалить или изменить.
- Сервер: CORS сравнивает `Origin` с одним адресом из `CORS_ORIGIN`, значение `*` запрещено, `Vary: Origin` отправляется всегда, ответ на preflight не требует токена.
- Пароль на клиенте проверяется в байтах (72), как на сервере, адрес почты не длиннее 254 символов.

## 4 Запуск

```bash
# 1. Сервер из лабораторной работы 3
cd part-2/lab-03-auth
cp .env.example .env     # впишите JWT_SECRET (не короче 32 символов)
npm install
npm run db:migrate
npm run dev              # http://localhost:3000

# 2. Клиент
cd part-2/lab-05-react-api
cp .env.example .env     # VITE_API_URL=http://localhost:3000

npm run dev              # http://localhost:5178
npm test                 # Vitest и React Testing Library (42 теста) и проверка отчётов
npm run build            # сборка в dist/
npm run shots            # скриншоты рисунков 1–9 в figures/ (нужен Chrome или Edge, сервер и клиент поднимаются сами)
```

## 6 Проверка

1. Запустить сервер и клиент, зарегистрироваться и войти (пароль от 8 до 72 байт).
2. Список загружается с индикатором, при остановленном сервере виден текст ошибки и кнопка «Повторить».
3. Добавить диаграмму: карточка появляется сразу с пометкой «Сохраняется…», потом получает настоящий идентификатор. Пустое или пробельное название не отправляется.
4. Изменить название (Enter сохраняет, Escape отменяет), удалить, быстро дважды нажать «Удалить»: уходит один запрос.
5. Ввести текст в поиск: через 400 мс уходит один запрос, предыдущий отменяется.
6. Остановить сервер и добавить запись: она исчезает с уведомлением. Удалить токен в Local Storage и обновить список: появится форма входа с сообщением.
7. Переключатель темы в шапке меняет тему, `Tab` показывает фокус, ссылка пропуска ведёт к содержимому.
