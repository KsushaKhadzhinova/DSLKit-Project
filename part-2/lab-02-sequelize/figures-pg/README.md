# Запуск ЛР2 на PostgreSQL

Снимки сделаны 28 октября 2026 на PostgreSQL 16 в Docker (`docker compose up -d db`, порт 5433, потому что 5432 был занят): `npm run db:reset`, затем `node server.js`, запросы из `requests.http`.
Окно Postman здесь не использовалось: ответы получены скриптом и нарисованы в виде панели ответа. Снимки структуры таблиц сделаны командами psql внутри контейнера.
Это первый прогон лабораторной на PostgreSQL: пять миграций и сидер применились без ошибок.
