# Аудит ЛР2

| Проблема | Риск | Что сделано |
| --- | --- | --- |
| В SQLite нет проверки длины VARCHAR и пустых значений на уровне БД | Мусор от других писателей | CHECK на непустые и длину title, owner, sourceCode в миграции, тест обхода модели |
| `removeColumn` в SQLite терял CHECK при откате | Откат миграции ломал целостность | Откат через `DROP COLUMN`, тест сохранения CHECK; `undo:all` и повтор проверены |
| Сид проверял только первую строку, owner `demo` мог совпасть с пользовательским | Дубли, потеря строк | Сид по каждой строке (owner и title), откат только своих строк, тест |
| TLS PostgreSQL: нельзя доверять своему CA, небезопасный режим допустим везде | Отключённая проверка сертификата | `DATABASE_SSL_CA`, в production TLS обязателен и проверка не отключается, тесты |
| Нет журнала запросов в таблице БД (чётный вариант) | Требование преподавателя | Таблица `RequestLogs`, миграция, middleware, ошибка записи даёт 500, очистка управляющих символов |
| Нет заголовков безопасности, 415, OPTIONS, `Allow` с HEAD | Замечания по теории HTTP | Middleware `http.js`, пределы в `limits.json`, тесты |
| Журнал растёт без ограничения | Рост таблицы | Не сделано: нужна политика хранения, описано здесь |
| Не проверялось на настоящем PostgreSQL | Расхождения диалектов | Не проверено, SQLite в тестах |
