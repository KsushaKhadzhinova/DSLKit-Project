# Аудит ЛР 7 (WebSocket)

| Проблема | Риск | Что сделано |
| --- | --- | --- |
| CORS `origin: '*'` (как в условии) | Любой сайт читает ответы сервера | Убрано. CORS выключен, дополнительные адреса задаются `ALLOWED_ORIGINS`. Тест `extra origins...` |
| Нет проверки `Origin` при подключении | Страница чужого сайта открывает сокет от имени посетителя | `allowRequest` и `src/origin.js`, чужой `Origin` отклоняется. Тест `the handshake from a foreign Origin...` |
| Нет заголовков безопасности | Нет защиты от встраивания и подмены типа | CSP, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, без `X-Powered-By`. Тест |
| Лимит частоты только у сообщений | Флуд событиями `typing`, `editing`, `room:join` | Общий лимит на сокет (`eventRateMax`), тест `every event type is rate limited` |
| Нет лимита комнат на пользователя и участников в комнате | Один клиент создаёт тысячи комнат | `maxRoomsPerUser`, `maxRoomMembers`, `maxUsers` в `limits.json`, тесты |
| История росла без предела по числу комнат | Утечка памяти по выдуманным названиям комнат | `historyMaxRooms`, вытеснение давно не использованных комнат. Тест |
| Личное сообщение самому себе разрешено | Шум, неожиданное поведение | Отказ `You cannot send a private message to yourself`. Тест |
| Имена `Alice` и `alice` считались разными | Подмена собеседника похожим именем | Сравнение без учёта регистра. Тест |
| Комнаты `D1` и `d1` были разными | Люди попадают в разные комнаты | Название приводится к нижнему регистру. Тест |
| В тексте оставались управляющие символы и RTL-переопределение | Подмена вида сообщения | Символы удаляются в `cleanText`, огромная строка отбрасывается до обработки. Тест |
| Индикатор «печатает» оставался после выхода или отключения | Ложный статус у остальных | Сервер шлёт `typing: false` при выходе, клиент гасит индикатор через 3 с. Тест |
| Повторный вход после обрыва дублировал историю, повторная отправка формы входа плодила сокеты | Дубли сообщений, утечка подписок | Клиент перерисовывает историю при входе, старый сокет закрывается перед новым |
| Нет страниц 404 и 500 в стиле сайта | Заглушка сервера, текст ошибки | `404.html`, `500.html`, обработчик ошибок без текста ошибки. Тесты |
| XSS в именах и сообщениях | Выполнение чужого кода | Было `textContent`, оставлено. Добавлен тест, запрещающий `innerHTML` в клиенте, плюс CSP без inline-скриптов. Проверено в браузере |
| Невалидные payload (не объект, массив, огромный пакет) | Падение обработчика | Проверено, ошибок нет. Тесты `payloads that are not objects...`, `an oversized packet...` |
| Нет остановки сервера по SIGINT | Клиенты видят обрыв без закрытия | `io.close` в `server.js` |
| Нет `README` на английском | Требование «отчёты и README на двух языках» | Не сделано, README только на русском, владельцу решить |
| История и личные сообщения не хранятся в MongoDB | Условие допускает, но преподаватель может спросить | Не сделано намеренно: MongoDB в ЛР 6, интерфейс `history.add/list` готов к замене |
| Нет авторизации по токену (вопрос 14 методички) | Имя можно взять любое свободное | Не сделано: в работе нет учётных записей, имя из `auth` |
| Секрет токена по умолчанию общий для всех | Подделка токена любого имени | При `NODE_ENV=production` без `TOKEN_SECRET` сервер не запускается, тест |
| Один адрес занимает все места сервера | Отказ в обслуживании | Лимит `maxPerAddress` (20) в `limits.json`, место освобождается при отключении, тест |
