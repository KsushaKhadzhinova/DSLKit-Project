# Проверка на живой MongoDB (Atlas)

Скрипт [`../scripts/live-mongo-check.mjs`](../scripts/live-mongo-check.mjs) проверяет историю чата (`createMongoHistory`) на настоящем кластере. В `npm test` он не входит: без `MONGODB_URI` печатает `SKIP` и завершается с кодом 0.

```bash
node --env-file=путь/к/.env scripts/live-mongo-check.mjs   # LIVE_SKIP_TTL=1 пропускает ожидание TTL
```

Строка подключения берётся только из окружения и нигде не печатается. Скрипт работает с коллекциями `lab7_test_*` в базе из строки подключения и в конце удаляет только свои.

## Результат (19.11.2026): 15 из 15

Сообщения через сокет-клиентов в двух комнатах записаны в коллекцию с идентификаторами `ObjectId`. После перезапуска сервера история сохранилась в исходном порядке, комнаты не смешиваются, новые идентификаторы уникальны и больше старых. Индекс `{room:1,_id:-1}` есть в Atlas. 10 клиентов отправили 50 сообщений одновременно, сохранены все 50 с уникальными идентификаторами. Клиент после переподключения получил историю и новые сообщения. При `HISTORY_TTL_SECONDS=2` создаётся TTL-индекс по `createdAt`, просроченное сообщение удалено MongoDB примерно за 30 секунд (монитор TTL срабатывает раз в минуту). Ошибок в коде не найдено. Полный вывод: [`live-run.txt`](live-run.txt).
