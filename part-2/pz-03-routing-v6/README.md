# Практическое занятие №3. Маршрутизация в React-приложениях

Проект DSLKit (SaaS, редактор диаграмм как кода). Условие: `materials/text/part-2/Модуль 02…/24. Практическое занятие 3…`. Отчёты: [`report.tpl.md`](report.tpl.md) на русском, [`report.en.tpl.md`](report.en.tpl.md) на английском (без титульного листа и ответов на контрольные вопросы).

## Версия React Router

В условии указан React Router v6 с пометкой «v6?». В этом варианте стоит **`react-router-dom` 6.30**: он точно следует условию. Код тот же, что в варианте с версией 7 (папка [`../pz-03-routing`](../pz-03-routing)), различается только версия пакета в `package.json` и `package-lock.json`. Что выбрать, см. раздел «Чем различаются варианты» ниже.

## Что сделано

| Требование условия                  | Реализация                                                                                    |
| ----------------------------------- | --------------------------------------------------------------------------------------------- |
| Минимум 4 страницы                  | `/`, `/catalog`, `/catalog/:id`, `/about`, `/login`, `/dashboard`, `*` (`pages/pages.jsx`)    |
| Динамический маршрут и `useParams`  | `CatalogItem`, неизвестный `id` показывает 404 на месте                                       |
| Меню с подсветкой (`NavLink`)       | `components/Layout.jsx`, активный пункт получает класс `nav__link--active`                    |
| Страница 404                        | маршрут `*`, компонент `NotFound`                                                             |
| Защищённый маршрут, имитация логина | `components/PrivateRoute.jsx` (layout-маршрут с `Outlet`), `auth.jsx` с флагом в localStorage |
| Программная навигация после входа   | `Login`: `navigate(from ?? '/dashboard')`; выход через маршрут `/logout`                      |

## Запуск

```bash
cd part-2/pz-03-routing
npm install
npm run dev      # http://localhost:5176
npm test         # Vitest, React Testing Library и MemoryRouter (146 тестов)
npm run build
```

## Что проверить

1. Пункт меню текущей страницы подсвечен, на `/catalog/2` подсвечен «Каталог».
2. Открыть `/catalog/999` и `/xyz`: показывается 404.
3. Открыть `/dashboard` без входа: переход на `/login` с подсказкой, после «Войти» возвращение в кабинет.
4. «Выйти» очищает флаг `dslkit.isAuth` в localStorage и ведёт на главную.

## Вход, защита и доступность

Форма входа проверяет имя (пустое и пробельное отклоняются, предел длины в `src/limits.json`). Адрес возврата после входа проверяется (`safeReturnPath`), параметры запроса и якорь сохраняются. После смены маршрута фокус переходит на основное содержимое, заголовок вкладки следует за страницей. Защита маршрута работает только в интерфейсе: настоящую проверку делает сервер. Страницы 404 и 500 оформлены как на сайте первой части.

## Внешний вид и скриншоты

Стили скопированы из сайта первой части командой `node docs/design-contest/bundle-css.mjs src/dslkit.css` (файл `src/dslkit.css`), недостающие правила шапки, карточки ошибки и подсказок лежат в `src/shell.css`, общая оболочка (шапка, подвал, переключатель темы, страницы 404 и 500) в `src/shell/`. Скриншоты для отчёта: `node shots/shots.mjs` (нужны Chrome и пакет `puppeteer-core`, он не входит в зависимости), результат в `figures/`.

## Чем различаются варианты

| | Вариант с версией 6.30 (`pz-03-routing-v6`) | Вариант с версией 7.18 (`pz-03-routing`) |
| --- | --- | --- |
| Условие | точно по условию (в нём «v6») | отличается от условия на одну версию |
| API работы | `BrowserRouter`, `Routes`, `Route`, `NavLink`, `Outlet`, `Navigate`, `useSearchParams` | тот же, без правок |
| Поддержка | старая линейка, исправления выходят, новых возможностей нет | текущая линейка с обновлениями |
| Предупреждения | при запуске в консоли могут появляться сообщения о будущих флагах v7 | сообщений нет |
| Новые возможности (маршрутизатор данных, `useBlocker`, режим фреймворка) | доступны в `createBrowserRouter`, в этой работе не используются | доступны, не используются |
| Что выбрать | если преподаватель требует именно v6 | если вопрос не задан или допустимо обновление |

Ответ на вопрос к преподавателю («допустимо ли v7 вместо v6») решает выбор: пока ответа нет, сдавайте вариант с версией 6.30, он безопасен по условию, а вариант 7.18 держите в запасе.
