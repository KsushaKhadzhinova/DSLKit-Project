# Лабораторная работа №4. Управление состоянием в React-приложении

Проект DSLKit (SaaS, редактор диаграмм как кода). Условие: `materials/text/part-2/Модуль 02…/22. Лабораторная работа 4…`. Предметная область: список диаграмм проекта. Отчёты: [`report.tpl.md`](report.tpl.md) на русском, [`report.en.tpl.md`](report.en.tpl.md) на английском (без титульного листа и ответов на контрольные вопросы).

## Что сделано

| Требование условия                                  | Реализация                                                                          |
| --------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Приложение на Vite                                  | `package.json`, `vite.config.js`, `index.html`, порт 5175                           |
| `useState` для массива, поля ввода, фильтра         | `App.jsx` (массив, фильтры), `DiagramForm.jsx` (поле ввода), `DiagramItem.jsx`      |
| `useEffect` и `localStorage`                        | `hooks/useLocalStorage.js`: загрузка при инициализации, запись при каждом изменении |
| Добавление, удаление, редактирование                | форма, кнопки «Удалить» и «Изменить», переключатель статуса                         |
| Фильтрация и сортировка                             | поиск по названию, статус, сортировка по дате и названию (`utils/diagrams.js`)      |
| Дополнительные эффекты                              | `document.title`, автосохранение с debounce 500 мс (`hooks/useAutosaveStatus.js`)   |
| Статистика                                          | всего, опубликовано, черновики (`StatsBar.jsx`)                                     |
| Пустой localStorage                                 | начальные данные `data/initialDiagrams.js`, повреждённый JSON тоже даёт начальные   |
| Хук `useLocalStorage` вынесен, как советует условие | `hooks/useLocalStorage.js`                                                          |
| Проверка ввода (требование преподавателя)          | `utils/validation.js`: пробельное название, длина; пределы в `src/limits.json`; `ErrorBoundary` |

## Запуск

```bash
cd part-2/lab-04-react-state
npm install
npm run dev      # http://localhost:5175
npm test         # Vitest и React Testing Library, 19 тестов
npm run build    # сборка в dist/
```

## Что проверить

1. Добавить диаграмму кнопкой и клавишей Enter, пустое название игнорируется.
2. Изменить название (Enter сохраняет, Esc отменяет), переключить статус, удалить.
3. Фильтры и сортировка меняют список, при пустой выдаче видно сообщение.
4. Перезагрузить страницу: список сохранился, в DevTools → Application → Local Storage есть ключ `dslkit.diagrams`.
5. Заголовок вкладки показывает число диаграмм, в строке статистики «Сохранение…» сменяется на «Сохранено» через 500 мс.
