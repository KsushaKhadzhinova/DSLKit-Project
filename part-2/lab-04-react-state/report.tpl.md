# Лабораторная работа №4. Управление состоянием в React-приложении

## 1 Цель работы

Освоить управление локальным состоянием в React с помощью хуков `useState` и `useEffect`, обработку побочных эффектов и динамическое обновление интерфейса на примере списка диаграмм проекта DSLKit, веб-редактора диаграмм как кода (направление SaaS).

## 2 Краткое описание приложения

Приложение показывает список диаграмм пользователя. У диаграммы есть название, нотация (UML, BPMN, ERD, DFD, IDEF0, сети Петри), статус «Черновик» или «Опубликована» и дата изменения. Пользователь добавляет диаграмму через форму, переименовывает её, меняет статус, удаляет, ищет по названию, фильтрует по статусу и сортирует по дате или названию. Список переживает перезагрузку страницы, потому что хранится в `localStorage`.

Проект создан на Vite командой `npm create vite@latest` с шаблоном React, тесты написаны на Vitest и React Testing Library. Запуск описан в `README.md` работы.

## 3 Ход работы

### 3.1 Состояние компонента

Массив диаграмм, поле ввода названия, выбранная нотация, строка поиска, фильтр статуса и режим сортировки хранятся через `useState`. Изменения массива записаны функциональными обновлениями вида `setDiagrams((prev) => ...)`, поэтому быстрые подряд идущие действия не теряют друг друга. Поле ввода сделано контролируемым, форма отправляется и кнопкой, и клавишей Enter. Ключевые части кода приведены в приложении А.

### 3.2 Хранение в localStorage

Логика хранения вынесена в хук `useLocalStorage`. Начальное значение читается из `localStorage` функцией-инициализатором `useState`, поэтому при первом рендере уже видны сохранённые данные. Эффект `useEffect` с зависимостью от значения записывает массив через `JSON.stringify` при каждом изменении. Если ключа нет или JSON повреждён, берётся начальный набор из трёх диаграмм.

### 3.3 Фильтрация, сортировка и статистика

Функции `filterDiagrams`, `sortDiagrams` и `getStats` чистые и лежат в `utils/diagrams.js`, поэтому проверяются без отрисовки. Сортировка работает с копией массива и не изменяет состояние.

### 3.4 Дополнительные эффекты

Заголовок вкладки обновляется эффектом и показывает число диаграмм. Хук `useAutosaveStatus` показывает «Сохранение…» после изменения и «Сохранено» через 500 мс тишины. Это debounce: каждое новое изменение очищает прежний таймер функцией очистки эффекта.

### 3.5 Проверка вводимых значений

Форма и режим редактирования проверяют название диаграммы до сохранения. Значение из одних пробелов считается пустым и отклоняется сообщением «Введите название диаграммы». Название длиннее предела отклоняется сообщением с числом допустимых символов. Предел и минимальная длина лежат в отдельном файле `src/limits.json`, а не в коде компонентов. Поле «Создана» у каждой записи показывает уникальное время создания с секундами, поэтому записи визуально различаются. Компонент `ErrorBoundary` показывает оформленное сообщение вместо пустой страницы, если отрисовка завершилась ошибкой.

### 3.6 Тестирование

Автоматические тесты (19 штук) проверяют чистые функции, оба хука и поведение приложения: добавление, удаление, редактирование с Enter и Esc, переключение статуса, фильтры, сортировку и восстановление списка после повторной отрисовки. Ручная проверка: `npm run dev`, затем действия из раздела «Что проверить» файла `README.md`, содержимое `localStorage` смотрится во вкладке Application инструментов разработчика.

## Заключение

Приложение на Vite реализует добавление, удаление и редактирование диаграмм, фильтрацию и сортировку, сохранение в `localStorage` и два дополнительных эффекта, заголовок страницы и автосохранение с debounce. Логика хранения вынесена в пользовательский хук, что упростит замену `localStorage` на REST API в лабораторной работе №5.

## Приложение А (обязательное) Ключевые части кода

```jsx
// hooks/useLocalStorage.js: загрузка через инициализатор, запись эффектом
export function useLocalStorage(key, initialValue) {
  const [value, setValue] = useState(() => readStorage(key, initialValue));
  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);
  return [value, setValue];
}
```

```jsx
// hooks/useAutosaveStatus.js: debounce 500 мс с очисткой таймера
useEffect(() => {
  setStatus('saving');
  const timer = setTimeout(() => setStatus('saved'), AUTOSAVE_DELAY);
  return () => clearTimeout(timer);
}, [value]);
```
