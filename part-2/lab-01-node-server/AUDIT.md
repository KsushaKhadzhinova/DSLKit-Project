# Аудит ЛР1

| Проблема | Риск | Что сделано |
| --- | --- | --- |
| Не было пределов длины полей, пробельные значения проверялись без обрезки | Огромные строки в памяти, пустые по сути записи | Пределы в `limits.json`, проверка после trim, title и owner обрезаются, тесты |
| Тело с другим Content-Type давало путаный 400 | Неверный код состояния | 415 для POST/PUT/PATCH не в JSON, тест |
| OPTIONS на `/diagrams` давал 405 | Нарушение HTTP, мешает предзапросам | OPTIONS отвечает 204 с `Allow`, `Allow` содержит HEAD и OPTIONS, тесты |
| Не было заголовков безопасности, был `X-Powered-By` | Раскрытие стека, MIME-sniffing, фреймы | Middleware `http.js`, `x-powered-by` выключен, тест |
| Лимит тела `100kb` был скрыт в коде | Нет единого места настроек | `bodyBytes` в `limits.json`, тест 413 |
| Данные в массиве, а для чётного варианта 26 требуют БД | Замечание преподавателя | Не сделано: условие ЛР1 требует массив, БД и лог в таблицу реализованы в ЛР2 и ЛР3, вопрос к преподавателю |
| Нет защиты от CSRF и CORS | Не применимо | Нет cookie и сессий, CORS добавляет работа ЛР5 |
