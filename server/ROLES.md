Источник правды: `src/permissions.js`. Эта таблица совпадает с кодом, это проверяет тест `tests/permissions.test.js`. Английская версия: [ROLES.en.md](ROLES.en.md).

## Правила ответов

- Чужой закрытый проект, несуществующий проект и неверный id дают одинаковый ответ 404 (существование не раскрывается).
- Видимый, но запрещённый шаг (запись в общий проект без права, удаление, управление участниками) даёт 403.
- Видимость проекта (`visibility`) меняет только владелец или администратор.
- Администратор не может менять собственную роль (ответ 409).
- Email виден только владельцу аккаунта (`/api/me`) и администратору (`/api/users`).
