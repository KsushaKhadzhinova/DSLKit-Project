## Решения по структуре (проверить)

1. **Архитектура проекта** = интегрированный стек ЛР3 + ЛР5 + ЛР8: React-клиент, Express и Sequelize, PostgreSQL, JWT, Nginx, Docker Compose. Три функциональных модуля: аутентификация, диаграммы, администрирование. MongoDB (ЛР6) и WebSocket (ЛР7) в основной стек не входят, упомянуты как перспективы.
2. **Раздел «1 Цель работы» не нумеруется отдельно.** Структура файла 03 требует цель внутри «Введения», а `lint-report.js` ждёт заголовок `## 1 Цель работы`. Выбрана структура файла 03, поэтому линтер выдаёт одну ожидаемую ошибку про этот заголовок (см. ниже). Если преподаватель требует «1 Цель работы» и здесь, вынести цель и задачи из введения в отдельный раздел, но тогда главы получат номера 2–4.
3. **Диаграммы в тексте даны как рисунки** (`diagrams/*.svg`), а исходники Mermaid вынесены в приложение Д. Причина: строгий линтер запрещает блоки кода в основном тексте, а код в записке должен занимать не больше страницы.
4. **Тема не из списка 150 тем** файла 01. Ближайшие по смыслу: 23 (проекты с досками), 34, 47. [TODO: согласовать тему «DSLKit, редактор диаграмм как кода» с преподавателем.]

## Линтер

`tools/lint-report.js` (строгий режим) лежит в ветках Части 2 (например `25`), в этой ветке инструментов нет, и отчёты курсовой не входят в `tools/report-suite.js`. Линтер запускался отдельно на копии из ветки `25` (файл вне репозитория) командой вида `lintReport(text, 'ru', { strict: true })`.

Результат: `note.md` и `note.en.md` проходят все правила, кроме одного, описанного в пункте 2 (заголовок `## 1 Цель работы`, в английской версии `## 1 Purpose of the Work`). Проверены: «Заключение», приложения «Приложение А (обязательное) ...» со ссылкой на каждое в тексте, нет «также» и «были», нет точки с запятой, нет `"`-кавычек, нет ссылок на рисунки в скобках, подписи «Рисунок N – ...» и «Таблица N – ...», описание со ссылкой словами перед каждым рисунком, нет блоков кода вне приложений.

Не проверяется линтером, сверить вручную: «ёлочки» внутри кода и таблиц, числительные с наращением, неразрывный пробел между «Рисунок» и номером (в Word), межстрочный интервал, объём кода в тексте (в тексте кода нет), заголовки по центру.
