Популярные стили UI — 2025/2026

Анализ актуальных визуальных языков дизайна. DSLKit вдохновляется несколькими направлениями.

Linear Dark (Utility)
Минималистичный тёмный, острые радиусы, фиолетовый акцент, плотная типографика. → DSLKit основа.
Glassmorphism
Матовое стекло, размытый фон, тонкий белый бордер. Используем для модальных окон DSLKit.

Bento Grid
Сетка равноправных карточек разного размера, вдохновлён macOS/Figma. → Используем в Dashboard.
Aurora / Ambient Glow
Мягкие радиальные градиенты имитируют северное сияние. Применяем в Landing page и Onboarding DSLKit.
Neo-Brutalism
Жирные чёрные бордеры, смещённые тени, кислотные акценты, нулевой радиус. Экстремальный контраст — не для DSLKit, референс.
Material Design 3 / You
Скруглённые pill-кнопки, Dynamic Color, state layers, elevation tokens. Вдохновил систему радиусов DSLKit.
Apple HIG / Liquid Glass
Squircle радиусы, SF Pro, translucent materials, iOS 18+ Liquid Glass эффект. → Главный ориентир DSLKit по плавности.
Claymorphism
«Глиняные» 3D элементы с мягкими тенями, пастельные фоны. Заимствуем мягкость теней для карточек DSLKit.
