# Как вносить изменения

Английская версия: [`CONTRIBUTING.en.md`](CONTRIBUTING.en.md).

1. Ветка: короткая, от свежего `origin/main`, имя `feat/…`, `fix/…`, `docs/…`, `ci/…`. Подробнее: [`docs/BRANCHES.md`](docs/BRANCHES.md).
2. Один раз на машине: `npm ci` и `npm run hooks:install` (хук перед push ловит секреты, лишние файлы и подписи инструментов в коммитах).
3. Перед push: `npm run verify` (lint, формат, тесты с покрытием 100%, страж репозитория).
4. Коммиты от имени владельца, на английском, без подписей инструментов и ИИ.
5. Pull request по шаблону. Когда CI на ветке зелёный, автослияние само вливает ветку в `main`.
6. Секреты только в `.env` на своей машине. Тексты на русском и английском меняются вместе.

Что проверяет CI: [`docs/CI-CHECKS.md`](docs/CI-CHECKS.md).
