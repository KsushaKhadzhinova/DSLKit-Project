## 2 Тест-план (кратко)

- **Объём:** главная и форма заявки, три страницы приложения (панель проектов, редактор, настройки), приветствие, страницы ошибок, английская версия; в редакторе: код, холст, шаблоны, импорт и экспорт, поиск и замена, Git-история, AI-помощник, вкладки «Вывод» и «Версии», тема, масштаб, мобильный вид.
- **Не тестировалось:** Firefox, Safari, реальные мобильные устройства, работа через сервис Kroki (выбор движков Graphviz, Mermaid, PlantUML оставлен в настройках и проверен модульно с подменой сети), установка PWA в настоящем Chrome, реальный Git-сервер (Git в редакторе локальный).
- **Критерий входа:** `npm test` зелёный. **Критерий выхода:** все проверки Passed, открытых дефектов выше «низкой» серьёзности нет.
- **Подход:** сначала дымовой набор, потом критический путь, потом расширенный; после каждого исправления полный повтор.

## 7 Риски, ограничения, что не закрыто

- **Сверка работ по ИТиВП** (части 1 и 2, курсовой) сделана чтением: `docs/ITIVP-CHECK.md`. Оставшиеся пункты в основном у владелицы (скриншоты Postman, Atlas, Docker Hub, оформление курсового в Word).
- **Не сделано:** режим «Соединить» работает для нотаций, где связь записывается одной строкой (нотации с графовой записью, IDEF0, ER); для классов UML, диаграмм последовательности и временных диаграмм связи пишутся в коде.
- **AI-помощник** работает по правилам в браузере (исправление опечаток в ключевых словах и незакрытых блоков, объяснение, форматирование, создание из шаблона); внешней языковой модели нет, потому что на сайте нет сервера и ключей.
- **Git в редакторе** локальный: коммиты, сравнение, возврат, копирование diff; подключения к GitHub нет.
- Кроссбраузерность проверена только в Edge; Firefox и Safari не проверялись.
