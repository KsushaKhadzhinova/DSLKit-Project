# Материалы курса ИТиВП

Условия лабораторных и практических работ, методические указания, генераторы вариантов и стандарт предприятия. Тексты PDF извлечены в папку `text/` для поиска и чтения без просмотрщика. Файл `files.tsv` перечисляет все найденные файлы и дубликаты, которые не копировались.

Не включены лекционные презентации и конспекты модулей (сотни мегабайт), они остаются локально в `E:\ИТиВП`.
