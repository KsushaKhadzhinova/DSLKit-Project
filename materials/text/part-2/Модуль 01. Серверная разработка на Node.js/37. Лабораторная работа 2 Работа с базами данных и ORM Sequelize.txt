4. ПОРЯДОК ВЫПОЛНЕНИЯ (общий для всех вариантов)
Часть 1. Подготовка базы данных
1. Установите PostgreSQL (или создайте бесплатный кластер в Neon / Supabase).
2. Создайте базу данных и пользователя. Запишите строку подключения (URL).
Часть 2. Установка зависимостей
npm install sequelize pg pg-hstore
npm install --save-dev sequelize-cli
Часть 3. Настройка Sequelize
1. Инициализируйте структуру:
npx sequelize-cli init
2. Настройте config/config.json или используйте переменные окружения (.env).
Пример для облачной БД:
{
  "development": {
    "use_env_variable": "DATABASE_URL",
    "dialect": "postgres"
  }
}
3. Создайте модель и миграцию (например, для модели Item):
npx sequelize-cli model:generate --name Item --attributes
name:string,description:string
Часть 4. Реализация CRUD в Express
Используйте созданную модель в маршрутах (аналогично лабораторной работе №1),
заменив код работы с массивом на вызовы методов Sequelize:
GET /items → await Item.findAll()
GET /items/:id → await Item.findByPk(id)
POST /items → await Item.create(req.body)
PUT /items/:id → await Item.update(req.body, { where: { id } })
DELETE /items/:id → await Item.destroy({ where: { id } })
Часть 5. Миграция и сиды
1. Создайте миграцию для добавления нового поля (например, priority для задач
или stockQuantity для товаров):
npx sequelize-cli migration:generate --name add-field-to-items
В файле миграции добавьте колонку с помощью addColumn.
2. Выполните миграции: npx sequelize-cli db:migrate
3. Создайте seed-файл для начального наполнения:
npx sequelize-cli seed:generate --name demo-items
4. Заполните файл данными (массив объектов) и выполните: npx sequelize-cli
db:seed:all
