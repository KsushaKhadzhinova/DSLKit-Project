Лабораторная работа 1 "Разработка
серверного приложения на Node.js"
1. ЦЕЛЬ РАБОТЫ
Приобретение практических навыков создания серверного приложения на платформе
Node.js с использованием фреймворка Express.js. Изучение основ маршрутизации,
обработки HTTP-запросов различных типов (GET, POST, PUT, DELETE) и формирования
ответов сервера для последующей интеграции с клиентской частью вашего
курсового проекта (начало выполненно в 1 части курса).
2. НЕОБХОДИМЫЕ ЗНАНИЯ
Для успешного выполнения работы студент должен знать:
Основы платформы Node.js (установка, модульная система, event loop).
Принципы работы фреймворка Express.js (создание приложения, маршруты,
middleware).
Методы HTTP (GET, POST, PUT, DELETE, PATCH).
Работу с параметрами запроса (route params, query string, body).
Форматы передачи данных (JSON, URL-encoded).
3. ЗАДАЧИ РАБОТЫ
Установить и настроить проект Node.js с Express.js.
Создать REST API для управления коллекцией данных, соответствующей
предметной области вашего курсового проекта (например, товары, заявки,
пользователи, заказы, задачи и т.п.).
Реализовать маршруты для CRUD-операций.
Настроить обработку ошибок и возврат соответствующих HTTP-статусов.
Протестировать API с помощью браузера, Postman или curl.
4. ПОРЯДОК ВЫПОЛНЕНИЯ (общий для всех вариантов)
Часть 1. Инициализация проекта
1. Создать папку проекта, выполнить npm init -y.
2. Установить зависимости: npm install express.
3. Установить dev-зависимости: npm install nodemon --save-dev.
4. В package.json добавить скрипты:
"start": "node server.js", "dev": "nodemon server.js".
Часть 2. Создание сервера
1. Создать файл server.js.
2. Подключить Express:
const express = require('express'); const app = express();
3. Добавить middleware для парсинга JSON: app.use(express.json()).
4. Определить порт (3000 или другой) и запустить сервер:
app.listen(port, () => console.log('Server running...')).
Часть 3. Реализация маршрутов (в соответствии с вашей темой курсового
проекта)
Создать набор эндпоинтов:
GET /items – получение списка всех элементов (товаров, задач, пользователей и
т.п.).
GET /items/:id – получение одного элемента по ID.
POST /items – добавление нового элемента.
PUT /items/:id – полное обновление элемента.
DELETE /items/:id – удаление элемента.
Данные временно хранить в массиве в памяти сервера. Название ресурса (items)
замените на соответствующее вашей предметной
области (например, products, tasks, courses, orders). 
Часть 4. Обработка ошибок
При отсутствии элемента возвращать статус 404 и JSON с ошибкой.
При неверных данных запроса возвращать статус 400.
Добавить глобальный обработчик ошибок (error-handling middleware).
Часть 5. Тестирование
Запустить сервер в режиме разработки: npm run dev.
Проверить все эндпоинты через Postman/Insomnia или встроенный REST Client VS
Code.
Зафиксировать результаты.
