реляционной PostgreSQL).

4. ПОРЯДОК ВЫПОЛНЕНИЯ (общий для всех вариантов)
Часть 1. Настройка MongoDB
1. Зарегистрируйтесь на MongoDB Atlas (бесплатный тариф).
2. Создайте бесплатный кластер (M0).
3. Создайте пользователя базы данных, запомните пароль.
4. Получите строку подключения (Connection String) – она понадобится в
приложении.
Альтернатива: установите MongoDB Community Edition локально – все
инструкции и код будут теми же (изменится только строка подключения).
Часть 2. Установка зависимостей
npm install mongoose
(Рекомендуется также установить dotenv для хранения строки подключения в .env.)
Часть 3. Подключение к базе данных
В файле server.js (или db.js) добавьте:
const mongoose = require('mongoose');
mongoose.connect(process.env.MONGO_URI)
  .then(() => console.log('MongoDB connected'))
  .catch(err => console.error('MongoDB connection error:', err));
Часть 4. Создание схемы и модели
Создайте папку models, файл <ModelName>.js. Определите схему в соответствии с
вашей предметной областью. Обязательно используйте хотя бы один вложенный
документ или массив.
Пример для интернет-магазина (товар с отзывами):
const productSchema = new mongoose.Schema({
  name: { type: String, required: true },
  price: Number,
  category: String,
  reviews: [{ userId: String, rating: Number, comment: String }],
  tags: [String],
  createdAt: { type: Date, default: Date.now }
});
const Product = mongoose.model('Product', productSchema);
module.exports = Product;
Часть 5. Реализация CRUD-операций
Создайте маршруты (Express), в которых используются методы Mongoose:
GET /items → Model.find()
GET /items/:id → Model.findById(id)
POST /items → new Model(body).save() или Model.create(body)
PUT /items/:id → Model.findByIdAndUpdate(id, body, { new: true })
DELETE /items/:id → Model.findByIdAndDelete(id)
Часть 6. Работа с вложенными структурами
Добавьте хотя бы один эндпоинт, который использует вложенные массивы
(например, добавление отзыва к товару, добавление подзадачи, регистрация
участника на событие).
Продемонстрируйте, как MongoDB позволяет обновлять элемент внутри массива
(например, увеличить количество товара в корзине).
Часть 7. Проверка и тестирование
Запустите сервер.
Используйте Postman или аналогичный инструмент для тестирования CRUD-
эндпоинтов.
Проверьте данные в MongoDB Compass или веб-интерфейсе Atlas (покажите
вложенную структуру).
