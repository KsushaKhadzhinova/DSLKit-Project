4. ПОРЯДОК ВЫПОЛНЕНИЯ (общий для всех вариантов)
Часть 1. Демонстрация проблемы prop drilling
Создайте иерархию компонентов (например, App → Header → Navigation → UserMenu →
UserAvatar), передавая данные через все уровни.
Покажите, что данные (например, userName) передаются через компоненты, которые их
не используют.
Часть 2. Создание контекста темы
const ThemeContext = createContext();
const ThemeProvider = ({ children }) => {
  const [theme, setTheme] = useState('light');
  const toggleTheme = () => setTheme(prev => prev === 'light' ? 'dark' : 'light');
  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};
Часть 3. Реализация бизнес-логики через useReducer + Context
Создайте редьюсер, соответствующий вашей предметной области (корзина, избранное,
список задач и т.п.):
const cartReducer = (state, action) => {
  switch (action.type) {
    case 'ADD_ITEM':
      // ...
    case 'REMOVE_ITEM':
      // ...
    default:
      return state;
  }
};
const CartProvider = ({ children }) => {
  const [cart, dispatch] = useReducer(cartReducer, []);
  return <CartContext.Provider value={{ cart, dispatch }}>{children}</CartContext.Provider>;
};
Часть 4. Использование в компонентах
const { theme, toggleTheme } = useContext(ThemeContext);
const { cart, dispatch } = useContext(CartContext);
Часть 5. Сохранение состояния (опционально, рекомендуется)
Сохраняйте корзину/избранное в localStorage при каждом изменении.
Восстанавливайте состояние при загрузке приложения.
