4. ПОРЯДОК ВЫПОЛНЕНИЯ (общий для всех вариантов)
Часть 1. Настройка проекта
1. Убедитесь, что ваш сервер (из лабораторных №1–№3) запущен и доступен по
адресу (например, http://localhost:3000).
2. В React-проекте, созданном в лабораторной работе №4, установите axios (или
используйте fetch):
npm install axios
3. Настройте переменные окружения (.env):
VITE_API_URL=http://localhost:3000/api
Часть 2. Создание сервиса API
Создайте файл src/api.js с функциями для взаимодействия с вашим API. Функции
должны использовать JWT-токен (если аутентификация обязательна) и обрабатывать
ошибки.
Пример с использованием axios:
import axios from 'axios';
const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL,
});
// Перехватчик для добавления токена
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});
export const fetchItems = () => api.get('/items');
export const addItem = (item) => api.post('/items', item);
export const updateItem = (id, updated) => api.put(`/items/${id}`, updated);
export const deleteItem = (id) => api.delete(`/items/${id}`);
Часть 3. Компонент списка
Используйте useState для хранения массива данных, флага loading и error.
В useEffect (с пустым массивом зависимостей) загружайте данные
вызовом fetchItems().
При загрузке отображайте индикатор, при ошибке – сообщение и кнопку
«Повторить».
Часть 4. Реализация CRUD-операций с оптимистичным обновлением
Добавление:
сразу добавить новый элемент в локальное состояние (с временным ID,
например Date.now());
отправить POST-запрос;
при успехе заменить временный ID на реальный из ответа сервера;
при ошибке – удалить элемент из состояния и показать уведомление.
Удаление:
оптимистично убрать элемент из списка;
отправить DELETE;
при ошибке – вернуть элемент обратно.
Редактирование:
оптимистично обновить элемент в списке;
отправить PUT/PATCH;
при ошибке – откатить изменение.
Часть 5. Дополнительное улучшение (по выбору)
Выберите одно из следующих улучшений (или другое, согласованное с
преподавателем):
Пагинация – загрузка элементов постранично (limit/offset) с кнопками «Загрузить
ещё» или навигацией.
Поиск (фильтрация) на сервере – добавление эндпоинта с параметром search и
debounce на ввод.
Повтор запроса при ошибке (retry) – до 3 попыток с задержкой.
Отмена запроса при размонтировании – с использованием AbortController.
Бесконечная прокрутка (infinite scroll) – подгрузка следующей страницы при
прокрутке.
Кэширование ответов – с использованием localStorage и инвалидацией кэша.
Загрузка изображений – через FormData (специальный эндпоинт на сервере).

8. ПРИМЕЧАНИЯ
Работа выполняется индивидуально.
Это ключевая лабораторная работа, связывающая клиентскую (React) и
серверную (Node.js) части вашего курсового проекта.
Убедитесь, что сервер поддерживает CORS. Если нет – добавьте middleware cors в
Express (лабораторная работа №3).
JWT-токен должен сохраняться после логина (например, в localStorage) и
автоматически подставляться в запросы (см. пример с axios interceptor).
