Ветка репозитория: pz23
1. ЦЕЛЬ РАБОТЫ
Освоение библиотеки React Router v6: настройка маршрутизации, создание SPA с
несколькими страницами, использование динамических маршрутов, создание
защищённых маршрутов (private routes).
2. НЕОБХОДИМЫЕ ЗНАНИЯ
Компоненты BrowserRouter, Routes, Route, Link, NavLink.
Хуки useParams, useNavigate, useLocation.
Вложенные маршруты и компонент Outlet.
Защита маршрутов (редирект на логин при отсутствии аутентификации).
3. ЗАДАЧИ РАБОТЫ (индивидуально)
Создать React-приложение с несколькими страницами (минимум 4).
Реализовать динамические маршруты (например, /catalog/:id).
Добавить навигационное меню с подсветкой активного пункта (NavLink).
Реализовать страницу 404 (Not Found).
Создать защищённый маршрут, доступный только после «логина» (имитация
аутентификации).
4. ПОРЯДОК ВЫПОЛНЕНИЯ (общий для всех вариантов)
Часть 1. Установка и настройка
npm install react-router-dom
Часть 2. Создание маршрутов
В файле App.jsx определите маршруты:
Главная (/)
Каталог / список (/catalog)
Детальная страница (/catalog/:id)
О проекте (/about)
Страница входа (/login)
Защищённая страница (/dashboard)
404 (*)
Часть 3. Динамические маршруты
В компоненте детальной страницы получите параметр id с помощью useParams().
Часть 4. Защищённый маршрут
Создайте компонент PrivateRoute (или используйте условный рендеринг с Navigate).
Проверяйте флаг isAuth (например, из localStorage или состояния).
Часть 5. Программная навигация
В компоненте Login после имитации входа выполните переход на защищённую
страницу: navigate('/dashboard').
