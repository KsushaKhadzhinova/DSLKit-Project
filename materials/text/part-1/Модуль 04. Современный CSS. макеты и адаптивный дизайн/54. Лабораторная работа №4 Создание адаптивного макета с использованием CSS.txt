Лабораторная работа №4. Создание адаптивного
макета с использованием CSS
1. ЦЕЛЬ РАБОТЫ
Освоение современных технологий CSS для создания адаптивных и отзывчивых
макетов веб-страниц. Формирование практических навыков работы с Flexbox, CSS Grid
Layout, медиазапросами и методологией БЭМ для организации CSS-кода на примере
проекта, тематически связанного с будущим курсовым проектом во 2 части курса
(следующий семестр).
2. НЕОБХОДИМЫЕ ЗНАНИЯ
Для успешного выполнения работы студент должен знать:
Базовый синтаксис CSS (селекторы, свойства, каскадность, наследование).
Семантическую HTML-разметку, созданную в лабораторной работе №3.
Понятие блочной модели (box model).
Основы работы с инструментами разработчика в браузере.
Структуру макета из Figma (собственного или найденного в открытом доступе).
3. ЗАДАЧИ РАБОТЫ
Самостоятельно найти (или создать) дизайн-макет главной страницы в Figma,
тематически соответствующий вашему будущему курсовому проекту.
Реализовать визуальный макет, соответствующий выбранному шаблону (или
созданному самостоятельно).
Применить методологию БЭМ для организации CSS-кода (на основе классов, уже
добавленных в HTML в ЛР №3).
Реализовать макет страницы с использованием Flexbox и CSS Grid.
Обеспечить адаптивность интерфейса с помощью медиазапросов (mobile-first
подход).
Использовать CSS-переменные для управления цветами, шрифтами и отступами.
Протестировать отзывчивость макета на различных разрешениях экрана с
помощью инструментов разработчика браузера.
4. ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ (общий для всех вариантов)
Часть 1. Подготовка проекта и анализ макета
1. Перейдите в рабочую ветку репозитория:
git checkout main
git pull origin main
git checkout -b feature/responsive-layout
2. Выбор дизайн-макета в Figma:
Самостоятельно найдите в открытом доступе (Figma Community) или
создайте простой макет главной страницы, соответствующий тематике
вашего курсового проекта.
Если вы не нашли готовый макет, разрешается использовать любой
бесплатный шаблон, близкий по функциональности (например, для
интернет-магазина, блога, портфолио, образовательной платформы и т.п.).
Сохраните ссылку на макет – она понадобится в отчёте.
3. Анализ макета:
Общую структуру макета (header, main, footer, sidebar).
Цветовую палитру (основные цвета, акцентные).
Типографику (шрифты, размеры, межстрочные интервалы).
Отступы и выравнивание элементов.
Адаптивные версии (мобильная, планшетная, десктопная) – если они
предусмотрены, или продумайте адаптив самостоятельно.
4. Создание и организация CSS-файлов по методологии БЭМ:
В папке css создайте файлы:
variables.css – для CSS-переменных.
base.css – для общих стилей (сброс, базовые настройки).
header.css – стили для шапки.
main.css – стили для основного контента.
footer.css – стили для подвала.
adaptive.css – стили для адаптивности (медиазапросы).
Основной файл style.css (или styles.css) будет импортировать все
остальные.
Часть 2. Настройка CSS-переменных на основе макета
В файле variables.css определите переменные согласно вашему макету:
:root {
    /* Цветовая схема */
    --color-primary: #...
    --color-secondary: #...
    --color-accent: #...
    --color-background: #...
    --color-text: #...
    --color-text-light: #...
    /* Типографика */
    --font-family-main: 'Roboto', sans-serif;
    --font-size-base: 16px;
    --font-size-h1: 2.5rem;
    --font-size-h2: 2rem;
    /* Отступы */
    --spacing-small: 8px;
    --spacing-medium: 16px;
    --spacing-large: 24px;
    --spacing-xlarge: 48px;
    /* Ширины */
    --container-max-width: 1200px;
    --breakpoint-mobile: 576px;
    --breakpoint-tablet: 768px;
    --breakpoint-desktop: 992px;
}
Часть 3. Реализация адаптивного макета
Важно: В этой работе вы НЕ пересоздаёте разметку, а добавляете стили к уже
существующей семантической структуре из лабораторной работы №3. Если в процессе
стилизации потребуется добавить дополнительные HTML-обёртки или классы – это
нормальная практика рефакторинга.
1. Базовые стили (в base.css):
Сброс отступов (margin, padding).
Установка базового шрифта и цвета текста.
Установка box-sizing: border-box.
2. Стилизация компонентов согласно вашему макету:
Шапка сайта (header.css): логотип, навигация (на десктопе –
горизонтальное меню, на мобильных – бургер-меню).
Основной контент (main.css): сетка карточек товаров / статей / курсов
(использовать Grid или Flexbox в зависимости от макета).
Боковая панель (если есть): стилизация фильтров, виджетов, профиля.
Подвал (footer.css): колонки с информацией, ссылки.
3. Создание бургер-меню для мобильных устройств:
На десктопах навигация отображается как горизонтальное меню.
На мобильных устройствах (ширина < 768px) навигация скрывается,
появляется иконка «бургер»; при клике на неё меню раскрывается.
(JavaScript для переключения класса добавляется в следующей работе, но
HTML-структуру и базовые стили нужно подготовить сейчас.)
Часть 4. Применение Flexbox и CSS Grid
1. Flexbox – для выравнивания элементов в шапке, футере, выравнивания карточек
по высоте, создания горизонтальных списков.
2. CSS Grid – для построения основной сетки страницы (например, двухколоночный
макет с сайдбаром), сетки карточек.
3. Пример использования Grid для основного макета:
.page {
    display: grid;
    grid-template-areas: 
        "header"
        "main"
        "sidebar"
        "footer";
}
@media (min-width: 768px) {
    .page {
        grid-template-areas: 
            "header header"
            "main sidebar"
            "footer footer";
        grid-template-columns: 1fr 300px;
    }
}
Часть 5. Адаптивность с помощью медиазапросов (mobile-first)
Реализуйте три точки перелома (mobile-first подход):
Мобильные устройства: ширина < 576px (базовые стили).
Планшеты: 576px – 768px – двухколоночная сетка для карточек.
Десктопы: 768px – 1200px – трёхколоночная сетка для карточек, горизонтальное
меню.
Пример медиазапросов в файле adaptive.css:
/* Базовые стили для мобильных устройств */
.products-grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: var(--spacing-medium);
}
/* Планшеты */
@media (min-width: 768px) {
    .products-grid {
        grid-template-columns: repeat(2, 1fr);
    }
}
/* Десктопы */
@media (min-width: 1024px) {
    .products-grid {
        grid-template-columns: repeat(3, 1fr);
    }
}
Часть 6. Тестирование соответствия макету
Сравните вашу реализацию с макетом в Figma (или с вашим собственным
эскизом).
Проверьте соответствие:
Цветовой схемы.
Типографики (шрифты, размеры, жирность).
Отступов и размеров (проверяйте с помощью инструментов разработчика).
Адаптивного поведения на разных разрешениях.
Часть 7. Эксперименты с кросс-браузерной совместимостью
Протестируйте страницу в нескольких браузерах (Google Chrome, Mozilla Firefox,
Safari при возможности, Microsoft Edge).
Обратите внимание на поддержку CSS Grid и Flexbox в старых браузерах. Если
какие-то свойства не работают – добавьте фоллбэки.
Проверьте отображение на реальных устройствах (или с помощью эмуляторов в
DevTools).
Часть 8. Фиксация изменений
git add css/
git add index.html
git commit -m "feat: implement responsive layout according to Figma design"
git push origin feature/responsive-layout
