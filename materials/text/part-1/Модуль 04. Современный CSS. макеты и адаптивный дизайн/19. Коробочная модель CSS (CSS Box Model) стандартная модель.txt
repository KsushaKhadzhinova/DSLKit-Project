Коробочная модель CSS (CSS Box
Model): стандартная модель
https://html5book.ru/css-blochnaya-model/
Коробочная модель CSS (CSS Box Model) — это основное понятие в веб-дизайне,
которое определяет, как элементы отображаются на странице и как они
взаимодействуют друг с другом.
CSS Box Model описывает структуру каждого элемента как прямоугольную коробку,
состоящую из нескольких слоев.
Понимание принципов работы коробочной модели имеет решающее значение для
эффективного управления размером, отступами и границами элементов. 
Как упоминалось выше, все объекты страницы ведут себя либо как блок, либо как
строка (в общем случае). Так или иначе, они характеризуются набором параметров, о
которых не следует забывать при формировании макета страницы.
Предположим, нам требуется создать блок <article> размером 450 на 250 пикселей с
отступами и границами. Эти дополнительные свойства по умолчанию будут
учитываться, что может расширить реальные размеры коробки. С другой
стороны, CSS не запрещает задать точные размеры элемента с включением всех его
свойств.
Вначале посмотрим на все свойства блока с учетом параметров размеров (показаны
на рисунке ниже).
Области блочного элемента
Вычисление размера блока осуществляется по атрибутам:
1. Параметры контента Content (свойства width и height)- Это фактический контент
элемента (текст, изображения и т. д.). Ширина и высота содержимого
определяются свойствами width и height;
2. Внутренние отступы (свойство padding)- Отступ между содержимым и границей
элемента. Отступ может быть задан по всем сторонам или отдельно для каждой
стороны. Отступы добавляются к размерам содержимого и могут быть настроены
отдельно для каждой стороны (верх, право, низ, лево);
3. Граница, рамка (свойство border)- Это линия, окружающая элемент. Границы
окружают содержимое и внутренние отступы. Они могут иметь ширину, стиль и
цвет, и их размеры также добавляются к размерам элемента;
4. Внешние отступы (свойство margin)- Отступ между границей элемента и другими
элементами. Также может быть задан по всем сторонам или отдельно для каждой
стороны. Внешние отступы также влияют на общие размеры элемента, но не
учитываются при расчете внутреннего размер.
Общий размер элемента, в итоге, будет определяться на основании стандартной или
альтернативной блочной модели.

Влияние свойств на размеры элемента
Важно понимать, как свойства width, height, padding, border и margin взаимодействуют
друг с другом и влияют на общий размер элемента.
По умолчанию, если вы установите только width и height, фактический размер
элемента будет больше из-за добавления padding, border и margin.
Расчет общей ширины и высоты:
Ширина элемента: width + padding-left + padding-right + border-left +
border-right
300px + 20px + 20px + 5px + 5px = 350px
Высота элемента: height + padding-top + padding-bottom + border-top + border-
bottom
200px + 20px + 20px + 5px + 5px = 250px
Общая ширина с учетом внешнего отступа: ширина элемента + margin-left +
margin-right
350px + 10px + 10px = 370px
Общая высота с учетом внешнего отступа: высота элемента + margin-top +
margin-bottom
250px + 10px + 10px = 270px
2. Влияние отступов (Padding)
Отступы увеличивают размер области, занимаемой элементом, без изменения
фактического размера содержимого. Например, если у вас есть элемент с шириной
300px и внутренним отступом 20px, фактическая ширина элемента станет 340px.

Границы также добавляют к общему размеру элемента. Ширина границы будет
добавлена к размерам элемента, что также необходимо учитывать при
проектировании.
Пример:
Общая ширина: 300px + 5px + 5px = 310px
4. Влияние внешних отступов (Margin)
Внешние отступы не влияют на фактический размер элемента, но они создают
пространство между элементами на странице. Внешние отступы могут вызвать
смещение других элементов на странице.

На что обратить внимание?
1. Свойство padding при передаче одного значения определяет внутренние отступы от
содержимого по всем четырем направлениям (внизу, вверху, слева, справа).
2. Свойство border характеризует толщину рамки, ее вид (в нашем случае – сплошная
линия), цвет.
3. Свойство margin задает отступы от других блоков страницы по тем же четырем
направлениям.
4. На основании стандартной модели итоговый размер блока будет не 650 на 300
пикселей, а следующим:
– ширина: 650 + 10 +10 + 5 + 5 + 20 + 20 = 720 px;
– высота: 300 + 10 +10 + 5 + 5 + 20 + 20 = 370 px.
В ряде случае это неудобно, так как заказчик требует размер блока с учетом всех
отступов и границ.
5. Проблемы с наложением внешних отступов
Важно отметить, что при использовании внешних отступов может возникнуть явление,
известное как схлопывание (margin collapsing), когда верхний и нижний внешние
отступы соседних элементов "сливаются".
Это может привести к неожиданным результатам при расчете общего размера блока.
