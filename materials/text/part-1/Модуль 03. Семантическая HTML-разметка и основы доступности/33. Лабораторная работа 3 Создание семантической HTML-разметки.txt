Лабораторная работа №3. Создание семантической
HTML-разметки
1. ЦЕЛЬ РАБОТЫ
Освоение принципов семантической HTML-разметки, основ веб-доступности и
микроразметки Schema.org. Формирование навыков создания валидной,
структурированной HTML-разметки для проекта, тематически связанного с будущим
курсовым проектом во 2 части курса (следующий семестр), на основе самостоятельно
выбранного дизайн-макета в Figma.
2. НЕОБХОДИМЫЕ ЗНАНИЯ
Для успешного выполнения работы студент должен знать:
Базовую структуру HTML5-документа.
Основные HTML-теги и их назначение.
Понятие семантической вёрстки.
Основы работы с Figma для анализа макетов.
Принципы валидации HTML-разметки.
Основы микроразметки Schema.org.
3. ЗАДАЧИ РАБОТЫ
Самостоятельно найти (или создать) дизайн-макет в Figma, тематически
соответствующий вашему будущему курсовому проекту.
Проанализировать макет и выделить семантические блоки.
Создать семантическую HTML-разметку главной страницы согласно макету.
Применить современные семантические теги HTML5.
Обеспечить базовую доступность с помощью атрибутов alt, правильной
структуры заголовков и skip-link.
Добавить базовую микроразметку Schema.org, соответствующую типу вашего
проекта.
Проверить валидность созданной разметки.
4. ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ (общий для всех вариантов)
Часть 1. Подготовка проекта и работа с Figma
1. Перейдите в рабочую ветку репозитория:
git checkout main
git pull origin main
git checkout -b feature/semantic-markup
2. Выбор дизайн-макета в Figma:
Самостоятельно найдите в открытом доступе (Figma Community) или
создайте простой макет главной страницы, соответствующий тематике
вашего курсового проекта.
Если вы не нашли готовый макет, разрешается использовать любой
бесплатный шаблон, близкий по функциональности (например, для
интернет-магазина, блога, портфолио, образовательной платформы и т.п.).
Сохраните ссылку на макет – она понадобится в отчёте.
3. Анализ дизайн-макета:
Изучите структуру макета, обращая внимание на:
Основные семантические блоки (header, main, footer, aside).
Иерархию заголовков (h1–h6).
Навигационные элементы.
Основной контент и дополнительные секции.
4. Экспорт ресурсов:
Экспортируйте необходимые изображения в папку images/ вашего проекта.
Сохраните информацию о шрифтах и цветах в файл design/design-
tokens.txt.
Часть 2. Создание базовой семантической структуры
На основе анализа Figma-макета создайте в файле index.html базовую семантическую
структуру:
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Название вашего проекта</title>
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <a href="#main" class="skip-link">Перейти к основному содержимому</a>
    <header>
        <!-- Шапка сайта -->
    </header>
    <nav>
        <!-- Навигация -->
    </nav>
    <main id="main">
        <!-- Основное содержимое -->
    </main>
    <aside>
        <!-- Боковая панель (если есть) -->
    </aside>
    <footer>
        <!-- Подвал -->
    </footer>
</body>
</html>
Часть 3. Создание семантической разметки по вашему проекту
1. Используйте следующие семантические теги (не менее 8 различных):
<header>, <nav>, <main>, <article>, <section>, <aside>, <footer>
<h1>–<h6> (правильная иерархия заголовков)
<figure>, <figcaption>, <time>
2. Обеспечьте базовую доступность:
Добавьте атрибут alt для всех изображений.
Используйте осмысленные тексты ссылок.
Создайте логичную структуру заголовков.
Добавьте skip-link для быстрой навигации (уже включён выше).
3. Использование методологии БЭМ:
При создании HTML-структуры сразу добавляйте классы по методологии
БЭМ (Блок, Элемент, Модификатор). Это облегчит последующую
стилизацию в лабораторной работе №4.
Пример: <header class="header">, <nav class="nav">, <div
class="article__title"> и т.п.
Часть 4. Добавление микроразметки Schema.org
1. Определите тип микроразметки в соответствии с вашим проектом (см.
рекомендации ниже).
2. Добавьте микроразметку с использованием
атрибутов itemscope, itemtype, itemprop.
3. Пример для интернет-магазина (Product):
<div itemscope itemtype="https://schema.org/Product">
    <h2 itemprop="name">Название товара</h2>
    <img itemprop="image" src="images/product.jpg" alt="Описание товара">
    <p itemprop="description">Описание товара</p>
    <div itemprop="offers" itemscope itemtype="https://schema.org/Offer">
        <span itemprop="price">1999</span>
        <span itemprop="priceCurrency">RUB</span>
    </div>
</div>
4. Пример для новостной статьи (NewsArticle):
<article itemscope itemtype="https://schema.org/NewsArticle">
    <h1 itemprop="headline">Заголовок новости</h1>
    <meta itemprop="datePublished" content="2025-01-15">
    <p itemprop="articleBody">Текст новости...</p>
</article>
5. Проверьте микроразметку с помощью Google Rich Results Test (или
аналогичного инструмента).
Часть 5. Наполнение контентом
Добавьте контент, соответствующий вашей тематике (тексты, изображения,
ссылки).
Используйте семантические теги для разметки контента.
Следите за тем, чтобы HTML-код оставался читаемым и структурированным.
Часть 6. Проверка и тестирование
1. Проверьте валидность HTML:
Используйте W3C Validator.
Исправьте все ошибки и критические предупреждения.
2. Проверьте микроразметку:
Используйте Google Rich Results Test.
Убедитесь, что основные свойства определены корректно.
3. Сделайте коммит:
git add index.html
git add images/
git commit -m "feat: add semantic HTML markup with Schema.org for [тип проекта]"
git push origin feature/semantic-markup
