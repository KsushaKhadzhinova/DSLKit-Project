Лабораторная работа №5. Разработка интерактивного
интерфейса на JavaScript
1. ЦЕЛЬ РАБОТЫ
Освоение основ языка JavaScript и практических навыков работы с DOM (Document
Object Model). Формирование умения создавать интерактивные элементы веб-
интерфейса, обрабатывать события и динамически изменять содержимое страницы на
примере проекта, тематически связанного с будущим курсовым проектом во 2
части курса (следующий семестр).
2. НЕОБХОДИМЫЕ ЗНАНИЯ
Для успешного выполнения работы студент должен знать:
Основы языка программирования JavaScript:
Переменные, операторы, условные выражения и циклы.
Массивы и объекты.
Функции и обработка ошибок.
Работа с DOM:
Основные методы для выборки элементов на странице.
Изменение атрибутов, стилей и содержания элементов.
Добавление и удаление элементов.
Обработка событий:
Применение обработчиков событий (клики, отправка форм).
Использование таймеров, анимаций и задержек.
Валидация форм и работа с LocalStorage.
Основы HTML и CSS (из предыдущих лабораторных работ).
Основы работы с консолью разработчика в браузере.
3. ЗАДАЧИ РАБОТЫ
Изучить основные операции работы с DOM (поиск элементов, манипуляция
контентом и стилями).
Освоить обработку событий (click, input, submit и др.).
Реализовать интерактивные компоненты в соответствии с тематикой вашего
курсового проекта.
Научиться работать с формами и валидацией данных.
Организовать код в соответствии с лучшими практиками (ES6+, модульность).
Использовать LocalStorage для сохранения состояния (например, корзины,
избранного, лайков и т.п.).
4. ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ (общий для всех вариантов)
Часть 1. Подготовка проекта и настройка окружения
1. Перейдите в рабочую ветку репозитория:
git checkout main
git pull origin main
git checkout -b feature/javascript-interactivity
2. Создайте структуру файлов JavaScript:
В папке js создайте:
script.js – основной файл скриптов.
components/ – папка для отдельных компонентов
(например, cart.js, filters.js, slider.js).
utils/ – папка для вспомогательных функций
(например, storage.js, validation.js).
3. Подключите JavaScript к HTML в конце тега <body>:
<script src="js/script.js"></script>
Часть 2. Основы работы с DOM (примеры для ознакомления)
Поиск элементов: getElementById(), querySelector(), querySelectorAll().
Манипуляция
контентом: textContent, innerHTML, createElement(), appendChild(), remove().
Работа с классами: classList.add(), classList.remove(), classList.toggle().
Часть 3. Обработка событий
Базовые события: click, input, submit, change, scroll.
Делегирование событий: использование event.target для обработки
динамически добавляемых элементов.
Часть 4. Реализация интерактивных компонентов (по вашему проекту)
Общее задание для всех студентов (индивидуально):
На основе HTML-структуры и CSS-стилей, созданных в предыдущих лабораторных
работах, реализуйте не менее 3 различных типов событий и не менее 2
интерактивных компонентов, характерных для вашей предметной области.
Примеры интерактивных компонентов (выберите подходящие для вашего
проекта):
Фильтрация элементов (новостей, товаров, рецептов, курсов и т.п.) по
категориям, цене, тегам.
Корзина покупок / избранное (добавление, удаление, подсчёт итогов) с
сохранением в LocalStorage.
Слайдер изображений (ручной или автоматический).
Табы (вкладки) для переключения между разными типами контента.
Модальное окно (для подробного просмотра, добавления, редактирования).
Система лайков / оценок (звёздный рейтинг) с сохранением состояния.
Форма с валидацией (регистрация, бронирование, отзыв, обратная связь).
Аккордеон (раскрывающиеся блоки) для FAQ или категорий.
Прогресс-бар (чтения статьи, прохождения курса, обратного отсчёта).
Таймер (обратный отсчёт до мероприятия, время приготовления блюда).
Бесконечная прокрутка или пагинация (динамическая подгрузка элементов).
Поиск с автодополнением (по элементам на странице).
Требования:
Каждый компонент должен использовать минимум один тип события
(например, click для кнопки, input для поиска, submit для формы).
Состояние интерактивных компонентов (например, содержимое корзины,
избранное, лайки) должно сохраняться в LocalStorage и восстанавливаться при
перезагрузке страницы.
Часть 5. Работа с формами и валидация (если применимо к вашему проекту)
Реализуйте валидацию полей формы:
Проверка на пустоту.
Проверка формата (email, телефон, дата).
Вывод сообщений об ошибках.
Отправка формы (имитация) – вывод данных в консоль или сохранение
в LocalStorage.
Часть 6. Рефакторинг и тестирование
Протестируйте функциональность в разных браузерах (Chrome, Firefox, Edge).
Проверьте обработку ошибок (try/catch).
Убедитесь, что код соответствует стандартам ES6+ (стрелочные
функции, const/let, шаблонные строки).
