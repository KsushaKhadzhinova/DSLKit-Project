Лабораторная работа №7. Создание компонентного
интерфейса с использованием React
1. ЦЕЛЬ РАБОТЫ
Освоение концепций компонентного подхода в React. Практическое знакомство с созданием
компонентов, работой с JSX и передачей данных через props. Подготовка компонентной базы для
последующего управления состоянием и интеграции с сервером (во 2 части курса, следующий
семестр).
2. НЕОБХОДИМЫЕ ЗНАНИЯ
Для успешного выполнения работы студент должен знать:
Продвинутый JavaScript (ES6+: стрелочные функции, деструктуризация, модули, spread/rest).
HTML5 и CSS3 (семантическая вёрстка, базовые стили, адаптивность).
Основы компонентного подхода в веб-разработке.
Работу с API (из лабораторной работы №6) – как база для будущей интеграции.
3. ЗАДАЧИ РАБОТЫ
Создать React-приложение с использованием Vite.
Изучить синтаксис JSX и его отличия от обычного HTML.
Научиться создавать функциональные компоненты.
Освоить передачу данных между компонентами через props.
Понять концепции SPA, Virtual DOM и различия между фреймворками (React, Vue, Angular).
Создать библиотеку переиспользуемых компонентов для дальнейшего использования в
курсовом проекте.
4. ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ (общий для всех вариантов)
Шаг 1. Подготовка рабочего окружения
1. Откройте терминал и перейдите в папку ваших проектов.
2. Создайте новое React-приложение с помощью Vite:
npm create vite@latest my-react-app -- --template react
3. Перейдите в созданную папку проекта и установите зависимости:
cd my-react-app
npm install
4. Установите React Router (для будущих работ по маршрутизации, но в этой работе не
используется):
npm install react-router-dom
5. Запустите приложение в режиме разработки:
npm run dev
Приложение будет доступно по адресу http://localhost:5173.
Шаг 2. Знакомство со структурой проекта и организация файлов
Создайте следующую структуру папок в src/ (в соответствии с вашей тематикой курсового проекта):
src/
├── components/
│   ├── ui/           – базовые UI-компоненты (Button, Card, Badge и т.п.)
│   ├── layout/       – компоненты макета (Header, Footer, Sidebar)
│   └── features/     – предметные компоненты (ProductCard, NewsItem, TaskItem и т.п.)
├── pages/            – (заготовка для будущей маршрутизации)
├── data/             – моковые данные (массивы объектов)
├── App.jsx           – корневой компонент
├── main.jsx          – точка входа
└── index.css         – глобальные стили (можно использовать CSS-модули или styled-components)
Шаг 3. Создание базовых UI-компонентов
Пример компонента кнопки (src/components/ui/Button.jsx):
function Button({ children, onClick, variant = 'primary', ...props }) {
    const className = `btn btn--${variant}`;
    return (
        <button className={className} onClick={onClick} {...props}>
            {children}
        </button>
    );
}
export default Button;
Пример компонента карточки (src/components/ui/Card.jsx):
function Card({ children, title, className = '' }) {
    return (
        <div className={`card ${className}`}>
            {title && <div className="card__title">{title}</div>}
            <div className="card__content">{children}</div>
        </div>
    );
}
export default Card;

Шаг 5. Создание композитных (предметных) компонентов
Пример компонента карточки товара (src/components/features/ProductCard.jsx):
import Card from '../ui/Card';
import Button from '../ui/Button';
function ProductCard({ product, onAddToCart }) {
    return (
        <Card title={product.name}>
            <img src={product.image} alt={product.name} />
            <p>Цена: {product.price} ₽</p>
            <p> {product.rating}</p>
            <Button onClick={() => onAddToCart(product)}>В корзину</Button>
        </Card>
    );
}
export default ProductCard;
Шаг 6. Компонент списка с фильтрацией (опционально, но рекомендуется)
Пример компонента ProductList.jsx:
import ProductCard from '../features/ProductCard';
import { useState } from 'react'; // но без useEffect (по заданию)
function ProductList({ products, onAddToCart }) {
    const [category, setCategory] = useState('all');
    const filtered = category === 'all' ? products : products.filter(p => p.category === category);
    return (
        <div>
            <select onChange={(e) => setCategory(e.target.value)} value={category}>
                <option value="all">Все</option>
                <option value="electronics">Электроника</option>
                {/* другие категории */}
            </select>
            <div className="product-grid">
                {filtered.map(product => (
                    <ProductCard key={product.id} product={product} onAddToCart={onAddToCart} />
                ))}
            </div>
        </div>
    );
}
export default ProductList;
Шаг 7. Главный компонент приложения (App.jsx)
import Header from './components/layout/Header';
import ProductList from './components/features/ProductList';
import { mockProducts } from './data/products';
function App() {
    const handleAddToCart = (product) => {
        console.log('Добавлен в корзину:', product);
        // в следующих работах будет реализовано состояние
    };
    return (
        <div>
            <Header title="Магазин" />
            <main>
                <ProductList products={mockProducts} onAddToCart={handleAddToCart} />
            </main>
        </div>
    );
}
export default App;

семестре вы добавите управление состоянием (useState/useEffect), маршрутизацию (React
